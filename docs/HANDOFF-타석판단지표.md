def decision_value(swing, swing_value, take_value):

### 새 APR (`HS% − NS%`)의 알려진 병리

이진 분류의 **Youden's J** (민감도 − 위양성률)와 동형이다.

| 상황 | 처리 |
|---|---|
| `a+b=0` | APR 미정의. 0 대입은 "기회 없음"을 "공격 실패"로 바꾼다 |
| `c+d=0` | APR 미정의. 0 대입은 미관측 선택성을 완벽으로 처리한다 |
| 한쪽 분모만 작음 | 총 투구 자격만으로 불충분. **양쪽 분모를 따로 공개** |
| 항상 스윙 / 항상 테이크 | 둘 다 APR=0. 원인이 정반대인데 요약값이 같다 |
| 극단 행동 + 성분별 shrinkage | 서로 다른 분모·사전평균 때문에 두 사후평균이 갈려 **추정 절차가 만든 가짜 차이**가 생길 수 있다 |

조건부 분산: `Var(APR | n_H, n_N) = p_H(1−p_H)/n_H + p_N(1−p_N)/n_N`. 극단 관측비율을 그대로 대입하면 분산이 0처럼 보인다 — 적은 표본에서 전부 스윙했다는 사실이 확률을 안다는 뜻이 아니다.

추가 성질: **기회 빈도를 제거하는 대신 희소 기회를 크게 가중한다** (hittable 1구 개선 = `1/n_H`). 클래스 비중은 보정하지만 **클래스 내부 난이도는 보정하지 않는다.** 전체 스윙 성향이 바뀌면 위치 구별 능력이 같아도 값이 변한다 — 민감도만 분리한 지표가 아니다.

### Task 1 — DV 정의 확정 — **완료 (`docs/ADR-001-DV-정의.md`)**

> **결정: `DV_avg = (S − p)·Δ`.** 세 후보는 모두 `c·(S−p)Δ + g` 꼴이고 `g`는 타자의 선택에
> 의존하지 않는 기회 항인데, `g = 0`인 것은 `DV_avg`뿐이다. 2026 실측(300구 이상 163명)에서
> 선수 간 분산 중 기회 항 지분은 현행 `(2S−1)Δ` 43.0%, `DV_opt` 20.1%, `DV_avg` 0%.
> `DV_avg`는 기존 `swing_aggression`·`za_raw`와 같은 `(S − p)` 잔차 계열이기도 하다.
> **구현은 Task 2 이후** — 교체될 Δ 표면 위의 값을 웹에 배포하지 않기 위해서다.

> C-6 기준 정정: 교체 여부의 문제가 아니다. 기대값 기반 DV는 **이미 `zone_decision.decision_value`로 존재하고 웹에 노출 중**이며, `decision_run`은 이미 별도 이름("Run Value" · `observed_decision_run`)으로 분리되어 있다. 남은 결정은 **현 DV(`(2S−1)·Δ` 원형)를 `DV_avg`/`DV_opt` 중 하나로 재정의할지**다.

~~`decision_run`(결과 기반)을 그대로 둘지, 기대값 기반 DV로 교체할지 결정.~~

### Task 4 — 지표 계산

- **SBJ**: `d` (두 평면 signed distance 중 작은 값) → τ 추정(카운트 고정효과 + 타자별 이질성 민감도 확인) → 모집단 필터 → 집계
- **APR**: HS% / NS% 각각. **양쪽 분모를 반드시 함께 출력.** 미정의 케이스는 결측 처리, 0 대입 금지
- **DV**: Task 1에서 정한 정의

**수용 기준**: 선수별 지표 + 각 분모 + 결측 사유가 한 테이블에.

### Task 5 — 중복 진단

rev.2의 부호 일치율 단독 판정은 폐기. 다음을 계산한다.

1. `Δ = k·Z + r` 회귀 (Z = tanh(d/τ)) → 투구 단위 잔차 `r`
2. 선수별 `mean((2S−1)·r)` 의 분포와 **독립 경기 블록 간 재현성**
3. 참고용으로 `mean(sign(d)==sign(Δ))` 와 `corr(Z, Δ)` 도 기록하되 판정에 쓰지 말 것

**판정**: 선수별 `mean(M·r)` 이 블록 간 재현되면 SBJ와 DV는 다른 것을 잰다. 재현되지 않으면 중복이다.

**수용 기준**: 재현성 수치와 그 불확실성 구간.
