# 0012. Zone Profile 색: 비율은 한 방향 색, AVG는 .250 중심, 기본 최소 표본 5구

- **상태**: 대체됨 → [0015](0015-zone-profile-league-relative.md) (2026-10)

## 맥락
Zone Profile은 모든 지표를 0~100%(AVG는 .000~1.000) 고정 범위의 파랑-흰색-빨강으로 칠해, 흰색이 항상 50%(.500)였습니다. 존 밖 0% 칸이 진한 파랑으로 화면 대부분을 덮어 존 안으로 시선이 가지 않았고, AVG는 대부분 파랑이었습니다. 최소 표본 기본값 0이라 1~2구 칸이 0%·100%로 진하게 칠해졌고, 범례에 숫자가 없었으며, 진한 칸의 검은 글자는 대비가 낮았습니다.

## 결정
- 비율 지표(Swing·Whiff·Contact·In-play %)는 연한 회색 → 빨강의 한 방향 색. 상한은 보이는 칸 최댓값을 10%p 단위로 올림.
- AVG는 .250을 가운데로 둔 양방향 색(.000~.500).
- 범례에 하한·중간·상한 숫자 표시. 배경이 진하면 흰 글자.
- 최소 표본 기본값 5구. 툴팁에 칸의 투구 수 표시. 0구·표본 미달 칸은 회색 빈칸.

## 기각한 대안
- 리그 평균 대비 색: 칸별 리그 집계가 데이터에 없어 `zone_profile.py` 변경이 필요합니다. 별도 작업으로 남깁니다.
- 선수 간 고정 상한(예: 0~80%): 선수끼리 비교는 쉽지만, 스윙이 적은 타자는 대부분 연하게 보여 구분이 줄어듭니다. 범례 숫자로 상한을 보여 주는 쪽을 택했습니다.

## 결과
- 같은 색이라도 선수마다 상한이 다를 수 있으므로 범례 숫자를 함께 읽습니다.
- 표본 미달 칸이 늘어 보일 수 있습니다(필요하면 최소 표본을 0으로 바꿈).
