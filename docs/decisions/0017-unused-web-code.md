# 0017. 미사용 웹 코드는 참조와 화면 동일성을 확인한 뒤 제거

- **상태**: 채택 (2026-10)

## 맥락
운영 진입점(`cli._exports()`, `--only`, 워크플로), 수동 실행 스크립트와 분석 코드를 조사했습니다. Python의 모델 부품·과거 시즌 fallback은 현재도 사용되고, `trackman_arm_angle.elevation_3d`는 운영 호출이 없어도 얼린 파일의 일부입니다. 반면 웹에는 폐기된 UI의 스타일과 호출되지 않는 표시 함수가 남아 있었습니다.

## 결정
- HTML과 JS의 동적 마크업·클래스 생성에 참조가 없는 항목만 제거합니다.
  - `styles.css`: 예전 선수 목록·카드(`player-list`, `player-card`와 하위 클래스)의 기본·모바일 스타일.
  - `theme.css`: 제거된 선수 카드와 옛 설명 패널(`reading-note`)의 공통 테두리 선택자.
  - Pitch Plot: 없는 `table-heading`, `frequency-count`, 공통 설명 카드로 대체된 `method-note`.
  - Swing/Take 프로필: 없는 `zone-key`·`zone-note`와 썸네일 숨김 선택자.
  - Zone Profile: 없는 `zone-guide`. Swing/Take 프로필의 같은 이름 클래스는 사용 중이므로 유지합니다.
  - Approach: 호출되지 않는 `signClass`. 실제 렌더링이 쓰는 `good`·`bad` 스타일은 유지합니다.
- 공통 CSS의 캐시 버전은 9개 페이지에서 함께 올리고, 변경한 도구 CSS·JS 버전도 올립니다.
- 기준 커밋과 같은 데이터로 1440px·390px의 모든 페이지와 6개 썸네일 캡처를 비교합니다. 지표 빌더·수식·산출물은 변경하지 않습니다.

## 기각한 대안
- 정적 분석기가 미사용으로 표시하는 모든 항목 삭제: 프레임워크 콜백, 수동 도구, 분석 코드의 사용을 놓칠 수 있습니다.
- 얼린 파일의 미사용 함수 제거: 모델에 고정된 소스 hash를 깨뜨립니다([0010](0010-frozen-files.md)).
- 지표 빌더를 함께 정리: 삭제를 뒷받침하는 미사용 근거가 없으며, 이번 변경은 웹의 미사용 코드에 한정합니다.

## 결과
- 화면·썸네일·데이터를 유지하면서 불필요한 스타일과 함수를 제거합니다.
- 기준 `fa3ba254` 대비 24개 캡처(9개 페이지 × 1440px·390px + 썸네일 6개)가 픽셀 단위로 동일했고, 브라우저 실행 오류·모바일 가로 넘침이 없었습니다. 전체 pytest 267개와 웹 규격·`.cjs`가 통과했습니다.
- Python 빌더·입력·커밋된 데이터 산출물은 기준과 동일합니다. 빌더 변경이 없어 지표 재생성 대신 웹 실행 결과 동일성을 검증했습니다. 신규 웹 작업의 공통 검색·설명 카드 규칙은 [0012](0012-shared-player-search.md)를 따릅니다.
