# 0008. 차트 축 범위는 눈금 간격의 배수

- **상태**: 채택 (2026-10)

## 맥락
Movement Zones 차트의 IVB 축이 −25~30이었습니다. 라벨 있는 눈금은 10인치 간격(−20, −10, …)이라 플롯 아래 테두리가 라벨 없는 선으로 끝났고, 사용자에게는 아래쪽 격자가 잘린 것처럼 보였습니다.

## 결정
- 축 범위를 눈금 간격의 배수로 잡습니다. Movement Zones는 HB·IVB 모두 −30~30, 플롯 영역 크기는 그대로(IVB 1인치당 픽셀만 약 9% 작아짐).
- 축 상수는 `AXIS`에 모으고, 타원 공분산 스케일도 같은 상수(`PX_X`, `PX_Y`)를 씁니다.
- 입력 검증 범위(IVB −25~30)는 데이터 규칙이라 그대로 둡니다.

## 기각한 대안
- 아래 테두리에 −25 라벨 추가: 눈금 간격이 고르지 않게 됩니다.
- 플롯 높이를 늘려 1인치당 픽셀 유지: 차트 전체 크기와 배치가 바뀝니다.

## 결과
- `tests/test_movement_zones_layout.cjs`가 축 범위가 눈금 배수인지, 네 테두리에 라벨 있는 눈금선이 있는지 검사합니다.
