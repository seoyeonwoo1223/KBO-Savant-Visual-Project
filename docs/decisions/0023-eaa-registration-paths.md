# eAA 후속 실험의 등록 경로 분리

**상태**: 채택 (협업 규칙·검사 범위, 운영 모델 변경 없음)

## 맥락

eAA 창구 0005가 기록한 대로 공용 sinker gates에 CL1 절을 추가한 이력이 원래 결과 패키지 manifest와 충돌했다. 역사적 gates를 다시 고쳐 무결성 실패를 감추면 안 된다.

## 결정

`collab/check.py`의 ID별 등록 경로 목록으로 SI1/SUP1/CL1은 역사적 sinker 경로를 유지한다. 후속 EAA-CL*은 claude_review 경로로 분리한다. 등록 SHA에서 지정 경로의 실제 ID 절을 확인하고, 읽기 실패와 미지정 ID는 실패한다. 이 변경은 새 실험을 등록하거나 실행하지 않는다.

## 기각한 대안

- 과거 gates를 복원·수정하거나 manifest를 새 기준으로 교체: 과거 조건과 실패 이력을 보존해야 하므로 기각.
- 모든 gates 파일을 검색해 같은 ID를 허용: 등록 파일의 권위를 약화하므로 기각.

## 결과

역사적 등록은 기존 원격 SHA로 계속 검사한다. 다른 실험군은 실행 전에 별도 등록 경로를 명시해야 한다. 검사기 테스트는 후속 CL 경로와 역사적 CL1 경로, 파일 읽기 실패를 확인한다. 과거 결과 패키지의 전체 재현은 기존 기록의 고정 SHA에서 수행해야 하며 이번 창구 검사는 이를 대체하지 않는다.
