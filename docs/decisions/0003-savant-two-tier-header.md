# 0003. Baseball Savant식 2단 헤더와 단일 페이지 폭 1440px

- **상태**: 채택 (2026-10, PR #41·#42)

## 맥락
도구마다 제목 크기(3.5~5.4rem)·여백·본문 폭(1180~1640px)이 달라 페이지를 옮길 때마다 시작점이 흔들렸습니다. 네이비 바와 홈 큰 제목에 "KBO Savant"가 두 번 나왔고, 일부 페이지 CSS의 bare `header{}`·`nav{}` 규칙이 공통 헤더 높이까지 바꾸고 있었습니다.

## 결정
- 헤더를 두 단으로 나눕니다: 브랜드 줄(로고·KBO Savant·부제, 스크롤 시 사라짐) + 메뉴 줄(상단 고정). 메뉴 줄은 sticky가 부모 범위를 벗어나지 못하므로 `<header>`의 형제 `.site-nav-bar`로 둡니다.
- 모든 도구가 `main.site-main`으로 헤더와 같은 1440px 폭·좌우 여백을 씁니다.
- 제목은 `.page-title`(eyebrow + 영문 h1 최대 36px + 한국어 부제). 브랜드보다 한 단계 작게.
- 홈은 큰 제목 없이 Explore 카드로 시작합니다.

## 기각한 대안
- 한 줄 네이비 바 유지: 홈에서 브랜드가 두 번 나오고 제목과 바가 경쟁했습니다.
- 네이비 바 제거: 도구 간 이동 수단과 브랜드 신호가 사라집니다.
- 페이지별 폭 유지: 왼쪽 시작점이 페이지마다 달라 헤더와 어긋납니다.

## 결과
- 규격은 `scripts/web_contract.py`가 검사하고 `scripts/new_web_tool.py`가 생성합니다.
- 메뉴 줄 아래 회색 선은 사용자 요청으로 제거했습니다(PR #44).
