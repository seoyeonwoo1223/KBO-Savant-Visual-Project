# 0007. Pitch Plot 구속 분포에서 구종 이름 열 제거

- **상태**: 채택 (PR #46)

## 맥락
구속 분포 차트 왼쪽의 구종 이름 열이 폭을 차지해 분포 그래프가 좁았습니다.

## 결정
- 이름 열을 빼고 좌우 여백 15px로 그래프가 카드 폭을 채우게 합니다. 구종은 색으로 구분하고 아래 표와 같은 색을 씁니다.

## 기각한 대안
- 라벨을 그래프 안쪽에 겹쳐 쓰기: 분포와 겹쳐 읽기 어렵습니다.

## 결과
- 비슷한 색의 구종(예: 포심 빨강·투심 진분홍)은 구분이 어려울 수 있습니다. 색 팔레트를 바꿀 때 이 점을 확인합니다.
- `tests/test_pitch_arsenal_layout.cjs`가 행 라벨이 없음을 검사합니다.
