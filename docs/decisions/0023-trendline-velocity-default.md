# 0023 — Trendline 구속은 경기별 원값을 기본으로 표시

**상태: 채택**

## 맥락

전준표의 2026-07-28 포심 평균은 단일 경기 72구에서 153.0km/h, 최근 10경기 224구에서 151.8km/h였다. 이동평균 제목에 경기별이라고만 표시하면 특정 날짜의 단일 경기 구속으로 읽기 쉽다. 해당 최근 10경기는 3월 31일–7월 28일에 걸쳐 당일 상태와 오래전 등판이 섞였다.

## 결정

- 경기별 보기에서 평균 구속은 경기별 원값을 기본으로 한다. 다른 지표는 기존 최근 5경기 기본값을 유지한다.
- 위젯 추가와 지표 변경에 같은 기본값을 적용한다. 구종이나 보기 변경은 선택한 집계를 유지한다.
- 제목에는 경기별 원값·최근 5경기 평균·최근 10경기 평균을 구분해 표시한다. 시즌·월별 제목과 기간 합산은 유지한다.
- 사용자는 기존 집계 선택으로 이동평균을 선택할 수 있다. 구속의 원자료·수식은 변경하지 않는다.

## 기각한 대안

- 모든 지표를 경기별 원값으로 변경: K%·BB% 같은 비율의 적은 경기 표본까지 기본으로 노출한다.
- 구속의 이동평균 선택을 제거: 장기간 추세를 확인할 선택지가 사라진다.
- 날짜만 붙인 경기별 제목 유지: 이동평균을 당일 원값으로 읽는 혼동이 남는다.

## 결과

1440px·390px 브라우저에서 기본 집계, 5·10경기 선택과 제목, 지표 전환, 위젯 추가, 시즌·월별 보기, 가로 넘침을 확인한다. 전준표 사례의 72구/153.0과 224구/151.8을 실제 화면에서 대조한다.
