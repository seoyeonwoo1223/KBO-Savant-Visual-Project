# 0020. 리더보드 열 정렬과 페이지 탐색

**상태: 채택**

## 맥락
정렬 화살표가 열 제목의 중심을 밀어 값과 어긋나 보였고, 고정 높이 표 안에서 세로 스크롤해야 했다. 사용자는 서번트처럼 긴 표와 번호 페이지, 조금 큰 글자, 진한 색 셀의 흰 글자를 요청했다.

## 결정
- 정렬 화살표를 버튼 오른쪽에 별도로 배치해 제목과 값의 중심을 맞춘다. 본문은 .95rem, 제목은 .85rem로 키운다.
- 표 내부의 세로 높이 제한을 없애고 기본 50명씩 표시한다. 하단 번호·이전/다음 버튼, 표시 범위, 50/100/200명 선택을 제공한다. 넓은 통계 표의 가로 스크롤과 선수명 고정은 유지한다.
- 필터링·정렬 후 페이지를 나눈다. 검색·팀·표본·시즌·분류·정렬·페이지 크기를 바꾸면 첫 페이지로 돌아간다. 빈 결과와 마지막 페이지도 범위를 벗어나지 않는다.
- 기존 시즌·분류 전체 표본을 기준으로 한 WAR/oWAR/OAA 색 스케일은 유지하며 가장 진한 빨강은 흰 글자와 충분한 대비가 나도록 조금 어둡게 한다. 배경의 상대 휘도를 계산해 흰색과 진한 글자색 중 대비가 높은 글자색을 고르며 hover에서도 유지한다.
- 썸네일 모드는 기존 limit을 사용하고 페이지 탐색을 숨긴다.

## 기각한 대안
- 전체 선수를 한 번에 무한 스크롤: 사용자가 요청한 번호 페이지 탐색을 제공하지 못한다.
- 모든 통계 열을 화면에 맞게 축소: 글자를 키워 가독성을 높이려는 요청과 맞지 않는다.
- 색의 진하기만 보고 임의의 임계값으로 흰 글자 선택: 빨강·파랑의 휘도가 다르므로 실제 대비를 계산한다.
