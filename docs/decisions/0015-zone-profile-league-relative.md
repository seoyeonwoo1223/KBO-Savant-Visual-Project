# 0015. Zone Profile 색은 칸별 리그 평균 대비 차이

- **상태**: 채택 (2026-10). [0012](0012-zone-profile-color-scale.md)를 대체합니다.

## 맥락
[0012](0012-zone-profile-color-scale.md)의 색은 선수 값 자체(비율은 보이는 칸 최댓값 기준, AVG는 .250 중심)였습니다. 존 밖은 원래 스윙이 적어서 "이 타자가 리그보다 많이/적게 치는 곳"이 색으로 드러나지 않았고, 상한이 선수마다 달라 같은 색이 다른 뜻이었습니다.

## 결정
- `zone_profile.py`가 시즌·대상(타자/투수)별 리그 전체 칸 집계 `web/data/zones/<season>/league/<role>.json`을 만듭니다. 선수 records와 같은 키(볼·스트라이크·(타자만) 투수 손·구종·x/z bin)와 카운터를 써서, 화면의 상대 투수·구종·카운트 필터를 리그에도 그대로 적용합니다. 해당 시즌 분석 대상 투구 전체(이름 없는 선수 포함)를 셉니다. 선수 shard 디렉터리와 분리한 이유는 `write_shards`가 role 디렉터리의 오래된 JSON을 지우기 때문입니다.
- 모든 지표(Swing·Whiff·Contact·In-play %, AVG)에서 각 칸의 리그 값을 흰색, 선수가 높으면 빨강·낮으면 파랑. 범위는 비율 ±20%p, AVG ±.100 (넘으면 끝 색).
- 칸 숫자는 선수 값. 툴팁은 `선수 / 리그 / 차이`와 선수·리그 투구 수. 범례는 차이 기준(−20%p · 0 · +20%p).
- 선수나 리그 어느 쪽이든 분모가 최소 표본 미만이면 회색 빈칸. 최소 표본은 지표마다 따로 기억합니다: 비율 지표 기본 5(구·스윙), AVG 기본 3(타수). 타수는 타석 마지막 공에만 생겨 칸마다 적습니다(홍창기 2026: 타수 408, 70칸 중 34칸이 0타수, 5타수 이상 20칸·3타수 이상 22칸). 1–2타수 칸은 .000/1.000으로 튀므로 3을 기본으로 둡니다. AVG의 회색 칸이 많은 것은 표본 한계입니다.

## 기각한 대안
- 리그 평균을 필터 없이 시즌 전체 하나로 두기: 구종·카운트 필터를 바꾸면 비교 기준이 달라져 오해를 낳습니다.
- 리그 값을 선수 shard마다 넣기: 같은 데이터가 수백 번 반복되어 용량이 커집니다.
- 선수 값 색 유지 + 리그 값만 툴팁: 요청 목적(리그 대비가 한눈에 보임)을 못 채웁니다.

## 결과
- 시즌당 리그 파일 2개(약 0.3–0.55MB, 압축 JSON)가 늘고, 선수를 처음 열 때 한 번 더 내려받습니다(연도·대상별 캐시).
- 흰색은 "리그와 같음"이지 "평균 수준의 좋은 값"이 아닙니다. Whiff %는 빨강이 리그보다 헛스윙이 많다는 뜻입니다.
- `metric_state`가 리그 파일 누락도 재빌드 사유로 봅니다.
