# 0014 — 현재 시즌 리더보드와 공식 주루 갱신

**상태: 채택**

## 맥락

2026 리더보드 생성기가 `_exports()`와 metric state에 연결되지 않아 8월 30일 출력이 남아 있었다. PBP의 주자 상태 변경은 도루·도실 사건을 노출하지 않으므로 이를 추정해서 공식 도루로 표시할 수 없다. 사용자는 OAA를 제외한 현재 시즌 oWAR에 공식 주루를 연결하고, OAA가 있는 완료 시즌은 조건부 서식을 요청했다.

## 결정

- 2026만 현재 시즌 PBP 생성기를 매일 실행 경로와 metric state에 연결한다. 2025와 이전의 완료 시즌 OAA 자료는 보존한다.
- KBO 공식 선수 주루 페이지의 정규시즌·연도 선택을 검증하고 모든 페이지를 수집해 `data/leaderboards/source/2026_running.json`에 저장한다. 공식 선수 ID와 이름이 모두 일치할 때 연결한다. HTTP·열 구조·시즌·페이지 중복 오류는 실패로 처리하며 기존 파일을 교체하지 않는다.
- 기존 소스 워크북 `기본-타자` off 수식의 도루 성공·실패 계수(`연도별 상수` AB46=0.2, AC46=0.4)를 사용해 **단순 도루 추정 득점 = 0.2×SB−0.4×CS**를 더한다. 기존 워크북의 리그 성공률 중립화 항과 추가 진루 가산을 그대로 복제하는 것은 아니다. 완전한 BsR 또는 표준 wSB로 부르지 않고 `도루 득점*`으로 표시한다. oWAR*는 기존 타격·포지션·대체수준 추정 득점에 이 도루 득점을 더한 뒤 기존 runs-per-win으로 나눈다.
- 공식 주루는 해당 시즌 현재 누적값이고 PBP는 게시된 기준일까지이므로 시점 차이가 가능하다고 화면에 명시한다. 미연결은 null/—로 표시하며 도루 보정을 추가하지 않는다. 기존 리그·구장·가중치 상수표는 유지하고 추정치임을 설명한다.
- 중간 합류 선수도 검색할 수 있도록 현재 시즌 리더보드는 1 PA 이상 또는 상대 타자 기록이 있는 선수를 모두 출력한다. 타자 200 PA·투수 50 IP 기준은 삭제 조건 대신 `qualified`와 표본 표시 및 UI 필터로 유지한다. 0이닝의 FIP/WAR는 null로 남긴다. 동명이인의 기본/확장 행은 선수 ID로 연결한다. Pitch Plot은 이미 최소 표본 아래 선수도 포함하므로 생성 기준을 바꾸지 않고 catalog·목록·프로필 fetch의 캐시 재사용을 막는다.
- WAR/oWAR/OAA는 시즌·분류별 전체 표본의 최대 절댓값을 기준으로 0=흰색, 양수=빨강, 음수=파랑을 적용한다. 검색·팀 필터나 hover로 색이 바뀌지 않는다.
- 시즌 catalog는 완료 시즌 게시 계약을 코드에서 재생성하고 출력 JSON을 입력으로 읽지 않는다.

## 기각한 대안

- PBP 주자 이동을 도루로 간주: 폭투·포일·견제·진루와 구분할 수 없다.
- 2026 OAA 또는 추가 진루 가치 추정: 검증 가능한 최신 자료가 없다.
- 공식 페이지의 잘못된 시즌 또는 일부 페이지만 연결: 다른 시즌 혼입과 누락을 방지할 수 없다.

## 결과

공식 주루 입력과 PBP·상수·생성 코드의 변경이 리더보드 재생성을 유발한다. 완료 시즌은 덮어쓰지 않는다. 검사는 `test_leaderboard_running.py`, `test_leaderboard_vb.py`, `test_metric_state.py`, `test_leaderboards_colors.cjs`와 1440px/390px 화면 확인으로 한다.
