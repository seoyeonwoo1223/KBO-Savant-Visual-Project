# 0004. 모바일 Swing/Take 프로필은 데스크톱 레이아웃 이미지로 표시

- **상태**: 채택 (PR #44)

## 맥락
Swing/Take 프로필은 가로로 넓은 한 장짜리 그래픽입니다. 모바일 반응형으로 다시 배치하면 형태가 달라지고 라벨이 넘쳤습니다. Baseball Savant는 모바일에서 같은 프로필을 이미지로 축소해 보여 주고, 사용자는 길게 눌러 저장할 수 있습니다.

## 결정
- 830px 이하에서는 같은 페이지를 화면 밖 1440px iframe에 띄우고, 그 안에서 html2canvas로 `.profile-card`를 캡처해 `<img>`로 보여 줍니다. 실패하면 기존 반응형 DOM을 둡니다.
- "프로필 이미지 저장" 버튼도 좁은 화면에서 같은 방식으로 데스크톱 레이아웃을 저장합니다.
- 반응형 DOM의 % 라벨은 반쪽 영역 안으로 제한합니다(이미지가 뜨기 전·실패 시 대비, PR #48).

## 기각한 대안
- html2canvas `windowWidth` 옵션으로 현재 문서를 데스크톱 폭에서 캡처: 가상 요소(`::before`)를 원본(모바일) 문서의 계산값에서 복사해 모바일 라벨이 섞였습니다.
- CSS `transform: scale()`로 축소: 이미지로 저장할 수 없고, 래퍼 높이 계산이 필요합니다.

## 결과
- 캡처 대상 CSS에 최신 색 함수를 쓰지 않습니다([0005](0005-no-modern-css-color-in-capture.md)).
- 페이지를 열면 1~2초 반응형 화면이 보였다가 이미지로 바뀝니다.
