# 단일 eAA-v3와 별도 비대칭 참고 범위

**상태: 채택 — 사용자가 실제 Pitch Plot 배포를 요청함.**

## 맥락

eAA는 실제 KBO 팔각도나 실제 연도별 변화를 측정하는 값이 아니라 시즌 대표 팔각도 추정치다. 기존 수치 모델은 MLB 고슬롯에서 과소 추정하는 경향이 있었다. 영상·사진을 선수별로 처리하지 않고 이 경향을 줄이는 것이 목표다.

## 결정

- 고정된 [eAA-v3 모델](../../data/models/estimated_arm_angle_v3.json)을 우선 사용한다. 55ft 기준 기하·속도·방향·비행 시간, 50ft 기준 무브먼트 방향·크기, 확인된 선수 신장을 공통 MLB/KBO 정의로 집계한다. 이 좌표는 릴리즈 순간의 어깨 위치를 직접 측정한 값이 아니다.
- 입력은 특징별 상·하위 10% 절사평균이다. 학습은 투수별 시즌 수의 역수에 실제 60° 이상 표본의 4배 가중을 적용한 2차 Ridge 회귀다. 모델 선택은 MLB 학습 투수 안에서 수행했으며 KBO 선수 참고값·SSG 각도·이미지는 사용하지 않았다.
- 화면에는 단일 시즌 eAA와 별도 비대칭 모델 참고 범위를 표시한다. 범위는 MLB 방향별 잔차 보정과 입력 시나리오를 합친 것으로 KBO 신뢰구간이나 외삽 오차 상한이 아니다. 점 추정을 범위 중간값으로 바꾸지 않는다.
- 포심 표본이 부족하면 기존 [v1 모델](../../data/models/estimated_arm_angle_v1.json)로 대체한다. 소표본·신장 미확인·궤적 품질 미달과 학습 범위 밖의 상태를 유지한다. v3 파일이 없는 환경은 [v2 모델](../../data/models/estimated_arm_angle_v2.json)을 사용할 수 있다.
- 2026년 측정 기준 전환의 상대 보정은 eAA 입력에만 적용한다. canonical 원자료와 화면의 HB·IVB 정의를 바꾸지 않는다.

## 기각한 대안

- 중앙값·경기별 가중평균을 일괄 채택: 동일 선형 모델의 집계 비교에서 뚜렷한 개선이 없었다. 절사평균만으로 고슬롯 문제가 해결된다고 주장하지 않는다.
- KBO 참고 각도에 맞춰 보정: 비교 장비·기간이 불완전하고 독립 검증을 잃는다.
- 영상 모델을 필수로 사용: 추정 지표를 원하는 사용자 목표와 수작업 제약에 맞지 않는다.
- 높은 예측에 임의로 위쪽 폭을 추가: 실제 고슬롯 조건의 편향과 높은 예측 조건의 잔차는 다르다. 이번 각도별 오차 회귀는 기울기 0을 선택해 전역 비대칭 폭을 사용한다.

## 결과와 검증

투수 단위 중첩 평가에서 실제 60° 이상 57시즌·35명의 평균 절대오차는 6.48°에서 5.09°, 평균 편향은 −6.02°에서 −2.94°로 줄었다. 전체 시즌 평균 절대오차는 3.81°에서 3.89°로 소폭 증가했으며 전체 정확도 개선을 주장하지 않는다. 별도 2024년 196명에서 오차는 3.69°이고 대칭·비대칭 범위 모두 179/196을 포함했다. 높은 각도와 KBO의 범위 포함률은 보장하지 않는다.

검사는 `tests/test_arm_angle_aggregation.py`, `tests/test_arm_angle_reference.py`, `tests/test_estimated_arm_angle_numeric.py`, `tests/test_estimated_arm_angle_robust.py`, `tests/test_eaa_movement_calibration.py`, `tests/test_pitch_arsenal_layout.cjs`에 있다. 고정 모델·공통 집계·범위 코드의 변경은 `metric_state`가 재생성을 요구하고, 모델 파일 변경도 Daily 워크플로에서 산출물 재생성을 시작한다.
