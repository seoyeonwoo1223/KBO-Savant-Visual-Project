Batter Search

What is this?

타자가 공마다 스윙하거나 지켜본 선택이 득점에 얼마나 도움이 됐는지 Run Value로 보여 줍니다. 선수를 고르면 Heart·Shadow·Chase·Waste 위치별 스윙·테이크 Run Value와 연도별 비교가 담긴 프로필로 이동합니다.

Run Value = Σ[Raw Run Value − 리그 평균 Run Value(볼카운트, 상대 위치)] · 양수일수록 타자에게 유리합니다. 시즌 300구 미만 타자는 표본 미달로 표시합니다.
