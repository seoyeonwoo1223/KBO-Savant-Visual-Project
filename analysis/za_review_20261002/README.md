# ZA 재설계 교차검증

검토 기준 커밋: `f0dc0a44367852cc1aea86d8eb24dcdb1a19d413`.

이 폴더는 논의·독립 검증 자료다. 운영 소스, 공개 산출물, 기존 판정 기준을 변경하지 않았다. 신규 후보의 성능은 계산하지 않았다. 외부 ZJ 원자료는 포함하지 않는다.

## 검토 의견

현재 목적에는 현행 Z0 유지가 가장 잘 맞는다. APR은 선택의 득점 가치, ZA는 판정에 맞는 선택의 리그 기대 대비 초과분, SA는 스윙 성향으로 구분한다. 서로 다른 구성 개념을 측정한다는 뜻이며 통계적 독립을 요구하지 않는다.

존 밖 스윙을 강조하는 설명은 존 안 초과 스윙과 존 밖 초과 억제를 별도로 표시하는 것이 가장 명료하다. 단일 점수를 바꾸려면 ΔV를 사용하지 않는 고정 거리 후보 하나를 새로 사전 등록하는 것이 적절하다. 초안은 [Z-e-draft.md](Z-e-draft.md)에 있다. 운영 반영을 결정한 문서는 아니다.

N5는 저장된 하네스 결과와 선택 코드상 기존 Z-d 추천안이다. 기존 기준을 사후 변경하거나 그 판정 기록을 뒤집지 않는다. 다만 외부 모집단 구현과 문서 정의의 차이 때문에 문서상 ZG4까지 정확히 검증되었다고 단정하지 않는다.

## 1. 존 안·밖 상수 가중의 대수

타자별 평균을 E_i, r=S−p_swing, m_i=E_i[r], x=r−m_i, z=2p_zone−1로 정의한다.

이진 존 z∈{−1,+1}에서는 E_i[x]=0이므로:

    Σ_in x − c Σ_out x = (1+c) Σ_in x

α=(1+c)/2, β=(1−c)/2, 리그 전체 가중 평균을 D_c라 하면 중립 점수는:

    N_c,i = α N0_i / D_c

같은 c와 리그 공통 정규화를 쓰면 순위가 정확히 같다. 타자별 정규화를 하는 경우에는 이 결론을 그대로 적용할 수 없다.

중립하지 않은 이진 점수는:

    Q_c,i = (α Z0_i + β SA_i) / D_c

c>1이면 SA 계수가 음수다. 다만 다른 공분산과의 상쇄 때문에 실제 SA 상관의 절댓값이 반드시 커지는 일반 정리는 아니다.

연속 판정 확률에서는 정확식이 다음과 같다.

    N_c,i = [α N0_i + 100 β Cov_i(r, |z|)] / D_c

Σx=0이어도 Σx|z|=0은 보장되지 않는다. 판정 확신도와 초과 스윙의 공분산이 남는다. x=(0.5,−0.5), A의 z=(0.9,−0.1), B의 z=(0.4,−0.4)라는 반례에서는 c=1 점수 A=0.25>B=0.20, c=3 점수 A=0.30<B=0.40이다. 정규화와 재중심화는 이 반전을 없애지 않는다.

실제 CSV 재계산에서도 N0와 N1은 완전히 같지 않았다. 2019–2023 Spearman은 0.99850–0.99904, 2024–2026은 0.99986–0.99991이다. 최대 순위 이동은 구심 시즌 7–10계단, ABS 시즌 3–4계단이다. 따라서 gates.md의 완전 동일 순위 주장은 근사 설명으로 한정해야 한다.

## 2. 거리·확신도·성분 분리

N2·N3·N4는 |E[ΔV|칸]|이고 N5·N6는 E[|ΔV||칸]이다. 두 연산은 부호 상쇄에서 차이가 난다. 모두를 같은 |ΔV| 가중이라고 부르면 부정확하다.

N3는 순수 거리 가중이 아니다. 2025 가중은 heart 0.952, shadow_in 0.792, shadow_out 0.579, chase 1.249, waste 1.618이다. 신뢰도는 0.829로 Z0의 0.817보다 높지만, 저장된 다음 시즌 BB% 상관은 0.224로 Z0의 0.276보다 낮고 외부 상관도 낮다. 따라서 잡음으로 신뢰도가 낮아졌다는 설명은 맞지 않는다.

가능한 원인은 카운트를 합친 구역 평균, 경계 판단의 축소, 선수별 보정항 −m_i E_i[wz]의 변화다. 예를 들어 N4의 2025 shadow_in 가중은 0스트라이크 0.225, 2스트라이크 2.294다. 먼 바깥쪽에서는 대부분 이미 참으므로 큰 무게가 새 구별 정보를 적게 추가할 가능성도 있다. 각 원인의 기여율은 분리하지 못했다. N3 실패로 순수 고정 거리 후보를 기각할 수는 없다.

현행 z는 이미 sign(z)|z|이므로 판정 확신도를 한 번 반영한다. |z|를 추가로 곱하면 z|z|가 되어 확실한 판정을 더 강조하는 새로운 목표가 된다. |z|는 판정 확률이 0.5에서 떨어진 정도이지, 시드 간 변동 같은 모델 추정 불확실성이 아니다.

설명용 별도 성분은 다음처럼 둘 수 있다.

    C_in  = 100 E_i[r | p_zone≥0.5]
    C_out = −100 E_i[r | p_zone<0.5]

각각 리그 기대보다 안쪽을 더 친 정도, 바깥쪽을 더 참은 정도다. 각 성분에는 공격성의 영향이 있으므로 SA와 함께 읽어야 한다. 두 성분을 임의의 1:c로 합치면 기존 혼입 문제가 다시 생긴다.

## 3. N0의 SA 상관 증가

원시 점수는 다음 관계를 갖는다.

    N0_i = Z0_i − SA_i z̄_i = 100 Cov_i(r,z)

이는 선수 내 일정한 초과 스윙 성향에 대한 불변성을 보장하지만 선수 간 SA 무상관을 보장하지 않는다. z̄_i<0이면 보정항 −SA_i z̄_i가 양의 SA 성분을 더할 수 있다.

|SA|≥0.2인 선수에서 원시 CSV로 z̄_i=(Z0_i−N0_i)/SA_i를 역산했다. 작은 SA를 제외한 이유는 소수 넷째 자리 반올림 오차의 확대를 막기 위해서다.

| 시즌 | Z0–SA ρ | N0–SA ρ | 역산 z̄ 중앙값 |
|---|---:|---:|---:|
| 2019 | +0.079 | +0.156 | −0.032 |
| 2020 | +0.068 | +0.183 | −0.052 |
| 2021 | +0.138 | +0.246 | −0.069 |
| 2022 | −0.027 | +0.041 | −0.029 |
| 2023 | +0.071 | +0.143 | −0.043 |
| 2024 | +0.071 | +0.067 | −0.003 |
| 2025 | +0.017 | +0.011 | −0.001 |
| 2026 | +0.142 | +0.158 | −0.008 |

2021의 보정항 SA 기울기는 +0.06670, 공통 평균 존 방향 성분은 +0.06763, 선수별 구성 잔차 성분은 −0.00093이다. 이 선형 공분산 분해에서는 음의 평균 존 방향 효과가 대부분을 설명한다. Spearman 상관 변화의 직접 분해는 아니다.

이진 존에서 존 안 비중을 π_i라 하면:

    N0_i = 200 π_i(1−π_i)(r̄_in,i − r̄_out,i)

투구 구성 표준화와 m_i 제거는 별개다. 구심 시즌은 일관되게 양의 방향으로 움직이고 2024·2025에는 조금 줄었으므로, 일률적인 과보정이나 시즌별 부호 반전을 주원인으로 단정하지 않는다.

## 4. APR과의 겹침 및 기존 결론 검토

후보 CSV와 공개 APR을 새로 대조했다. 아래 값은 시즌별 Spearman의 단순 평균이며, 타자 자료를 합친 상관이 아니다. 기준 커밋의 2026 curated 자료 마감은 9월 29일이다.

| 후보 | 8시즌 평균 | 구심 2019–2023 | ABS 2024–2026 |
|---|---:|---:|---:|
| Z0 | 0.625 | 0.612 | 0.649 |
| N0 | 0.592 | 0.555 | 0.653 |
| N1 | 0.591 | 0.553 | 0.653 |
| N2 | 0.812 | 0.767 | 0.887 |
| N3 | 0.565 | 0.536 | 0.612 |
| N4 | 0.793 | 0.748 | 0.867 |
| N5 | 0.721 | 0.673 | 0.801 |

- (a) 가치 구조 유입이라는 기제에는 동의하지만 단일 원인·단조 관계에는 동의하지 않는다. 이진 존 방향과 ΔV 부호가 같으면 2rΔV=2rz|ΔV|이다. 그러나 중립 후보는 r−m_i, APR은 r을 쓰며 APR에는 타자별 수축이 있다. N3 상관은 Z0보다 낮고, 더 세밀한 N4 상관은 N2보다 낮다.
- (b) BB%·X4와 APR 겹침의 동반 증가는 확인되지만 같은 원천이라는 인과 단정은 보류한다. 가치·카운트·투구 구성 효과를 분리하지 않았다. X4는 ISO를 통제하며 APR은 통제하지 않는다.
- (c) 어떤 공식도 ABS에서 크게 겹친다는 주장은 과하다. Z0의 ABS 평균 상승은 작고 2026 상관 0.584는 2019의 0.673보다 낮다. ABS p_zone과 DV 사건 모델은 별도 입력과 예측을 쓰므로 ΔV 부호와 존 방향의 일치는 강제되지 않는다. 운영 투구별 부호 일치율은 재계산하지 못했다.
- (d) 역할 분리와 현행 유지에는 동의한다. ZA에도 카운트를 조건으로 한 리그 정책은 들어 있지만 카운트별 득점 가중은 없다. 자연스러운 상관은 설명으로 다루고, 새 설계의 겹침 증가를 채택 기준으로 제한한다. APR을 회귀해 빼면 정확도가 아니라 APR로 설명되지 않는 잔차가 된다.

현행 ZA의 정확한 설명은 같은 투구 조건의 리그 정책 대비 기대 판정 일치율 차이(%p)다. 객관적인 존 인지 능력이나 개인별 최적 득점 판단을 직접 측정하는 것은 아니다.

## 5. 기존 기준과 외부 비교의 해석 한계

ZG8의 후보 점추정≥N4 개별 CI 하한은 등록된 선택 규칙이다. 후보−N4의 짝지은 차이 CI와 사전 허용폭 없이 통계적 비열등성을 증명하지 않는다. 기존 규칙을 바꾸지 않고 해석을 제한한다.

저장된 외부 Spearman은 Z0 0.69015, N5 0.70050이다. 백분위 MAE는 18.251→18.490이다. 상관 기준의 통과를 외부 정확도 전반의 개선으로 확대하지 않는다. 외부 원자료가 없어 이 수치는 새로 검증하지 못했다.

외부 자격 집합은 하네스에서 PA≥e.game_id.nunique()×2/10으로 만든다. 이는 팀당 평균 경기수이며 gates.md의 PA≥실제 팀 경기수와 부분시즌에는 다를 수 있다. 기준 모집단의 차이는 외부 백분위에 직접 연결된다. 영향은 미측정이며 기존 통과 판정을 반대로 결론 내릴 근거도 없다.

비용 가중은 시즌 전체에서 추정한 뒤 반분·날짜 마감 표본에 적용한다. 따라서 날짜 마감 외부 비교에는 마감 이후의 리그 가중 추정 정보가 들어간다. 고정 거리 가중의 새 실험에서는 마감 표본만으로 정규화하고 Z0도 같은 모집단에서 재계산하도록 제안한다.

## 검증 범위와 재실행

읽은 순서는 gates.md의 관련 절 → zb/zd 하네스 → 두 결과 JSON → 운영 ZA 경로였다. curated 자료는 summary.json → schema.json 순서로 확인했다. partition-index.json은 읽지 않았다. 계산 입력은 명시한 Git 파일 경로에서만 읽는다.

독립 계산 입력은 기준 커밋의 정확한 Git 객체다. 후보 CSV·공개 리더보드·산식으로 대수와 상관을 검증한다. 투구별 전체 재현, 반분 신뢰도, BB%·X4 부트스트랩, 외부 47점은 이번 재실행 범위가 아니다. 신규 후보 성능도 계산하지 않는다.

저장소 루트에서 Python 3.12와 constraints-za.txt의 여섯 패키지 버전을 사용한다(스크립트가 버전 일치를 assert한다).

```bash
PYTHONPATH=src OMP_NUM_THREADS=2 python analysis/za_review_20261002/check_za.py
```

PowerShell에서는 `$env:PYTHONPATH = 'src'; $env:OMP_NUM_THREADS = '2'`를 먼저 설정한다.

검증 스크립트의 종료 상태는 0이다. 이진 중립 항등식·SA 혼합식·연속 분해식과 순위 반전 반례를 실제 계산했다. 8시즌 적격 타자 집합이 같았고 Z0·SA의 최대 공개 점수 차이는 각각 0.000050%p로 CSV 반올림 범위 안이었다. Z0·N4·N5의 재계산 APR 상관은 저장 JSON과 수치 정밀도 범위에서 일치했다.

파일:

- check_za.py: 고정 커밋을 입력으로 읽는 독립 계산 및 대수 검증.
- checks.json: 실제 계산값, 환경, 입력 SHA-256, 검증 한계.
- sources.json: 계산 근거를 구조화한 자료.
- Z-e-draft.md: 결과 계산 전에 고정할 신규 실험 초안.
- counter-review.md: 이 검토에 대한 반론 메모(Z-e 미등록, 운영 결론은 Z0 유지).

checks.json에는 실행 환경에 따라 바뀌는 값(파이썬 패치 버전, 로컬 캐시 상태)을 기록하지 않는다. 같은 기준 커밋이면 어느 체크아웃에서 실행해도 같은 파일이 나온다. 로컬 화면용 sources.html과 실행 로그는 커밋 대상에서 제외한다.
