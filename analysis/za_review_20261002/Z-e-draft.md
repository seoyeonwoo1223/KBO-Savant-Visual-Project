## Z-e. 가치 비사용 존 밖 거리 가중 ZA — 실행 전 등록 초안

### 배경과 목적

Z·Z-b·Z-c·Z-d 결과를 본 뒤 설계한 신규 실험이다. 기존 기준과 판정을 변경하지 않는다. 신규 후보의 성능을 계산하기 전에 후보식, 표본, 문턱, 선택 규칙을 고정한다. 이 문서는 초안이며 신규 후보의 통과를 선언하지 않는다.

APR은 현행으로 유지한다. ZA가 APR과 다른 판단 측면을 보여주면서 먼 존 밖 스윙을 더 크게 평가할 수 있는지 검증한다. 가중의 정의·추정·튜닝에는 ΔV, APR, 선수 결과 지표, 외부 ZJ를 사용하지 않는다.

### 후보와 대조

r=S−p_swing, z=2p_zone−1, m_i=mean_i(r)로 정의한다. p_swing·p_zone·적격 투구는 운영 za7.6-apr과 동일하게 고정한다. 채택 평가 후보는 E1 하나다.

    h = 1 + 0.5 I(p_zone<0.5 AND region=chase)
          + 1.0 I(p_zone<0.5 AND region=waste)
    w = h / mean_league(h)
    E1_i = 100 mean_i[w(r−m_i)z] − μ_league

μ_league는 같은 평가 표본의 전 투구 점수 평균이다.

- 모델상 존 안인 공은 region에 관계없이 가중 1이다.
- 모델상 존 밖 중 chase는 1.5, waste는 2이며 나머지는 1이다.
- 1·1.5·2는 객관적인 득점 비용이 아니라 거리 강조의 설계 강도다.
- region은 기존 앞면 상대 좌표 기반 구분이다. ABS 실제 판정면의 정확한 거리라고 부르지 않는다.
- E1은 가중 판단 잔차다. 현행의 비가중 기대 정확도 차이와 같은 의미라고 설명하지 않는다.
- 대조는 Z0와 N0다. E1이 미달해도 다른 가중 강도나 확신도 후보로 자동 대체하지 않는다.

### 표본과 재현 확인

- 대상: 2019–2026. 2026 마감일을 실행 전에 고정한다.
- 시즌 적격은 300구, 반분 적격은 각 반쪽 150구 이상이다.
- m_i, 가중 정규화, 리그 재중심화는 평가 표본 안에서 다시 계산한다.
- 외부 날짜 마감 평가에는 마감 이후 자료를 사용하지 않는다.
- 대조 Z0·SA가 운영 투구 근거에서 재현되는지 확인한다. 모델·투구 자격·자료 버전이 일치하지 않는 시즌은 판정에 쓰지 않는다.
- 외부 모집단은 기존 ZG4대로 PA≥실제 팀 경기수다. 원사이트의 팀·트레이드 처리와 경기 마감 정의를 확인하여 실행 전에 고정한다. 정의가 확인되지 않으면 해당 외부 검증을 미측정으로 둔다.
- Z0·N0·E1은 같은 마감일과 모집단에서 다시 계산한다. 기존 JSON의 Z0 외부 집계값을 새 표본의 기준값으로 대신 쓰지 않는다.

### 필수 기준

ZG1–ZG5의 기존 정의와 문턱을 재사용한다.

| ID | 항목 | 문턱 |
|---|---|---|
| ZG1 | 경기 홀짝 반분 Spearman-Brown 신뢰도, 반쪽 150구 이상, 8시즌 평균 | ≥0.75 |
| ZG2 | 시즌별 Spearman(E1, SA), 적격 타자 | 모든 시즌 절댓값 ≤0.30 |
| ZG3 | 리그 투구 가중 평균 | 모든 시즌 절댓값 ≤0.10%p |
| ZG4 | 외부 ZJ Spearman, 동일 마감·모집단 | 같은 조건에서 재계산한 Z0보다 큼 |
| ZG5 | 다음 시즌 BB% Pearson, 기존 시즌 쌍·150타석·시즌 중심화 | 같은 표본의 Z0 이상 |
| ZE1 | APR 겹침 증가 제한 | 모든 시즌 abs(ρ(E1,APR))−abs(ρ(Z0,APR))≤0.03 |
| ZE2 | APR 겹침 절대 상한 | 8시즌 평균 abs(ρ(E1,APR))≤0.70 |
| ZE3 | 일정한 초과 스윙 성향에 대한 불변성 | 타자별 r에 상수를 더한 합성 검증에서 점수 변화 <1e−10 |

ZE1의 0.03은 역할 보존을 위한 허용 증가폭, ZE2의 0.70은 절대 상한이라는 정책이다. 통계적 독립성이나 유의성의 보편적 경계라고 해석하지 않는다. 현재 Z0 수준에서는 ZE1이 더 강한 제한일 수 있다. ZE3는 선수 내 불변성이며 선수 간 SA 무상관의 증거가 아니다.

### 보고 항목

- 기존 ZG6: X4 계수·95% CI와 시즌 간 상관.
- 같은 타자 부트스트랩을 사용한 E1−Z0의 APR 상관 차이 CI.
- 다음 시즌 BB% 상관 차이 CI와 외부 백분위 MAE.
- 구심·ABS별 APR 상관, 시즌별 최대 순위 이동.
- 존 안 비중·2스트라이크 비중·구역 구성과의 상관.
- N0 대비 변화와 존 안·밖·거리 구역별 점수 기여.
- APR 통제 후 결과 연관성은 독자 정보의 탐색 진단으로만 보고한다.

개별 후보 X4 CI 하한과 다른 후보 점추정의 비교로 통계적 비열등성을 주장하지 않는다.

### 선택 규칙

1. E1이 ZG1–ZG5와 ZE1–ZE3을 모두 충족하면 운영 변경을 논의할 추가 검토 후보로 추천한다.
2. 하나라도 미달하면 현행 Z0를 유지한다.
3. 외부 원자료나 모집단 정의가 없어 ZG4를 계산할 수 없으면 미측정으로 표시하고 전체 통과를 선언하지 않는다.
4. 결과를 본 뒤 가중·구역·표본·문턱을 바꾸려면 별도 새 절로 등록한다. 바뀐 후보를 Z-e 사전 등록 통과라고 부르지 않는다.
5. 외부 ZJ 원자료는 저장소에 넣지 않는다. 분석에서는 src/, web/, 공개 산출물을 변경하지 않는다.
