## 1. 프로젝트와 최종 목표

- 저장소: https://github.com/seoyeonwoo1223/KBO-Savant-Visual-Project
- 현재 작업 경로: `/workspace/KBO-Savant-Visual-Project`. 다른 환경이라면 실제 경로부터 확인해라.
- 목적: LG 제공 2019–2024 TrackMan 릴리즈 좌표·익스텐션·회전수와 KBO 공개 Visual Baseball(VB) 궤적으로 투수의 **추정 암슬롯**을 만들고, TrackMan이 없는 광주 및 2025–2026으로 확장하며, Y2Y 변화도 살펴보는 것.
- 사용자 결정: `eAA = Estimated Arm Angle(추정 암슬롯)`. Savant의 **릴리즈 순간 투구 어깨–공 선과 수평선의 정면 각도**를 목표로 한다. 0°는 수평, 90°는 수직 위, 어깨보다 낮으면 음수다.
- 정의: `degrees(atan2(z_ball-z_shoulder, abs(x_ball-x_shoulder)))`. 3D elevation, 팔꿈치 관절각, 몸통 기준 상완 각도와 구분한다.
- 제품: Pitch Plot에 **투수·시즌 대표 eAA 하나**, 회색 점선 하나, 별도 모델 참고 범위를 표시한다. 구종별/투구별 암슬롯은 아직 제품화하지 않았다.
- 핵심 문제: 사용자가 여러 투수의 eAA가 다소 낮다고 느낀다. 안우진·전준표의 외부 전언과도 차이가 있으나 같은 정의의 검증된 KBO 각도 라벨이 없다. 현재 목표는 이 현상의 원인을 식별하고, 실제 정확도 검증이 가능한 최소 데이터·실험을 정하는 것이다.

## 2. 완료된 데이터·모델·제품 작업

1. TrackMan 원본 1,793,078구에서 양팀이 KBO 1군인 1,189,400구를 구분했다. 2군/군 팀을 섞지 않았다. 실제 TM 좌표는 `rel_height`, `rel_side`, `extension`을 m로 해석했다. export의 제조사 datum 계약은 별도 확인이 남아 있다.
2. KBO 공식 프로필에서 신장과 선수 ID·이름을 대조해 **736명**의 신장을 확보했다. 출처·원문 SHA-256·수집 시점을 보존했다. 신장은 조회 시점 성인 프로필 값이며 시즌별 측정 신장은 아니다. 이름 불일치 선수를 강제로 연결하지 않았다.
3. 공식 MLB Savant 팔각도·공/어깨 좌표와 MLB 신장을 확보했다. 초기 연구는 602명·1,295개 시즌의 투수 단위 5-fold 평가였다. 신장 포함 기하 모델 MAE 4.76°, 릴리즈만 사용 5.19°. 이 초기 전체 재학습 모델과 아래 배포 v1은 다르다.
4. VB 55ft 궤적 좌표를 TM 실제 릴리즈 좌표로 연결하는 모델을 만들었다. 연구용 유효 TM/VB 쌍 **1,112,517구**, 실제 학습 단위는 투수·경기 평균이다.
5. **2022–2026의 1,178개 투수·시즌** eAA를 생성하고 Pitch Plot에 연결했다. 모든 시즌에 같은 고정 모델을 사용한다. 유효 100구 미만·입력 범위 초과·신장/투구 손 미확인은 값을 보류한다.

### 현재 생산 eAA-v1 경로

`canonical VB → 55ft 좌표 정규화 → VB→TM 선형 연결 → MLB 팔각도 회귀 → overall.eaa → Pitch Plot`

- 연결 입력: 신장(m), 팔 쪽 x55(m), z55(m), `dx/dy`, `dz/dy`. `StandardScaler → Ridge(alpha=10)`.
- 각도 입력: 신장, 신장 대비 실제 릴리즈 높이·팔 쪽 좌우 위치, 투구 손. `2차 다항 → StandardScaler → Ridge(alpha=10)`.
- 연결: 2019–2023 투수를 60/20/20 train/calibration/test로 분리하고 2024 전체를 시간 외삽 평가로 제외했다. MLB도 투수 단위 60/20/20이다. 한 투수의 시즌은 분리되지 않는다. 생산 계수는 train만 학습한 상태로 고정했다.
- 핵심 파일: `src/visualbaseball/estimated_arm_angle.py`, `src/visualbaseball/vb_arm_angle.py`, `data/models/estimated_arm_angle_v1.json`.
- **현재 모델은 어깨 높이·좌우 위치를 직접 추정하거나 고정하지 않는다.** 이를 입력으로 관측하지 않은 회귀 모델이다. “어깨 높이를 몇 cm 높게 잡았다”라고 단정하지 마라.

### 검증 수치와 불확실성의 의미

- 연결의 제외 투수 테스트 각도 차이 MAE **0.93°**, 제외 2024 MAE **0.70°**. 기준은 TM 좌표를 같은 MLB 각도 모델에 넣은 값이다. **실제 KBO 암슬롯 MAE가 아니다.**
- 2024 좌표 좌우 MAE 3.69cm, 높이 MAE 1.03cm, 좌우 편향 −3.68cm가 남는다.
- 고정 MLB 각도 모델의 독립 test MAE **4.43°**. 초기 5-fold 4.76°와 표본/절차가 달라 개선량으로 비교하지 않는다.
- calibration 투수의 모든 시즌 중 최대 절대오차로 90% 모델 참고 반경을 계산했다. MLB **12.00°**, 연결 **2.23°**, 조건을 통과한 관측 구장 표본에서 합 **±14.23°**를 사용한다.
- 이 합은 **KBO 90%/95% 신뢰구간·예측구간이 아니다.** 두 90% 성분의 합도 자동으로 전체 90%가 되지 않는다. 시즌별 포함률과 투수의 모든 시즌을 덮는 그룹 포함률을 구분해라.
- 광주·새 대전·보조 구장 등 미학습 구장이 포함되면 시즌의 유한 참고 범위를 보류한다. 추정점·플래그는 남을 수 있다. 2025–2026은 TM 학습기 밖의 적용 연도이며 실측 정확도 미검증이다.
- 2026 `source_y0`는 50ft에서 55ft로 바뀌었지만 공통 55ft로 변환했다. 전환 전후 공통 투수×구장×구종의 평균 변화는 실제 동작/시기 변화와 혼재하므로 장비 보정량으로 사용하지 않았다.
- Y2Y는 같은 모델의 시즌 차이와 공통 구장·동일 가중치 차이를 제공한다. 구종·부상·구속·기간·장비를 모두 통제한 실제 동작 변화라고 주장하지 않는다.

## 3. 이미 시험한 추가 변수와 ODE

### 회전축 ODE

- 2019–2024 매칭 자료에서 실제 릴리즈 평면부터 플레이트까지 시간을 재계산하고, SI 단위 항력·중력·마그누스 ODE를 적용했다.
- 시간은 VB 궤적 계수에서 역산한 값이다. 독립적으로 측정한 flight time이 아니다. VB 원본 시간은 50/55ft 평면부터라 그대로 릴리즈 시간으로 쓰지 않았다.
- RPM·HB·IVB·도착 구속에 항력계수·유효 회전 비율·유효 축을 맞췄다. **자이로 성분 0을 둔 유효 횡회전 축**이며 실제 전체 3D 회전축이나 광학 spin efficiency를 유일하게 복원한 것이 아니다.
- 같은 관측값으로 맞춘 작은 잔차, 같은 VB 계수에서 나온 플레이트 y 진단은 독립적인 물리 정확도 검증이 아니다. TrackMan의 HB/IVB 내부 정의와 “같은 시간 무회전 그림자 경로” 정의의 일치도 미확인이다.
- 포심 100구 이상 958개 시즌 수치 수렴, 최종 물리 조건 동시 통과·회전 비율 상한 미도달 689개. 추가 특징 연구 추정값은 조건·학습 범위 통과 667개다.
- ODE 축과 HB/IVB 직접 축 차이 중앙 **0.077°**. 새로운 어깨 정보를 얻기보다 기존 힘 방향을 물리적으로 점검하는 역할일 수 있다.
- MLB 같은 522명·1,111개 시즌, 동일 투수 fold: 기하 MAE **4.64° → 유효 축 추가 3.98° → 축·RPM·구속 추가 3.85°**.
- KBO 연구값은 같은 표본 기하 기준보다 변화 중앙 **−2.01°**. 과소 추정 해결을 입증하지 못했다. 여기서 비교 기하 모델도 생산 v1과 동일하지 않다.
- 광주·2025–2026에 대응하는 실측 TM RPM/익스텐션을 임의로 채우지 않았다. VB 힘 방향을 사용하려면 TM 유효 축과의 별도 연결·구장/연도 분리 검증이 필요하다.

### 익스텐션·발사각·분산·구종 구성

- 공식 Statcast 2020–2024 2,103,117구를 수집하고 목표/후보가 함께 유효한 공통 투구에서 비교했다.
- 같은 표본 기하 모델 MAE: 기본 **4.76°**, 익스텐션/신장 **4.37°**, 수직·수평 발사각 4.56°, 릴리즈 분산/공분산 4.72°, 구종 구성 4.82°.
- 회전 포함 같은 표본 기본 **3.85°**, 익스텐션 추가 **3.76°**. 이 추가 개선의 bootstrap 95% 구간은 −0.005–0.188°로 0을 포함한다.
- 후보 선택은 학습 내부에서 수행한 중첩 검증도 실시했다. 높은 슬롯 표본은 적고 별도 test에는 60° 이상이 0개다. 전체 MAE만으로 높은 슬롯 검증을 주장하지 마라.
- KBO 익스텐션 추가 연구값 변화 중앙은 기하 기준 대비 **−3.00°**, 회전 포함 대비 **−1.00°**. 생산 v1과 직접 비교한 수치가 아니다.
- 익스텐션은 팔 길이가 아니며 보폭·몸통 전진을 포함한다. 어깨의 전후 위치 없이 정면 각도나 실제 팔 길이로 치환하지 마라.
- 전체 MLB 평균 편향이 거의 0이어도 높은 슬롯은 과소 예측한다. “모든 각도에 +10°”나 참고값에 맞춘 유형별 보정은 시행하지 않았다.

- 김광현은 릴리즈 전 정지 화면에서 팔로스루로 넘어가는 편집, 윤현은 측면/사선 투영이라 정면 각도 집계에서 제외했다. 진단용 화면 각도 55.09°/83.51°를 실제 암슬롯으로 쓰지 마라.
- 안우진·임찬규·원태인의 선택 영상은 릴리즈 때 어깨와 공이 함께 보이지 않아 값을 보류했다.
- 촬영 날짜·개별 투구 매칭·중복 투구 여부는 일부 미확인이다. 파일명 연도를 확정 메타데이터로 취급하지 마라. GIF 재생 시간을 촬영의 물리 시간으로 쓰거나 반복 화면을 독립 투구로 세지 마라.
- 현재 영상값은 학습 라벨이나 생산 eAA 교체에 사용하지 않았다. 보정된 실제 Savant 각도 생성 수는 0이다.

### 외부 참고값의 상태

- 안우진 **약 56°**: 구단 관계자 전언. 대상 시즌·측정 정의·구종/경기/시즌 범위 미확인.
- 전준표 **2026년 47–53°**: 사용자는 “아마 SSG TrackMan 자료일 것”이라고 설명했다. 원문·영점·측정 방식·집계 범위는 미확인.
- 이강준 “얼추 맞는다”: 정성적 의견. 실제 숫자 검증 라벨이 아니다.
- 이 값들을 목표로 삼아 모델을 맞추지 마라. 참고값의 **어깨–공/상완/몸통 기준·수평/수직 영점·시즌/구종** 차이부터 점검해라.

## 5. 과소 추정 원인을 분리하려고 이미 한 시험

1. **전준표 연결 경로:** 같은 2024년 17경기·526구에 고정 모델을 적용하면 VB→TM 연결 입력 35.70°, 실제 TM 좌표 입력 35.54°, 차이 **0.16°**다. 이 표본의 연결만으로 문제를 설명하기 어렵지만 **2026년 오차를 검증한 것은 아니다.** 실제 KBO 팔각도를 대조한 것도 아니다.
2. **평균화:** 전준표 2026 유효 1,163구의 평균 입력 예측 38.9644°, 투구별 모델 출력 평균 38.9669°, 차이 **0.0025°**. 투구별 모델 자체의 정확도는 미검증이고 이 비교는 집계 방식 진단이다.
3. **구종 구성:** 포심 798구만 사용하면 39.91°, 전체 대비 **+0.94°**. 단일 시즌 8–14° 차이의 주원인이라는 근거는 약하다.
4. **좌표 높이 datum:** 연결된 2026 높이를 가상으로 +10cm 하면 45.04°, +15cm 하면 48.09°, +20cm 하면 51.13°. 민감도일 뿐 실제 오프셋의 증거가 아니며 적용하지 않았다.
5. **각도 정의:** SSG 47–53°가 만약 수직 기준이면 수평 기준은 **37–43°**로 현재 38.96°가 안에 든다. SSG가 실제로 수직 기준이라는 정보는 없다. 변환도 적용하지 않았다.
6. **유사 MLB 기하 표본:** 우투·신장 ±5cm·신장 대비 릴리즈 높이 ±0.025·팔 쪽 위치 ±0.04로 전준표와 가까운 30명·45개 시즌을 선택했다. 실제 각도 **26.45–55.79°**, 고정 모델 예측 **36.57–41.77°**. train/calibration/test를 포함한 탐색이며 반복 시즌도 있어 독립 성능 통계가 아니다. 그중 test 6명·9시즌에서도 실제 **32.35–53.15°**, 예측 **37.91–41.77°**다.
7. **독립 test 사례:** 카일 피네건 2024는 신장 187.96cm·릴리즈 높이 174.60cm·팔 쪽 위치 56.90cm로 전준표(186cm·171.76cm·53.73cm)와 가깝다. 실제 **50.34°**, 고정 모델 **39.35°**다.
8. **어깨 좌표 반사실적 예시:** 전준표 공 좌표를 고정하고 가까운 MLB의 어깨 중앙값을 넣으면 37.85°, 어깨 높이만 피네건 값이면 41.67°, 좌우만 피네건 값이면 **47.10°**, 둘 다면 50.95°다. **전준표의 실제 어깨 측정값이나 보정값이 아니다.**

현재 가설은 **관측하지 않은 어깨의 높이·좌우 위치와 회귀의 조건부 압축**이다. 투수판 위치·몸의 좌우 이동·어깨 폭·몸통/어깨 기울기·팔 길이·팔꿈치 굽힘이 같은 전역 공 좌표에 다른 암슬롯을 만들 수 있다. KBO→MLB 분포 차이, 모델의 함수 형태/규제, 측정 정의 차이도 분리해야 한다. 낮은 실제 슬롯을 높게 예측하는 MLB 사례도 있어 “KBO 전체가 항상 일정하게 낮다”는 명제는 미확정이다.

어깨–공 각도는 정확한 두 점이 있으면 계산되며 몸통 기울기를 별도로 빼는 지표가 아니다. 매구 수작업을 피하려고 자동 후보에서 선수·시즌별 대표 3–5구부터 검토하는 방안을 생각 중이다. 3–5구가 충분한지는 아직 시험하지 않았고, 카메라/릴리즈 보정된 독립 투구 3–5개씩을 이미 확보했다는 뜻도 아니다.

## 6. 네가 교차 점검할 핵심 질문

1. **정의·좌표·대응:** Savant/SSG/TM/VB가 정말 같은 목표인가? 좌우 시점/투구 손 부호, m/cm/ft, 지면·마운드 datum, 50/55ft와 실제 릴리즈, 평균 각도와 평균 좌표의 각도, MLB 상대/전역 어깨 좌표의 변환에서 오류가 있는가? 같은 두 점을 다른 영점에서 빼는 실수가 있는지 독립 재계산해라.
2. **식별성:** 지금 가진 관측만으로 어깨 위치/실제 암슬롯이 얼마나 식별되는가? 같은 공 위치에 다른 어깨 위치가 가능한 예시를 만들어라. 추가 RPM·flight time·축·익스텐션이 새 정보를 주는지, 기존 궤적의 재표현인지 구분해라.
3. **원인 구분:** 어깨 좌우 위치 누락, 몸통 기울기, 회귀의 함수 형태/규제, 라벨 집계, 측정 정의, MLB→KBO 분포 차이 중 현재 증거로 구분 가능한 것은 무엇인가? “평균으로 수축한다”가 증상을 설명할 뿐 원인을 입증하지 못하는 부분도 비판해라. 가까운 MLB 사례 선택의 민감도/반복 시즌을 점검해라.
4. **ODE 독립성:** 물리 모델의 힘 분해·HB/IVB·flight time 기준은 타당한가? 제조사 정의 차이, gyro·SSW·공기밀도·바람·계수 가정으로 어떤 해가 달라지는가? 작은 fit 잔차와 직접 축 일치가 정확도/추가 정보의 증거가 되는지 평가해라.
5. **통계 검증:** 투수 단위 분리·전처리·후보 선택·학습 범위·표본 선택에 누수가 있는가? 높은 슬롯의 빈약한 test, 낮은/높은 슬롯의 방향성 편향, 구장·연도 외삽을 어떻게 평가해야 하는가? 참고 반경의 계산/포함률/표현이 과장됐는지 검토해라.
6. **영상 검토:** 전달된 원본 프레임과 표시 이미지에서 shoulder joint와 ball/grip 위치가 타당한가? pose의 관절점이 가슴 쪽으로 치우쳤는가? ±픽셀 가정이 너무 좁은가? 마지막 held/첫 detached 화면으로 실제 릴리즈 각도를 식별할 수 있는가? 보정 없이 제시 가능한 값과 보류해야 할 값을 다시 판정해라. 현재 점을 정답으로 전제하지 마라.
7. **자동화 병목:** 카메라 보정에 필요한 최소 조건은 무엇인가? 방송/GIF로 가능한 보정과 불가능한 보정, pose+ball 검출의 오차 전파, 중복/편집 검출, 대표 3–5구의 충분성을 검사하는 기준, 구종·시즌별 추가 표본 조건을 제안해라. 매구 수작업이 필요한 경우와 대표 표본으로 되는 경우를 구분해라.
8. **다음 선택:** 추가 기하 관측 수집, 모델 함수 형태 비교, 유형별 모델, 독립 KBO 라벨 수집 중 무엇을 먼저 해야 하는가? 유형을 실제 암슬롯 정답으로 나누는 순환적인 평가를 피하고, 투수를 분리한 개선 검증을 설계해라. 실제 동작과 장비 변화가 구분되지 않는 Y2Y의 식별 한계를 명시해라.
