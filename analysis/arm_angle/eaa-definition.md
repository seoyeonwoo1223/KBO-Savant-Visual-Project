# eAA 정의, VB 연결 검증 및 추정 범위

**eAA = Estimated Arm Angle(추정 암슬롯)**로 정의한다. 목표는 Savant의 정면 어깨–공 각도이며, 현재 산출 단위는 **투수·시즌 평균**이다. KBO 어깨 좌표를 관측한 값이 아니라 릴리즈 위치와 신장으로 예측한 값이다. 이번 작업에서 VB 연결 모델, 검증, 2022–2026 결과와 Y2Y 비교까지 구현했다. Pitch Plot에 단일 시즌 eAA와 별도 오차범위 표시를 적용했다.

## 무엇을 완료했는가

- KBO 공식 프로필에서 2025–2026 선수 **134명**의 신장을 추가 확인했다. 신장 표는 총 **736명**이다. 선수 ID와 이름을 함께 대조하고 출처·원문 해시를 저장한다.
- 2019–2024 투구 순서·카운트·선수·구속 검증을 통과한 TM/VB 쌍에서, 신장과 유효 좌표가 있는 **1,112,517구**를 연결 연구의 학습·범위 보정·평가에 사용했다. 실제 학습 단위는 그 투구를 평균한 투수·경기다. 전기 정보와 투구 손이 어긋나는 14구는 제외했다.
- 선수 단위 분리, 구장 전체 제외, 2024년 전체 제외 평가를 수행했다. 검증용 시즌/투수를 보정 회귀나 표준화 학습에 넣지 않았다.
- 2022–2026년 **1,178개 투수·시즌**의 eAA를 산출했다. 유효 투구 100구 미만 또는 모델의 입력 범위를 벗어나면 최종값을 비운다. 누락 신장·입력 이상은 별도 eligibility 파일에 남긴다.
- 모든 연도에 같은 고정 모델을 적용했다. 연도별 리그 평균이나 개인의 연도별 각도를 강제로 같게 만들지 않는다.

## 연결 모델

VB `release_x_55`, `release_z_55`는 홈에서 55ft 떨어진 궤적 좌표다. TM `rel_side`, `rel_height`는 실제 릴리즈 좌표다. 좌우 부호와 단위를 맞춘 뒤 다음 잔차를 학습한다.

```text
TM rel_side = -VB x55 / 100 + 투구 손 부호 × 예측 좌우 잔차
TM rel_height = VB z55 / 100 + 예측 높이 잔차
```

입력은 신장(m), 팔 쪽 x55(m), z55(m), 55ft에서의 좌우/전후 및 수직/전후 속도 비율이다. 투구 손을 반영한다. `StandardScaler → Ridge(alpha=10)`로, 투수·경기 평균에 같은 학습 비중을 준다. 선수·구장·연도 ID를 회귀 입력으로 넣지 않는다. 선형 모델이므로 투구별 속도 비율을 평균한 값을 보존하면 경기별 예측과 시즌 평균 예측의 일관성이 유지된다.

연결 모델은 2019–2023 투수를 사전에 고정한 난수로 60% 학습 / 20% 범위 보정 / 20% 평가로 나눴다. 동일 투수의 모든 시즌은 같은 그룹이다. 배포용 연구 모델도 학습 그룹으로만 학습한 상태로 고정한다. 2024년은 시간 외삽 평가이며 학습·범위 보정에 넣지 않았다.

그 좌표를 `2차 다항 → StandardScaler → Ridge(alpha=10)` MLB 팔각도 모델에 넣는다. MLB 모델 역시 전체 투수를 60/20/20으로 분리해 학습과 범위 보정·평가를 분리했다. 초기 TrackMan 연구의 전체 MLB 재학습 모델과 구분되는 **고정 eAA 모델**이다. 초기 5-fold MAE 4.76°와 이번 독립 테스트 MAE 4.43°는 평가 표본이 달라 개선량으로 비교하지 않는다.

익스텐션은 팔 길이가 아니며, 대응 MLB 익스텐션 기준값이 없어 팔각도 회귀에 포함하지 않았다. 신장은 사용했고, 어깨 관측을 대체한다고 해석하지 않는다.

## 오차범위의 정확한 의미

단순히 MAE를 `±오차`로 쓰지 않는다. 학습과 독립적인 보정 그룹에서 투수별 **모든 시즌 중 최대 절대오차**를 구하고, 유한 표본 순서통계로 90% 참고 반경을 정했다. 독립 평가 그룹에서 그 반경의 포함률도 확인했다.

| 성분 | 참고 반경 | 독립 테스트 시즌 포함률 | 평가 대상 |
|---|---:|---:|---|
| MLB 각도 예측 | 12.00° | 97.4% | MLB 실측 팔각도 |
| VB→TM 연결 | 2.23° | 93.9% | TM 기반 모델 추정값 |

전체 투수의 모든 시즌을 함께 덮은 독립 테스트 비율은 각각 96.7%, 86.5%였다. 표의 시즌별 포함률과 투수 그룹별 포함률은 서로 다른 값이다. 90%는 동일 모집단의 교환 가능한 투수 그룹에 대한 방법의 목표이며, 유한 테스트에서 정확히 90%가 된다는 뜻도 아니다.

관측된 구장 안에서 입력 범위와 표본 수 기준을 통과하면 **두 참고 반경의 합 ±14.23°**를 `reference_low_deg`, `reference_high_deg`에 저장한다. 각도 정의의 범위인 −90°~90°로 제한한다. 오차 독립성을 가정한 제곱합을 쓰지 않는다. 두 성분의 90% 범위를 합쳤다고 전체 90%가 되는 것도 아니다. 같은 대상에서 두 성분의 포함률이 모두 유효하더라도 합집합 상계로 보장되는 하한은 80%이고, KBO에는 그 전제 자체가 확인되지 않았다.

따라서 이것은 **모델 참고 범위**이며 KBO 90%/95% 신뢰구간·예측구간이 아니다. MLB→KBO 전이 편향, 미관측 구장 편향, 미래 장비/추적 품질 변화까지 측정한 전체 오차범위는 여전히 없다. 임의 어깨 위치 기하 시나리오 범위도 여기에 섞지 않는다.

미관측 구장이 포함된 시즌은 `range_status=unavailable_unseen_stadium_bias`로 기록하고 양 끝을 빈값으로 둔다. 학습 범위를 벗어난 입력과 100구 미만 시즌도 범위를 제공하지 않는다. 미래 시즌의 알려진 구장만 있는 표본에 참고 범위가 있더라도 `reference_only_future_season_unvalidated`를 표시한다. 단순 특성 최솟값/최댓값 검사는 다변량 분포나 장비 편향을 모두 탐지하지 않는다.

## 광주와 2025–2026

| 연도 | 계산 가능한 eAA 투수·시즌 |
|---|---:|
| 2022 | 228 |
| 2023 | 231 |
| 2024 | 245 |
| 2025 | 231 |
| 2026 | 243 |

광주에서도 VB 좌표를 연결해 추정할 수 있다. 2022–2026 광주 표본만으로 100구·특성 범위 기준을 통과한 투수·구장·시즌은 **241개**다. 광주 특유의 편향을 직접 검증할 TM 자료가 없으므로 전체 오차범위는 미확정이다. 시즌 전체와 광주 부분 표본은 서로 다른 모집단이다.

2025에는 김상수(`76430`)의 검증 신장이 없어 648구가 빠졌다. 현재 KBO 프로필이 김태혁으로 표시되어 이름 대조에서 거절했다. 2026에서는 신장 결측이 없고, 궤적 결측 88구를 제외했다. 2019–2024의 기존 이름 불일치 선수도 강제로 연결하지 않는다.

2026 원본 `source_y0`는 3월 28일–7월 9일 50ft, 7월 16일–10월 1일 55ft다. 같은 55ft로 정규화한 좌표를 사용했으며 원본 기준면을 그대로 모델에 넣지 않았다. 양 시기 모두 30구 이상 있는 **투수×구장×구종 419개 조합**에서 평균 좌표 변화 중앙값은 x −0.82cm, z +0.13cm였다. 시즌 중 실제 변화와 측정 변화가 함께 들어 있으므로 장비 편향의 추정값으로 쓰거나 이 값을 강제로 빼지는 않는다.

## Y2Y 해석

양쪽 연도 모두 같은 VB 연결 모델과 같은 MLB 팔각도 모델로 계산했다. 과거 TM 값과 미래 VB 값을 바로 빼지 않는다.

- `raw_change_deg`: 두 시즌 전체 표본의 eAA 차이.
- `common_park_change_deg`: 두 시즌 각각 30구 이상 있는 공통 구장만 사용하고, 양쪽 시즌 구장 점유율의 평균을 동일한 가중치로 적용한 차이. 공통 구장의 표본 점유율도 저장한다.
- `change_reference_low_deg/high_deg`: 양쪽 시즌 참고 범위가 있을 때 범위 끝점 차이로 만든 보수적인 참고 범위. 양쪽 오차의 상관이나 같은 선수의 편향 상쇄를 추정했다고 가정하지 않는다.
- 미관측 구장 때문에 범위가 없으면 변화의 참고 범위도 비운다. 공통 구장으로 평균을 맞춘 값은 구종·구속·부상·기간 구성과 장비 변화를 모두 통제하지 않는다.

이번 결과만으로 실제 Y2Y 변화 방향을 확정한 사례는 없다. 외부 앵커가 없으면 리그 공통 연도 이동이 실제 동작 변화인지 측정 편향인지 식별되지 않는다. eAA 차이는 관측 자료를 같은 모델로 변환한 **연구용 변화 신호**다.

## Pitch Plot 적용 계약

첫 적용 단위는 투수·시즌 평균이다. 공개 화면에는 `eAA 40.7°`처럼 추정값, 단위, 기간, 표본 수를 표시한다. `estimated_KBO_angle_unvalidated` 값만 사용하고, 빈값을 0°로 바꾸지 않는다.

참고 범위가 있으면 **모델 참고 범위 · KBO 실측 미검증**으로 표시한다. `range_status=unavailable_unseen_stadium_bias`이면 **범위 미확정**을 표시하고 숫자 범위를 만들지 않는다. 구장·시즌 위험 플래그는 설명에 연결한다. 투구별·구종별 실제 암슬롯으로 읽히게 표시하지 않는다.

Pitch Plot의 `overall.eaa`에 시즌 대표 추정값을 연결하고, 구종별 eAA는 생성하지 않는다. 화면에는 정수 각도와 회색 점선 하나, 별도 참고 범위 또는 범위 미확정을 표시한다. 실측 검증 상태는 접힌 설명과 저장 이미지에도 표시한다. 실제 KBO 전체 오차범위를 검증하려면 투구 영상에서 같은 릴리즈 프레임의 어깨–공 각도를 측정하고, 투수를 분리한 평가와 광주·신규 구장·미래 시즌 기준값을 확보해야 한다.

선수 신장을 갱신할 때는 `python analysis/arm_angle/collect_vb_heights.py --seasons 2025 2026`을 사용한다. 기존 검증 행은 재사용하며, 수집 로그는 기본적으로 캐시에 남겨 과거 수집 증거를 덮어쓰지 않는다.

이미 검증 신장과 MLB 자료가 저장되어 있으므로 재계산은 오프라인이다. 입력은 canonical API가 읽은 지정 컬럼과 매칭 파일이며, 결과 CSV를 학습 입력으로 되먹이지 않는다. 큰 매칭 파일·경기 평균 파일은 `.cache/arm_angle/vb_bridge/`에 보존하고 Git에는 넣지 않는다.


## Pitch Plot 구현 및 검증

생산 추론은 `src/visualbaseball/estimated_arm_angle.py`에서 수행한다. 연구에서 고정한 계수·다항 차수·특성 범위·구장 목록을 `data/models/estimated_arm_angle_v1.json`으로 보존했다. 학습·범위 보정·테스트를 다시 수행하거나 결과 CSV를 읽지 않고, 해당 시즌 canonical 투구와 공식 신장 표·선수 ID/이름/투구 손으로 계산한다. 개별 투구의 속도 비율을 먼저 평균하고, 선형 좌표 연결 후 시즌 평균에 팔각도 모델을 적용한다.

`pitch_arsenal.py`가 원래의 구종 표시·병합과 독립적으로 시즌 전체 eAA를 계산하여 `overall.eaa`에 넣는다. 프로필 스키마는 4다. 확인되지 않은 신장·투구 손·유효 좌표, 소표본, 입력 범위 초과는 각도와 범위를 빈값으로 둔다. 기존 데이터에 eAA가 없을 때도 화면은 0°로 대체하지 않는다.

화면의 원측정값/보정값·시점·단위 전환은 eAA와 참고 범위를 바꾸지 않는다. 시점만 전환하면 회색 참고선의 좌우 방향이 뒤집히며, 양 축을 같은 축척으로 그려 각도를 유지한다. 좌투·우투, 수평 0°·음수 언더핸드·수직 90°를 처리한다. 불확실성 부채꼴이나 구종별 각도선을 추가하지 않았다.

신장 표, 고정 모델, 추론 코드의 변경은 `metric_state`의 Pitch Plot 빌드 hash에 포함된다. 신장·모델 파일 변경도 일일 갱신 워크플로를 실행하도록 경로에 추가했다. 모델 재학습을 자동 실행하지 않는다.

2022–2026 프로필을 다시 생성하여 연구 추정값 1,178개와 확인했다. 각도·범위 차이는 저장 정밀도의 반올림 오차 0.000051° 미만이다. 기존 프로필 1,431개의 구종·구속·무브먼트·사용률 등 통계는 이전 출력과 모두 같았다. 전체 Python 테스트 187개, Node 레이아웃/eAA 테스트와 브라우저의 범위·빈값·시점·단위/모드·모바일 확인을 통과했다.

이미지 저장에서는 html2canvas가 접힌 `details` 본문까지 그리는 문제가 있어, 캡처 복제본에서 설명 패널을 짧은 `모델 추정 · KBO 실측 미검증` 문구로 바꾼다. 실제 PNG 저장까지 확인했다. 클라우드 브라우저에서 외부 라이브러리 직접 로드가 차단되어, 브라우저 검사는 정상 TLS로 받은 기존 공식 CDN 자산을 테스트에서만 로컬 응답으로 제공했다. 제품의 라이브러리 주소는 유지한다.
