## 목표와 배경

KBO Pitch Plot에 Savant의 팔각도 정의를 목표로 한 `eAA (estimated Arm Slot)` 단일 수치와 별도의 오차범위를 표시하고 있다. 릴리즈·신장 기반 기존 모델에서 특히 일부 고슬롯 투수의 값이 낮다는 의심이 있다. 영상 하나씩 어깨·몸통을 측정하는 방식을 피하고, 확보 가능한 수치 자료만으로 개선할 수 있는지 확인하려 한다.

사용자의 외부 참고값은 박영현 약 53–60°, 조병현 약 77°, 두 선수의 회전효율 약 99%와 회전축 약 12시다. SSG TrackMan 관련 정보지만 같은 투구의 원시 대응값과 산식은 없다. 박영현의 IVB 19.8–20.9인치도 기간·투구 분모·장비 간 정의를 확정하지 못했다. **이 참고값을 검증된 정답이나 이번 실험의 학습 라벨로 취급하지 마라.**

SSG와 Savant가 같은 각도일 가능성은 열어 두되, 정의가 같다고 확인된 것으로 쓰지 마라. 공의 궤적에서 회전과 어깨 자세가 각각 어디까지 식별 가능한지 구분해 줘.

## 교차 검토할 핵심 주장

### 1. 같은 표본의 변수 효과와 학습 누수

공식 팔각도 3,392개 시즌 / 1,296명 중 포심 회전·무브먼트·익스텐션 공동 표본은 2,292개 시즌 / 961명이다. 전체 구종 시즌 평균 팔각도를 목표로, 포심 평균을 회전·무브먼트 입력으로 썼다. 관측 60° 이상은 57개 시즌 / 35명이다. 전 모델은 고정된 2차 다항식·표준화·Ridge(alpha=10), 같은 선수의 모든 시즌을 같은 5-fold에 둔다.

| 연구 모델 | OOF MAE | 관측 60° 이상 평균 편향 |
|---|---:|---:|
| 릴리즈·신장 | 4.780° | −8.519° |
| 무브먼트·구속 추가 | 3.804° | −5.580° |
| 회전수·익스텐션 추가 | 3.420° | −4.094° |
| 광학 회전·무브먼트·익스텐션 | 3.192° | −3.766° |
| 같은 입력에서 어깨를 예측해 각도 계산 | 3.187° | −3.407° |

기하 대비 회전수·무브먼트·익스텐션의 MAE 개선은 1.360° [선수 부트스트랩 95%: 1.145°, 1.573°]. 어깨 중간 모델의 전체 추가 개선은 0.0047° [−0.023°, 0.031°]이나 고슬롯에서는 약 0.495° [0.290°, 0.708°] 개선된다. 20° 미만에서는 점추정 오차가 증가한다. 추가 분산·발사 방향·구종 비율은 전체 MAE를 개선하지 않았다.

실제 어깨 관측은 학습 목표로만 쓰며 검증/KBO 입력에 주입하지 않았는지, 전처리와 특징 선택도 fold 밖 정보를 보지 않는지 확인해 줘. 예측 어깨는 새 관측이 아닌 같은 입력의 변환이므로, 이 실험만으로 어깨 위치의 인과 효과나 유일한 복원을 주장할 수 있는지도 검토해 줘.

같은 평가 선수에서 qualified-only 학습 대비 표본 확대 자체의 광학 공동 모델 개선은 전체 약 0.0348°, 고슬롯 약 −0.077°다. 변수 효과와 표본 효과를 혼동하지 마라. **관측 각도별 고슬롯 편향**과 **예측 각도 조건부 편향**을 나눠 봐 줘. 전체 광학 공동 모델 평균 편향은 약 −0.019°, 예측 55° 이상 그룹은 약 +0.209°다. 모든 선수에게 +5° 같은 일괄 보정이 정당한 근거인지 판단해 줘.

### 2. 12시·99% 고슬롯 표본과 KBO 시나리오

공동 표본 우완 중 축 165–195° / active spin ≥98.5%는 두 시즌뿐이다: McKenzie 2023(54.03°, 168.15°, 98.78%), Romero 2022(73.96°, 179.86°, 99.65%). Romero는 팔각도 191구 / 포심 회전 107구다.

사용자 회전축·99%와 2024 TrackMan RPM을 가정해 2026 VB 입력에 넣으면 박영현은 광학 공동 모델 53.70–58.45°, 예측 어깨 모델 54.71–59.92°, 조병현은 각각 69.82° / 71.67°다. **2026 실제 광학 측정이나 신뢰구간이 아니다.** 박영현의 가정 축은 172.5–180°, 조병현은 180°다.

선수별 5번째 이웃 거리는 학습 분포 약 92–97백분위다. 12시 `−cos(axis)`의 단일 범위 초과는 표준화 약 0.0000236이며, Romero 제거 영향도는 광학 최대 0.262° / 예측 어깨 최대 0.069°다. 희소 결합 표본·민감도·모델 형식이 어떤 불확실성을 남기는지 평가하고, 거리 백분위를 OOD 확률로 바꾸어 해석하지 마라.

### 3. ODE 회전 역산의 의미

44개 대표 포심 시즌 × 6개 가정 = 264개 시험이다. 박영현 2024의 조건부 유효회전 비율은 밀도 1.225에서 97.37%, 1.30에서 86.14%이며 축은 약 160.30°다. 조병현은 94.94% → 84.26%, 축 약 167.48°다. 박영현 기본 적합의 플레이트 y 오차 −12.64cm는 기준 10cm를 넘으므로 학습에 사용하지 않았다.

비행시간을 약 −3.22ms 조정해 위치까지 맞추면 효율 상한 100%에 걸린다. 높은 밀도와 시간 적합을 동시에 쓰면 통과할 수 있다. 네 관측량에 네 파라미터를 맞춘 잔차 감소는 독립 검증이 아니다. 새 시간 적합값을 VB 학습 정답에 추가하지 않았다.

무브먼트의 vendor 정의, 무회전 기준 경로, 파생 비행시간, 공기밀도·바람·양력·항력·SSW·자이로·축 변화가 역산 결과에 어떻게 섞이는지 확인해 줘. **무브먼트 기반 유효 축과 광학 회전축**, **조건부 유효회전 비율과 관측 회전효율**이 동일하다는 주장은 하지 않는다. 궤적 ODE가 어깨 위치를 식별할 수 있는지도 구분해 줘.

### 4. VB 연결의 분리 평가와 범위

2019–2023 학습, 2024 시간 분리와 미학습 선수 분리를 수행했다. 미학습 52명에서 축 MAE 3.526°, RPM MAE 90.65, 비율 MAE는 자유 예측 5.71%p → logit 제한 6.33%p다. 100% 초과는 2명 → 0명이지만 정확도가 개선된 것은 아니다. 학습 정답은 광학값이 아닌 ODE 조건부 역산값이다. 박영현의 적격 역산 학습 라벨은 0개다.

2026 자동 VB 대용치는 박영현 46.15°, 조병현 62.37°, 페덱 38.98°다. 조병현은 VB 학습 특징 범위를 벗어난다. 이것을 실제 eAA나 검증된 KBO 각도로 배포하지 않았다. 시기·선수 분리가 장비·구장 전이를 어디까지 보장하는지 검토해 줘. 구장 완전 홀드아웃을 한 것으로 간주하지 마라.

독립 선수 hash 분리의 학습 583명 / 범위 보정 186명 / 평가 192명, 선수별 최대 시즌 절대오차로 90% 범위를 구했다. 광학 공동 모델 반경 ±7.32°, 예측 어깨 ±7.16°와 선수의 모든 시즌 포함률 약 88%는 **MLB 평가 결과**다. rank·선수 독립성·exchangeability·평가 포함률의 표본 불확실성을 재확인하고 KBO 범위 보장과 혼동하지 마라.

### 5. 페덱과 정의의 대조

페덱의 독립 선수 MLB OOF는 2020/2021/2022/2024 관측 47.16/50.21/48.73/45.88°, 광학 공동 예측 45.15/46.91/47.22/44.11°다. MLB에서도 잔차가 남으므로 KBO 장비 문제만으로 모두 설명되는지 검토해 줘. 이전 MLB 시즌 각도를 KBO 2026 정답으로 대입하지 마라.

공식 좌표와 코드에서 수평 기준 팔각도, 절대/상대 어깨 좌표, 좌우 손 부호, feet/m 및 신장 비율, `atan2` 방향, 평균 각도와 평균 좌표의 각도를 대조해 줘. 서로 다른 투구 분모의 시즌 평균도 확인해 줘.

## 답변에 원하는 내용

1. 중대한 오류·통계적 해석 오류·근거 부족을 우선순위별로 정리하고, 각각 정확한 파일·열·행 또는 코드 위치와 재계산 근거를 제시해 줘. 확인되지 않은 가설은 가설로 표시해 줘.
2. 어떤 결론은 재현됐고 어떤 결론은 원시 캐시 부재로 미검증인지 구분해 줘. 필요하면 저장소를 수정하지 않는 작은 독립 계산 코드를 제공해 줘.
3. 영상 작업 없이 추가할 수 있는 **수치 변수 또는 측정**을 제안해 줘. 이미 시험한 변수와 겹치지 않는 새 정보인지, 직접 관측·외부 사전정보·기존 변수의 파생값인지, KBO에서 확보 가능한지, 개선을 판별할 선수/기간/구장 분리 실험이 무엇인지 함께 써 줘.
4. 고슬롯 저평가가 회귀 수축·조건부 표본 선택·구종 분모·장비 정의·자세 비식별성 중 무엇으로 설명되는지 경쟁 가설을 비교하고, 가장 적은 새 자료로 가설을 구분할 다음 실험 1–3개를 추천해 줘.

참고 선수 값에 맞춘 임의 상수 보정, 회전효율 99%의 자동 정답 취급, 확인되지 않은 SSG 정의 일치, 연구 결과의 즉시 운영 모델 교체를 권하지 마라. 증거가 충분하면 기존 판단을 비판해도 좋다. 주장·측정·가정을 구분하는 독립 검토가 목적이다.
