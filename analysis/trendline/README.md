# Trendline 지표와 기간 비교

## 자료 범위

2019–2026 KBO 정규시즌 canonical pitches·games에서 완료 경기만 사용한다. 해외·퓨처스 기록은 연결하지 않는다. 2019·2020의 SK 이름도 1군 팀으로 포함하고 당시 표기를 보존한다. 선수는 이름이 아니라 역할과 선수 ID로 연결하며, 이적 전후 기록은 해당 ID의 기간에 합산한다. 각 시즌의 최신 경기일을 표시한다. PBP 재집계이므로 공식 합계와 다를 수 있다.

2022–2024는 `pa_type`이 비어 있어 `pa_result=삼진`으로 보완한다. 다른 시즌의 `pa_type=bb`는 사구도 포함하므로 볼넷은 `볼넷·고의사` 결과만 집계한다. 결과가 없고 명확한 삼진·안타·홈런 유형도 없는 종료 타석은 `pa_unknown`으로 남기고 K%·BB% 분모에서 제외한다. 해당 타석 수는 화면에 표시한다. 미래 데이터의 미확인 값을 0으로 간주하지 않는다.

## 정의

| 지표 | 분자 | 분모 |
|---|---|---|
| 평균 구속 | 유효 양수 구속 합 (km/h) | 유효 구속 투구 수 |
| 구종 사용률 | 해당 구종 투구 수 | 전체 투구 수 (미분류 포함) |
| K% | 삼진 (결과가 삼진이거나, 2스트라이크에서 헛스윙·루킹 스트라이크로 끝난 타석) | 결과 확인 완료 타석 |
| BB% | 볼넷·고의사 | 결과 확인 완료 타석 (사구 포함) |
| Swing% | 스윙 | 스윙 여부 확인 투구 |
| O-Swing% | 존 밖 스윙 | 위치·스윙 확인 존 밖 투구 |
| Z-Swing% | 존 안 스윙 | 위치·스윙 확인 존 안 투구 |
| Contact% | 접촉 | 스윙 중 접촉 여부 확인 투구 |
| Whiff% | 헛스윙 | 스윙 중 접촉 여부 확인 투구 |
| SwStr% | 헛스윙 | 스윙 여부 확인 및 스윙 시 접촉 여부 확인 투구 |
| Zone% | 존 안 투구 | 유효 위치 투구 |
| HB·IVB (투수) | 보정 무브먼트 합 (in) | 무브먼트 측정 투구 수 |

Visual Baseball 원본은 2019년 3–5월을 중심으로 삼진 2,623타석의 결과를 비워 두었고(`type=out`, `result=""`), 낫아웃 폭투·포일은 결과가 WP·포실로만 남는다. 마지막 공이 2스트라이크의 S·T 판정이면 규칙상 삼진이므로 삼진과 완료 타석으로 센다. 그 밖의 빈 결과(예: 0스트라이크에서 주루사로 이닝 종료)는 계속 미확인이다. 비율은 100을 곱한다. 존은 `abs(px)≤10/12 ft`, `sz_bottom≤pz≤sz_top`로 정의한다. 좌표·경계가 없거나 비유한 값이면 존 분모에서 제외한다. 2024 ABS 전환과 px 측정면 변화 등 시즌별 기준 차이는 연속 추세 해석의 한계다. HB·IVB는 Pitch Plot과 같은 `movement_calibration.calibrate`(타석 위치 성분과 구장·날짜 효과 제거) 보정값을 인치로 저장하며, 시즌마다 그 시즌 투구 전체로 한 번 적합한다. HB는 저장 좌표와 같은 포수 시점이라 우투 암사이드가 음수다. 두 지표는 구종을 섞으면 의미가 없어 구종별 선만 제공한다. 구종은 공용 pitch_types의 원래 분류를 유지하고, Pitch Plot의 소수 구종 표시 병합을 이 추세에 적용하지 않는다.

## 집계·리그 평균

- 시즌·월별: 선택한 날짜 구간 안의 해당 시즌·월 기록을 합산한다. 기록이 없는 시즌·월은 null이며 선을 끊는다.
- 경기별: 해당 선수의 최근 1·5·10번 출전 경기에서 분자·분모를 합산한다. 시작 구간의 표본이 적어도 확인된 값을 표시한다. 선택한 기간 밖의 경기는 포함하지 않고 시즌 경계에서 초기화한다. 더블헤더는 경기 ID가 다른 두 경기로 센다.
- 경기별 보기의 기본 집계는 평균 구속이 경기별 원값, 다른 지표가 최근 5경기다. 위젯을 추가하거나 지표를 바꾸면 해당 지표의 기본 집계를 적용한다. 사용자는 경기별 원값·최근 5·10경기를 선택할 수 있으며, 제목에도 실제 집계를 표시한다. 시즌·월별 보기는 해당 기간 합산을 유지한다.
- 리그: 선택한 날짜 구간을 시즌별로 잘라 그 시즌의 리그 전체 투구·타석을 합산한 값 하나를 수평선으로 그린다(시즌을 섞지 않으므로 여러 시즌이면 시즌마다 한 선분). 시즌·월·경기별 점과 툴팁·제목의 리그 대비 차이도 이 시즌 값과 비교한다. 리그 경기를 N개 고르거나 선수별 비율을 평균내지 않는다. 선택한 선수도 리그에 포함한다.
- 구종별 지표는 동일 구종의 리그 기록을 사용한다. 사용률 분모는 선수·리그 각각 전체 구종이다. K%·BB%는 구종 필터를 제공하지 않는다.
- 리그 평균 점선은 선이 하나인 위젯에서 기본으로 켜고, 구종별 여러 선에서는 끈 채 시작한다. 값 차이는 비율의 경우 %p, 구속은 km/h, 무브먼트는 in이다.
- HB 리그 평균은 좌·우투의 부호가 반대라 섞으면 의미가 없으므로 그리지 않는다. IVB는 같은 구종의 리그 평균을 켤 수 있다. 어느 지표에도 높고 낮음의 좋고 나쁨을 표시하지 않는다(커브의 낮은 IVB 등).
- 경기별 이동평균의 세로축은 이동평균 선과 경기별 원값의 5–95% 범위를 포함한다. 그 밖의 극단 원값 점은 그리지 않는다.

## 표본 표시

평균 구속·HB·IVB·사용률·Swing%·O-Swing%·Z-Swing%·SwStr%·Zone%는 해당 분모 50개, Contact%·Whiff%는 확인된 스윙 30개, K%·BB%는 확인된 타석 30개 미만에서 빈 원을 쓴다. 통계적 안정화 기준이라고 주장하지 않는 표시 기준이다. 분모 0은 null이다.

## 생산 경로

`trendline.py`는 필요한 컬럼만 읽고 경기별 선수·일자별 리그의 분자·분모를 JSON으로 게시한다. 브라우저는 그 카운트를 합산해 기간 선택·이동평균을 계산한다. `web/`를 입력으로 되읽지 않는다. 현재 시즌은 `_exports()`에, 완료 시즌은 `--only trendline` 일일 단계에 연결한다. 입력·코드 hash 및 모든 선수 출력 파일 존재 여부로 재생성을 판정한다.
