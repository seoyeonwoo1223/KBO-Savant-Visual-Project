# Trendline 지표와 기간 비교

## 자료 범위

2019–2026 KBO 정규시즌 canonical pitches·games에서 완료 경기만 사용한다. 해외·퓨처스 기록은 연결하지 않는다. 2019·2020의 SK 이름도 1군 팀으로 포함하고 당시 표기를 보존한다. 선수는 이름이 아니라 역할과 선수 ID로 연결하며, 이적 전후 기록은 해당 ID의 기간에 합산한다. 각 시즌의 최신 경기일을 표시한다. PBP 재집계이므로 공식 합계와 다를 수 있다.

2022–2024는 `pa_type`이 비어 있어 `pa_result=삼진`으로 보완한다. 다른 시즌의 `pa_type=bb`는 사구도 포함하므로 볼넷은 `볼넷·고의사` 결과만 집계한다. 결과가 없고 명확한 삼진·안타·홈런 유형도 없는 종료 타석은 `pa_unknown`으로 남기고 K%·BB% 분모에서 제외한다. 해당 타석 수는 화면에 표시한다. 미래 데이터의 미확인 값을 0으로 간주하지 않는다.

## 정의

| 지표 | 분자 | 분모 |
|---|---|---|
| 평균 구속 | 유효 양수 구속 합 (km/h) | 유효 구속 투구 수 |
| 구종 사용률 | 해당 구종 투구 수 | 전체 투구 수 (미분류 포함) |
| K% | 삼진 | 결과 확인 완료 타석 |
| BB% | 볼넷·고의사 | 결과 확인 완료 타석 (사구 포함) |
| Swing% | 스윙 | 스윙 여부 확인 투구 |
| O-Swing% | 존 밖 스윙 | 위치·스윙 확인 존 밖 투구 |
| Z-Swing% | 존 안 스윙 | 위치·스윙 확인 존 안 투구 |
| Contact% | 접촉 | 스윙 중 접촉 여부 확인 투구 |
| Whiff% | 헛스윙 | 스윙 중 접촉 여부 확인 투구 |
| SwStr% | 헛스윙 | 스윙 여부 확인 및 스윙 시 접촉 여부 확인 투구 |
| Zone% | 존 안 투구 | 유효 위치 투구 |

비율은 100을 곱한다. 존은 `abs(px)≤10/12 ft`, `sz_bottom≤pz≤sz_top`로 정의한다. 좌표·경계가 없거나 비유한 값이면 존 분모에서 제외한다. 2024 ABS 전환과 px 측정면 변화 등 시즌별 기준 차이는 연속 추세 해석의 한계다. 구종은 공용 pitch_types의 원래 분류를 유지하고, Pitch Plot의 소수 구종 표시 병합을 이 추세에 적용하지 않는다.

## 집계·리그 평균

- 시즌·월별: 선택한 날짜 구간 안의 해당 시즌·월 기록을 합산한다. 기록이 없는 시즌·월은 null이며 선을 끊는다.
- 경기별: 해당 선수의 최근 1·5·10번 출전 경기에서 분자·분모를 합산한다. 시작 구간의 표본이 적어도 확인된 값을 표시한다. 선택한 기간 밖의 경기는 포함하지 않고 시즌 경계에서 초기화한다. 더블헤더는 경기 ID가 다른 두 경기로 센다.
- 리그: 시즌·월별은 선수와 같은 달력 구간을 사용한다. 경기별 이동평균은 해당 선수의 창 시작일–현재 경기일까지 리그 전체 투구·타석을 합산한다. 리그 경기를 N개 고르거나 선수별 비율을 평균내지 않는다. 선택한 선수도 리그에 포함한다. 같은 날 더블헤더에서는 리그 하루 전체 기록을 비교하며 tooltip에 날짜 구간을 표시한다.
- 구종별 지표는 동일 구종의 리그 기록을 사용한다. 사용률 분모는 선수·리그 각각 전체 구종이다. K%·BB%는 구종 필터를 제공하지 않는다.
- Swing%·O-Swing%·Z-Swing%는 리그 평균 점선을 기본으로 켠다. 다른 지표도 사용자가 켤 수 있다. 값 차이는 비율의 경우 %p, 구속은 km/h이다.

## 표본 표시

평균 구속·사용률·Swing%·O-Swing%·Z-Swing%·SwStr%·Zone%는 해당 분모 50개, Contact%·Whiff%는 확인된 스윙 30개, K%·BB%는 확인된 타석 30개 미만에서 빈 원을 쓴다. 통계적 안정화 기준이라고 주장하지 않는 표시 기준이다. 분모 0은 null이다.

## 생산 경로

`trendline.py`는 필요한 컬럼만 읽고 경기별 선수·일자별 리그의 분자·분모를 JSON으로 게시한다. 브라우저는 그 카운트를 합산해 기간 선택·이동평균을 계산한다. `web/`를 입력으로 되읽지 않는다. 현재 시즌은 `_exports()`에, 완료 시즌은 `--only trendline` 일일 단계에 연결한다. 입력·코드 hash 및 모든 선수 출력 파일 존재 여부로 재생성을 판정한다.
