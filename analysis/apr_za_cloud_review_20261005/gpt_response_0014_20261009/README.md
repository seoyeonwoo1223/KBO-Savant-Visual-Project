## SZ 정합·기본값·해상도: 설명 수준 구별

## ZN-A의 가장 큰 문제: 경계 오프셋은 결정적 증명이 아니다

0014가 제안한 상·하단·좌우 경계 오프셋 적합을 **진단**으로 두는 데 동의한다. 오프셋0을 “VB sz=실제 ABS 설정 신장”의 결정적 검산이라고 부르는 것은 반대한다.

공유 오차식에서 반지름 rho를 eta만큼 늘리고 left/right/upper/lower 오프셋을 각각(+eta,−eta,−eta,+eta) 이동하면 모든 유효 경계가 같다. 확률이 정확히 동일한 대수 반례를 checks.json에 기록했다. 따라서 rho와 자유 경계를 동시에 적합할 수 없다. rho를 외부에서 고정해도 센서/궤적 바이어스, 오차모형, 실제 대체 콜 등이 혼재하므로 오프셋0은 지정 모형과의 일관성까지만 의미한다. 비유의성도0의 동등성 증거가 아니다.

주모형은 공식 경계·외부 고정 rho·영평균 오차를 고정하고 sigma만 추정한다. 오프셋 진단은 별도 학습/평가와 사전 동등성 한계로 보고하며 주 q에 경계 이동을 되먹이지 않는다. 실패 시 q_za 자동 대체나 운영 수정으로 이어지지 않는다.

## 등록 상태와 남은 공백

0014의1~5는 필요한 재료지만 사전등록의 최종 판정표는 아니다. 초안에는 원천/행 ID, 입력/결측 분모, 부호 있는 두 면, 정합 구간, 원천 신장 대용값 표시, 공 크기·면별 오차 가정, 주 경계와 오프셋 진단 분리, 평가 누수/기준을 넣었다.

공통 평가 행·Take 라벨/대체 콜 처리·sigma 학습과 fold 경계·수치 채택 문턱/CI·오프셋 동등성 한계는 아직 gates에 확정되지 않았다. 따라서 ZN-A는 미등록·미실행으로 남긴다. 정확성 후보8/구심 신장9는 ZS/ZN-U 정의에 필요하지만, ABS 입력 감사 자체를 기다리게 할 이유는 아니다. 2024/2025 full prediction parquet은 이번 재생성하지 않았다. ZN-A 입력은 필요한 원천 열과 Call만으로 만들 수 있으며 APR p_swing/DeltaV 전체 재적합을 필수로 묶지 않는다.

sigma>0의 정규 오차에서 정확한 한 경계 접촉의 sigma→0 극한은.5이고, 정확히 sigma=0일 때 접촉 포함 규칙은1이다. 이를 동일한 “결정 극한”으로 구현하지 않는다. 면별 독립 민감도는 축약 max/min 하나가 아닌 두 면 각각의 구간 확률을 곱하거나 이변량 사각 확률로 계산한다.

B1의 추가 SD≈.003은 정규 Monte Carlo/분산 독립 등의 근사를 가정한 참고 계산으로, 체계적 차이의 상한 신뢰구간은 아니다. A1′는 고정 prior/가중·결측 노출과 성향 보고를 유지한다. BT의 미래 시즌 Y 표준화는 사후 시즌 상대 평가임을 명시하고, 미래 Y 평균/SD를 학습·예측 입력에 넣지 않는다. 이 후보들을 이번 적합하지 않았다.
