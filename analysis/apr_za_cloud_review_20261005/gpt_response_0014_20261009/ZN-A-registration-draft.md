# ZN-A 등록 초안: 규정 기하와 VB 존 대용값 조건부 q

**상태: 검토용 초안·미등록·미실행.** 이 파일은 gates.md 등록을 대체하지 않는다. 수치 기준/분할/라벨 규약을 고정한 뒤 STATUS ID 예약·창구 알림→gates 새 절 커밋/원격 게시→적합 순서로 진행한다. 과거 ZQ/ZL 및 gates의 실패 판정은 유지한다. 운영 채택과 별개다.

## 질문과 판정 범위

시즌별 공식 ABS 규정 경계와 VB 입력으로 구성한 모형이 관측 Take 콜과 얼마나 일치하며, 입력·오차 가정의 한계는 무엇인가? 선수별 ABS 설정 신장을 직접 확보한 실험이 아니므로 **규정 기하·VB 존 역산 대용값에 조건부인 모형**으로 표시한다. 실제 ABS 설정 신장 일치, 센서 정확도, 인과적 판단 능력, 운영 교체를 자동 주장하지 않는다. 학습은 실제 Take 콜이며 선수 참고각도나 프로필 신장을 정답 라벨로 쓰지 않는다.

## 입력 동결안

- 원천 커밋 `e48da3a26a617db67fbb51f6b1cbcb072b729eaf`. 시즌별 curated pitches tree:2024 `6c5238aa41b390f8c3ee199e81c648467fedc288`,2025 `163387d7c01633d0854c9a3a6efe8dc115d88580`,2026 `999567839db68cc4b0881b8c95213c40a15bd799`.
- summary→schema→curated.load_rows로 필요한 열만. 고정 metadata/loader 코드 blob·각 월 파일 SHA256·선택 행 digest·컷오프·설치 버전을 실행 manifest에 남긴다. 대형 입력을 새 원격 산출물로 중복 게시하지 않는다.
- 입력 행은 원 `pitch_id`, game_id/date/season, batter_id, 행동/콜 코드와 필요 품질 상태, 두 판정면에 필요한 궤적/보고 좌표, sz_top/bottom을 보존한다. 원 `pitch_id` 결측·중복은 입력 계약 실패로 보고한다. 기존 예측 파일의 투구 ID를 기하 키로 복원했다고 주장하지 않는다.
- 2026 기존 판단 적격 대조는 고정 예측 SHA256 `f754f18cc972775315be87eabd4fc88b3c873c420f8e439c0fea5ad13acdfe5f`,2026-10-03까지211,140구다. 이 파일은 이미 본 기준 대조이며 새 ZN-A 입력 자체는 원천에서 만든다.
- 2024·2025 full prediction parquet은 미생성 상태. 이 기하/콜 실험에 APR p_swing·DeltaV 전체 재적합은 필요 없다. 최종 ZA 비교가 이 값을 필요로 한다면 별도 재생성 코드·SHA·범위를 명시한다.
- 2024·2025의 기존5~9월 평가와2026 역사 자료는 재사용 평가다. 미래 자료를 제외한 새 확증이라고 이름 붙이지 않는다. 원천/학습 코드 버전 혼합을 금한다.

## 포함·제외와 분모

원천 전체→행/행동/콜 품질 적격→궤적/보고 위치→SZ 정합→학습 Take→평가/전체 행동을 순서별로 집계한다. 다중 사유 플래그와 고정 순서의 단일 사유 분모를 함께 낸다.

- 유효 궤적·유한 성분, 두 면 계산/물리적인 순방향 교차, 보고 위치 정합을 요구한다. 기존1cm 보고 위치 기준을 고정 출처와 함께 사용한다. 상승 궤적은 부호 있는 일반식으로 계산하며 상승이라는 이유만으로 버리지 않는다.
- SZ 결측, 비양수/상≤하단, 반올림 가정에서 상·하단 역산 허용 신장 구간이 겹치지 않으면 존 미확인이다. `lo=max((top−.0005)×30.48/rt,(bottom−.0005)×30.48/rb)`, `hi=min((top+.0005)×30.48/rt,(bottom+.0005)×30.48/rb)`, lo≤hi를 요구한다. .001ft 반올림 가정은 표시하고 절삭 가정은 민감도로 분리한다.
- 초안은 공통 신장의 구간 중점 H=(lo+hi)/2를 **고정 입력 복원 규칙**으로 제안한다. 이를 rt/rb에 곱해 중간면 기준을 만든다. 0.1cm 격자 포함/프로필 차이는 진단이며, 성능이 좋아지는 H를 찾아 선택하지 않는다. 이 복원 규칙 자체도 최종 gates에서 명시한다.
- 공유3.375/1.5ft 등 비정합값을 프로필/미래 ABS값으로 자동 보완하지 않는다. 미확인 q는0이나 틀린 판단으로 코딩하지 않는다. 선수별/시점별 제외 비중, 유지 투구 수·최소 표본 상태를 보고한다.
- 기존적격2026에서는SZ 부정합264구, ID56637는165/204구(80.9%)다. 따라서 전체 제외율만 보고 통과하지 않는다. 선수 비교에 필요한 지원 문턱은 ZS와 별도 정의한다.
- 주 Call 적합 표본은 투구가 있는 실제 Take의 CalledStrike/Ball이다. HBP·번트·자동 판정·장비 장애/구심 대체 등 별도 결과를 물리 존의 Ball로 자동 묶지 않는다. 분류 가능한 원천 태그와 제외/민감도 규칙을 최종 gates에서 고정한다. 대체 콜을 구분할 태그가 없으면 “순수 ABS 라벨”로 확정하지 않는다.

## 공식 경계·단위

상/하단 비율:2024 rt=.5635/rb=.2764,2025~2026 rt=.5575/rb=.2704. 좌우는 중간면±23.59cm, 끝면 기준은 중간면의 상/하단보다1.5cm 낮다. 원 규정 출처는 기존 abs_geometry_review.json과 kbo_abs_2026_supplement.json이다.

원천 x_mid,z_mid,z_back을 cm로 계산한다. 운영 x_mid_relative의1은25.4cm이고 공식 경계1이 아니다. 중간면과 끝면을 보존하고:

```
T_mid=z_mid−rt*H; T_back=z_back−(rt*H−1.5)
B_mid=z_mid−rb*H; B_back=z_back−(rb*H−1.5)
T=max(T_mid,T_back); B=min(B_mid,B_back)
```

부호 있는 delta=z_mid−z_back의 일반 이동식은 기존 값을 진단 대조할 때만 사용한다. 주 입력을 max/min gap에서 역복원하지 않는다.

## 공 크기·확률모형

`ball_rule_sources.json`:2024~2026 공식야구규칙3.01 둘레9~9¼in. 구형공 반지름3.638282~3.739345cm. 초안 주 rho=9.125×2.54/(2*pi)=3.6888136935cm, 민감도 양끝, 중심점 대조rho0. 실제 투구별 치수나 ABS 내부 반경을 확보했다는 뜻은 아니다. rho를 Call 손실로 고르거나 sigma/경계와 동시 추정하지 않는다.

주모형은 두 면에 완전히 공유하는 영평균 수직 정규 오차와 별도 독립 수평 정규 오차다. 공식 경계·rho·오차 평균은 고정하고 sigma_x/sigma_z만 학습 후보로 둔다. sigma는 유효 폭이며 순수 센서 정확도가 아니다.

```
qx=Phi((23.59+rho−x_mid)/sigma_x)−Phi((−23.59−rho−x_mid)/sigma_x)
qz=max(0,Phi((rho−T)/sigma_z)−Phi((−rho−B)/sigma_z))
q=qx*qz
```

빈 교집합은0이다. sigma=0의 정확한 결정 규칙은 경계 접촉 포함이다. sigma>0을0으로 보내는 극한은 정확한 경계에서.5가 될 수 있으므로 두 결과를 분리한다.

면별 독립 민감도는 qz_mid×qz_back이다. 각 면의 `[-rho−B_plane, rho−T_plane]` 구간을 별도 계산한다. 중간 상관은 이변량 정규 사각 확률을 사용하며, 공유 max/min 축약식을 독립 오차에도 그대로 쓰지 않는다. 주 가정과 민감도의 승자를 사후 바꿔 채택하지 않는다.

## 경계 오프셋 진단과 식별

주 q의 경계는 움직이지 않는다. 별도 진단에서 rho를 외부 고정하고 left/right/top/bottom 오프셋을 추정할 수 있으나 추정/보고 범위와 평균 바이어스 가정을 먼저 명시한다. rho와 자유 오프셋의 동시 적합은 금한다(동일 확률 변환 반례가 있음). 진단에서 맞춘 경계를 주 q에 되먹이지 않는다.

오프셋0 부근 일치의 표현은 “해당 오차모형·지정 반지름에서 콜과 규정 기하가 일관됨”이다. “실제 ABS 입력 신장 증명”이 아니다. 동등성 한계는 공 반지름 범위만으로 정하지 않고 목적상 허용 좌표 오차·불확실성 예산을 cm로 제시한다. CI 전체가 한계 안에 있어야 동등성 진단 통과다. 비유의성은 통과 조건이 아니다.

## 학습·평가 및 등록 전 확정 항목

1. **학습/평가:** 시즌별 sigma 추정인지 연도 간 공통 폭인지, 날짜 블록/경기 분할·기준 기간·출력 fold를 고정한다. 최소 단위는 경기다. 시험 Call을 sigma·오프셋·prior 선택에 쓰지 않는다. 교차적합이 미래 경기 학습을 허용하면 회고 평가로 표시하고 시간 일반화와 구별한다.
2. **비교:** 동일 평가 행에서 고정 공식 기하 주모형, 사전 고정한 rho/면별 상관 민감도, 기존 콜모형을 비교한다. 기존 q가 새 SZ 필터와 다른 행에서 적합/평가됐다면 수치를 곧바로 우열 비교하지 않는다. “센터점 대비 규정 contact” 대조는 진단이며 채택 후보를 추가하지 않는다.
3. **보고:** held-out log loss/Brier·경계별 보정, 물리 존 경계 주변 표본 수, 게임 군집 불확실성, 선수별 포함률·콜/행동 구성·좌표 잔차를 같이 낸다. 경계 진단은 다른 경계에서 충분히 떨어진 표본 정의를 사전 고정하고 꼭짓점은 별도 보고한다. Take 성능만으로 모든 Swing의 확률 정확도를 독립 입증했다고 쓰지 않는다.
4. **수치 gates:** 입력 계약(해시·grain·단위·q 범위·결측 처리), 학습/수렴 실패 규칙, 허용 성능 손실 및 CI 판정, 경계별 최소 지원·최대 보정 오차, 오프셋 동등성 한계·다중 진단 처리, 민감도 허용 변동을 수치로 고정해야 한다. **아직 확정되지 않았다.** 이번 이미 본 분모에 맞춰 유리한 기준을 사후 정했다고 숨기지 않는다.
5. **판정:** 주모형 기준 충족/실패/지원 부족 판정 불가를 나눈다. 실패·판정 불가는 결과와 원 등록을 보존한다. q_za 자동 대체·존 경계 재학습·운영 반영은 하지 않는다. 조건부 통과도 독립 확증이나 ABS 설정값 확보가 아니다.

정확성 후보8(A0/A1′)와 구심 신장9는 ZS/ZN-U의 정의 선택이다. 이 ABS 입력 감사·초안 작성에는 의존하지 않는다. ZS 주후보 범위를 사용자 답변 없이 고정하지 않는다.
