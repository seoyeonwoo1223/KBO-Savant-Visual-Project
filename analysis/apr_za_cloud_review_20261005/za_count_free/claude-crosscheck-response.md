## 확인된 사실

**0001-C1. ZC 구현에는 결과를 바꾸는 오류가 없다 (동의).**

- **재현:**
  - 2023 재적합 결과의 `players_2023.csv`가 커밋본과 바이트 단위로 같다. `results_2023.json`은 Python 패치 버전 표기(3.12.14 → 3.12.3)만 다르다.
  - 2022 재적합 p_swing의 SHA-256이 `results_2022.json`과 같다(`crosscheck_diagnostics.py`가 단언).
- **테스트·항등식:**
  - 합성 테스트 14개가 통과한다.
  - Z0 = N0 + SA·z̄와 D_q = N0/[2q̄(1 − q̄)]가 세 시즌 타자별 CSV에서 반올림 오차 안에서 성립한다.
  - N0·D_bin·D_q 영향함수와 G/(G − 1) 경기 SE는 공분산·비율 추정량의 표준 형태와 같다.
- **분리:**
  - q_za는 p 보정층에 들어가지 않는다. `run_experiment.py:180`은 q_call을 넘기고, 학습 블록 내부 보정은 `src/visualbaseball/zone_decision.py:391,401`의 카운트 포함 필드를 쓴다.
  - q_call 적합(`run_experiment.py:125-139`)은 운영 `predict_pzone`과 라벨·분류기·seed·clip이 같다.
- **절차:**
  - 사전 등록 `2036e4da`가 결과 커밋 `c89d1088`보다 먼저다. 그 뒤 `preregistration.md`는 바뀌지 않았다.
  - `f2d5b62f`는 교차검증 요청 문서만 추가했다.
- **서술:** 공개 집계 일치를 "투구별 동일성이 아님"으로 명시했다. ZA+ 표준편차 감소를 척도·수축 변화로 해석한 것도 맞다.

**0001-C2. 콜 손실 증가는 카운트별 양방향 콜 차이의 크기다 (부분 동의).**

|---|---|---|
| 0스트라이크 | +5.0 / +4.7%p | 각 약 1.5만 구 |
| 1스트라이크 | −4.7 / −4.9%p | |
| 2스트라이크 | −13.3 / −13.7%p | |
| 3볼 | +1.7 / +2.5%p | |

카운트 입력을 빼면 설계상 생기는 결과다. 콜 예측의 "악화"라기보다 제거한 카운트 정보의 크기로 읽어야 한다.

**0001-C3. q_za는 2스트라이크 비중이 높은 타자의 점수를 체계적으로 낮춘다. 최종 점수의 카운트 구성 상관이 줄어드는지는 시즌마다 다르다 (해석 추가).**

적격 타자 기준 Pearson이다.

| | 2022 | 2023 |
|---|---|---|
| (Z0_free − Z0_call)과 2스트라이크 비중 | −0.37 | −0.27 |
| (Z0_free − Z0_call)과 0스트라이크 비중 | +0.38 | +0.29 |
| 2스트라이크 비중과: Z0_call → Z0_free | +0.117 → +0.083 | −0.052 → −0.087 |
| 0스트라이크 비중과: Z0_call → Z0_free | −0.040 → −0.001 | +0.073 → +0.112 |

- "q의 카운트 불변"은 "점수의 카운트 구성 독립"을 보장하지 않고, 상관이 움직이는 방향도 시즌마다 다르다.
- 카운트 구성은 판단 능력의 결과이기도 하므로, 이 상관을 인공물이라고 단정하지 않는다.
- (정정) 채팅으로 먼저 보낸 답변의 "의존성이 커졌다"는 2023만의 결과였다.

**0001-C4. 개인 점수 변화는 대부분 SE 안이다 (해석 추가).**

| | 2022 | 2023 |
|---|---|---|
| \|Z0_free − Z0_call\| 표준편차 | 0.29 | 0.31 |
| Z0_call 평균 SE | 1.08 | 1.09 |
| 1 SE를 넘는 비율 | 1.2% | 0.6% |
| 0.5 SE를 넘는 비율 | 10.5% | 13.3% |

최대 23–29위 순위 이동은 점수가 촘촘한 중간 구간의 노이즈다.

**0001-C5. 반분 신뢰도는 2022에서 Z0_call이 유의하게 높다 (보완).**

같은 ID에서 Spearman–Brown 차이를 타자 bootstrap 2,000회(seed 20261005)로 계산했다.

| 차이 | 2022 | 2023 |
|---|---|---|
| Z0_call − Z0_free | +0.019 [0.010, 0.030] | +0.010 [−0.004, 0.025] |
| Z0_call − N0_free | +0.017 [0.004, 0.032] | +0.013 [−0.004, 0.030] |

- 문서의 "유의성 검정은 하지 않았다"를 이것으로 보완한다.
- 반분 신뢰도는 시즌 안에서 안정된 카운트 구성 성분도 신뢰도로 센다. 높다고 곧 좋은 측정은 아니다.
- 예측을 고정한 조건부 결과라는 한계는 그대로다.

**0001-C6. N0·D_q는 로짓 척도의 공격성을 중립화하지 않는다 (반대: "공격성 중립" 명명).**

위치 판단 능력 없이 logit(p) + a_i로만 더 휘두르는 귀무 타자를 만들었다. a_i는 mean σ(logit p + a_i) = mean S의 해다.

| 귀무 타자 기대 점수 | 2022 | 2023 | 2026 |
|---|---|---|---|
| N0와 SA의 Pearson | 0.89 | 0.91 | 0.89 |
| Z0와 SA의 Pearson | 0.50 | 0.66 | 0.67 |
| 관측 Z0 − 귀무 Z0와 SA의 Pearson | −0.16 | −0.04 | −0.08 |

- 귀무 점수의 SD는 관측 SD의 약 20%다(분산의 약 4%).
- 2023에서 SA 상관이 Z0_call .089 → Z0_free .115 → N0 .139로 커진 것은 이 성분으로 설명된다.
- 이 성분을 빼면 SA 상관이 0이 아니라 음수가 될 수 있다. 공격적인 타자가 실제로 존 판단이 나쁠 수 있기 때문이다.
- D_q는 N0를 타자별 상수로 나눈 값이라 같은 성분을 갖는다. N0·D_q를 "공격성 중립"이라고 부르지 않아야 한다. 같은 성분이 APR B에도 있다(GPT `preregistration-draft.md` B2와 같은 문제).

## 추가 자료 없이는 판정 불가

**0001-C7. q_za의 추정 대상이 불분명하고, 이 변경은 C1에서 정한 측정 정의를 되돌린다 (판정 불가, 사용자 결정 사항).**

- q_za ≈ Σ_c P(c | Take, x)·q(x, c)다. 위치마다 카운트 가중을 타자들의 Take 선택이 정하므로 물리 존도, 고정 카운트 표준화도 아니다.
- 구심 시즌에는 2스트라이크에서 실제로 좁아진 존을 활용한 Take가 q_za 아래에서 감점된다.
- gates.md C1이 구심 p_zone에 카운트를 넣으면서 측정 대상은 "그 카운트에서 실제로 적용된 심판 존과의 일치"가 되었다. 이를 되돌리는 것은 측정 정의 변경이며 사용자가 정한다.
- 어느 정의가 존 인식에 가까운지는 외부 라벨 없이는 판정할 수 없다. ABS 시즌의 규칙 존 ZA를 다리로 쓰는 ZQ1을 등록했다.
- 이 밖에 판정하지 못한 것:
  - 카운트 구성 상관이 인공물인지 능력인지
  - 재적합 불확실성
  - 2019–2021
