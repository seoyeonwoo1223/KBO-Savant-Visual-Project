# ZA 전용 카운트 입력 제거 실험

**ZA의 q만 카운트 입력을 제거하고, 카운트를 포함한 p_swing은 고정하는 실험을 구현했다.** 2022·2023 구심 시즌의 기존 집계 재현과 카운트 불변 검산이 통과했고, 2026 ABS 대조군은 q·Z0가 그대로다. 사용자가 선택한 범위인 별도 실험 브랜치의 구현·검증 결과다. 운영 코드·공개 JSON·APR·기존 gates는 변경하지 않았다.

명시적 카운트 제거는 확인됐지만 **순수한 물리 존 인식력 개선은 확인되지 않았다.** 구심 q는 계속 Take의 실제 콜로 학습한다. 카운트 제거 뒤 실제 콜 예측 손실은 두 시즌 모두 증가했다. 구현 목표와 콜 예측 목표를 구분하고, 이 실험을 운영 채택 완료로 해석하지 않는다.

## 구현과 기준

기준 커밋은 `6495992497af77df9abef861d235443a3302f130`, 브랜치는 `experiment/za-count-free-20261005`다. 직전 교차검토 커밋 `de8f7b53`에서 분기하고, 첫 후보 적합 전에 [실험 계약](preregistration.md)을 `2036e4dad9fa60ff638873bfd81e796425c66146`으로 커밋했다. 시작 시 갱신된 원격 master의 주요 산식 소스는 기준과 같았으며, 새 데이터는 혼합하지 않았다.

현재 운영 코드에서는 같은 p_zone이 p_swing의 존 안팎 isotonic 보정에도 쓰인다. 이 q를 통째로 바꾸면 p_swing도 달라져 APR까지 영향을 받는다. 실험에서는 다음 두 경로를 분리했다.

- `q_call`: 기존 카운트 포함 구심 콜 모형. p_swing의 원래 보정에 계속 사용한다.
- `q_za`: ZA의 존 축에만 사용하는 별도 모형. 구심 입력은 `x_relative,z_relative,sz_top,sz_bottom`이다. 카운트 필드를 제외하고 기존 HGB·5 seed·3 날짜 블록을 유지한다.
- `p_swing`: 운영 함수의 propensity·보정 부분을 AST로 추출해 재사용한다. 카운트 입력과 q_call 기준의 보정층을 유지하고 모든 후보에서 동일한 배열을 쓴다.
- ABS: 기존 중간/후면 좌표 입력이 이미 카운트를 보지 않으므로 저장 예측의 q를 재사용한다.

ΔV·RE·사건/가치 모형을 적합하지 않았고, 운영 writer를 호출하지 않았다. [run_experiment.py](run_experiment.py)가 이 분리를 실행하고, [metrics.py](metrics.py)가 고정 예측의 원점수와 공동 영향함수 SE를 계산한다.

2022·2023은 명시적 월별 curated pitches/events와 필요한 컬럼만 읽어 기존 자격·반이닝 신뢰도·손·무브먼트 처리를 재현했다. 2026은 10월 3일까지의 저장 예측이다. 입력 읽기는 summary → schema → 명시적 월별 경로 순서이며 partition-index나 data/web/data glob은 사용하지 않았다.

동일 입력 위치의 카운트를 0-0과 3-2로 바꾼 구심 q_za 검산에서 차이는 0이었다. 후보 간 p_swing 배열 변경과 ABS q 변경도 0이었다. 입력 파일별 SHA-256·버전·블록·예측 배열 해시는 `results_2022.json`, `results_2023.json`, `results_2026.json`에 있다.

## 카운트 제거에 따른 q 변화와 콜 예측 비용

| 항목 | 2022 | 2023 | 2026 |
|---|---:|---:|---:|
| 전체 투구 평균 \|q_za−q_call\| | 0.027609 | 0.027572 | 0 |
| q=.5 안팎 구분이 바뀐 비율 | 2.4747% | 2.6093% | 0% |
| Take log loss: 기존 → 제거 | 0.167620 → 0.171493 | 0.164659 → 0.168890 | 동일 |
| Take Brier: 기존 → 제거 | 0.052168 → 0.053526 | 0.050837 → 0.052311 | 동일 |
| 경계 2스트라이크 관측−q_za | −13.34%p | −13.66%p | 해당 비교 없음 |

경계 표본은 **기존 q_call .1–.9의 Take**로 고정했다. 2스트라이크 경계 표본은 각각 3,443·3,192구이며 기존 q_call의 관측−예측은 −0.95·−1.00%p다. 카운트 제거 모형이 실제 구심 콜을 과대예측하는 차이가 커졌다. 이 수치는 물리 라벨에 대한 오류를 측정한 것이 아니다.

같은 위치의 q를 고정하려는 목표와 실제 카운트별 콜 예측 목표는 다르다. 기존 C1 콜 예측 검증에서 불리한 결과를 인정하며, 기존 gates의 목적·문턱을 사후 수정하지 않는다. [comparison.json](comparison.json)의 paired_call_cost는 적합 뒤 추가한 기술통계로, 고정 예측의 경기 군집 SE만 반영하며 채택 기준으로 쓰지 않는다.

## 후보 정의와 비교

`r=S−p_swing`, `z=2q_za−1`이며 평균과 공분산의 분모는 n이다.

| 후보 | 원점수 | 해석 |
|---|---|---|
| Z0_call | 100 E[r(2q_call−1)] | 현행 대조 |
| Z0_free | 100 E[rz] | q의 카운트 입력만 제거 |
| N0_free | 100 Cov_n(r,z) | 타자 내 평균 잔차 스윙 성향 제거 |
| D_bin | 100{E[r\|q≥.5]−E[r\|q<.5]} | 안팎 잔차를 같은 비중으로 비교 |
| D_q | 100{E[qr]/E[q]−E[(1−q)r]/E[1−q]} | 확률로 안팎 구성을 표준화 |
| P0_free | 100 E[(2S−1)z] | 리그 정책을 빼지 않은 일치 마진 대조 |

전체는 300구 이상, D_bin은 안팎 각각 50구·10경기, D_q는 양쪽 Kish ESS 50 이상과 .1≤q 평균≤.9다. 세 시즌 전체 적격 선수 **162·173·166명 모두 여섯 후보의 공통 지원 조건을 통과**했다. 반분은 시즌 전체 정렬 경기 코드 홀짝이며 각 절반 150구, D_bin 안팎 각각 25구·5경기, D_q 양쪽 ESS 25 이상이다. 후보별과 공통 ID에서 동일 선수의 Z0_call을 함께 비교했다.

후보별 수치는 [candidate_comparison.csv](candidate_comparison.csv), 지원·공통 표본·반분·상관의 상세값은 [comparison.json](comparison.json), 타자별 점수·SE·구성·원순위 변화는 `player_comparison_2022.csv`, `player_comparison_2023.csv`, `player_comparison_2026.csv`에 있다. 단위가 다른 후보의 SD·SE 크기를 직접적인 성능 우열로 비교하지 않는다.

동일 선수의 반분 Pearson을 Spearman–Brown으로 환산한 값은 다음과 같다. 세 시즌 반분 공통 지원은 각각 155·165·161명이다.

| 후보 | 2022 | 2023 | 2026 |
|---|---:|---:|---:|
| Z0_call | 0.840 | 0.788 | 0.827 |
| Z0_free | 0.821 | 0.778 | 0.827 |
| N0_free | 0.823 | 0.775 | 0.823 |
| D_bin | 0.771 | 0.741 | 0.821 |
| D_q | 0.823 | 0.774 | 0.822 |

카운트 제거에 따라 구심 Z0의 반분 값은 소폭 낮아졌고, D_bin/P0의 값은 더 낮았다. 이 차이에 대한 독립적인 유의성 검정은 하지 않았다. N0/D_q가 측정 정의에 주는 차이는 있지만 이 자료에서 뚜렷한 신뢰도 개선은 확인되지 않았다.

Z0_free와 Z0_call의 적격 선수 원점수 순위 상관은 **2022 0.99323, 2023 0.99237**다. 평균 절대 점수 변화는 **0.2315·0.2341%p**, 최대 원순위 변화는 **23·29위**다. 작은 전체 변화와 일부 선수의 큰 순위 이동이 함께 나타났으며 개인 능력 변화 검정으로 해석하지 않는다.

N0의 상수 잔차 이동 불변성은 선수 간 SA 무상관을 보장하지 않는다. 2023 SA Pearson은 Z0_call 0.0885 → Z0_free 0.1152 → N0_free 0.1386이었고, APR Spearman은 0.6875 → 0.7034 → 0.7084였다. 낮은 상관을 만들기 위해 산식을 선택하거나 APR 관련성을 제거하지 않았다.

## Z0의 ZA+ 척도 민감도

[plus_sensitivity.py](plus_sensitivity.py)는 Z0_call과 Z0_free 각각의 M·중심·k를 계산해 운영 `_plus_index`를 그대로 적용한다. 현행과 같은 6자리 입력·SE 반올림과 **G 보정 전 SE**를 사용해 q 변경만 분리했다. 모든 타자의 기존 ZA+·백분위·입력·SE는 세 시즌 공개값과 반올림 후 완전히 같았다. 후보 원점수 표의 SE는 G/(G−1) 보정을 포함하므로 이 민감도 계산의 현행 SE와 구분한다.

| 항목 | 2022 기존 → 제거 | 2023 기존 → 제거 |
|---|---:|---:|
| M | 35.0756 → 37.6413 | 34.3679 → 36.9807 |
| k(투구) | 160.770 → 179.024 | 183.165 → 202.995 |
| 적격 ZA+ SD | 13.776 → 12.062 | 13.080 → 11.457 |
| 적격 ZA+ 순위 상관 | 0.99323 | 0.99273 |
| 최대 절대 ZA+ 점수 변화 | 6.7094 | 6.4225 |

2026은 M·k·ZA+가 모두 같고 최대 점수 변화도 0이다. 구심은 q 변경에 따른 원점수 분포·M·k 변화가 함께 반영되어 지수 분산이 줄었다. 이는 척도와 수축의 변화이며 능력 측정 개선의 증거가 아니다. N0/D/P0에는 이 M이나 ZA+를 적용하지 않았다.

## 해석과 후속 권고

먼저 Z0_free를 **q 분리 구현의 기준 후보**로 유지하고, 평균 공격성 성분까지 분리할지 결정할 때 N0_free를 병행하는 방향을 권한다. 구성 표준화 D_bin/D_q와 정책 미차감 P0는 대조 후보로 유지한다. 이번의 상관·반분·순위 결과로 자동 선정하지 않았다.

`Z0_free=N0_free+SA×mean(z)`이므로 N0는 평균 성향 성분을 버리는 별도 정의다. `D_q=N0_free/[2 q̄(1−q̄)]`라서 두 후보는 서로 다른 새로운 정보를 만들어내기보다 받은 존 확률 구성에 따라 척도가 달라진다. 이진 q에서는 `N0=2π(1−π)D_bin`이다. 반분은 예측과 겹치는 학습 표본을 고정한 기술통계이며 독립적인 미래 신뢰도 검증이 아니다.

results의 `scores.N0_free`는 **시즌 전체 투구를 하나의 집단으로 중심화한 공분산**이다. comparison의 `all_player_pitch_weighted_means.N0_free`는 **타자별 중심화 후 투구 가중 평균**이다. 예를 들어 2022는 −0.02551과 +0.12580으로 다르다. 둘을 같은 리그 평균으로 표시하지 않는다.

구심 q_za에는 Take 선택, 심판·포수, 훈련 카운트 구성의 영향이 남는다. 구심의 앞면 좌표와 ABS의 중간/후면 좌표도 다르다. 지역 평균은 관측 구성의 요약일 뿐이며, HGB는 가운데→경계→바깥으로의 단조성을 강제하지 않는다. 따라서 “가운데 큰 양수·경계 0·멀리 바깥 큰 음수”는 `z=2q−1`의 해석이지 모든 궤적에 대해 검증된 기하학적 법칙은 아니다.

기하학적 섀도 띠 전체가 q=.5인 것도 아니다. 실제 지역별 z 평균은 아래와 같으며 특히 ABS는 섀도 안쪽의 대부분을 거의 확실한 스트라이크로 본다. q=.5 부근과 표시용 섀도 구역을 구분해야 한다.

| 지역 | 2023 q_za의 평균 z | 2026 평균 z |
|---|---:|---:|
| heart | +0.9732 | +0.9982 |
| shadow_in | +0.5692 | +0.9530 |
| shadow_out | −0.5506 | −0.4481 |
| chase | −0.9850 | −0.9997 |
| waste | −0.9994 | −0.9998 |

운영 채택 전에 2019–2026 전체 재검증, 독립적인 물리 존 라벨/경계 공간 검증, 구심·ABS 좌표와 높이·fallback 점검이 필요하다. 순수 지각 능력을 주장하려면 행동만으로 관찰되지 않는 카운트 전략·인지의 분리를 검증할 근거도 필요하다. 이 단계에서는 두 구심 시즌과 ABS 대조군의 실험을 완료했고 그 이상의 검증은 수행하지 않았다.

## 실행과 재현

Python 3.12.14에서 `constraints-za.txt`의 여섯 패키지 버전을 사용했다. 저장 결과의 base 소스와 입력 해시가 맞아야 한다.

```bash
python3.12 -m venv /tmp/za-count-free-venv
/tmp/za-count-free-venv/bin/pip install -r constraints-za.txt
PYTHONPATH=src OMP_NUM_THREADS=2 PYTHONDONTWRITEBYTECODE=1 /tmp/za-count-free-venv/bin/python analysis/apr_za_cloud_review_20261005/za_count_free/run_experiment.py --seasons 2023 2026
PYTHONPATH=src OMP_NUM_THREADS=2 PYTHONDONTWRITEBYTECODE=1 /tmp/za-count-free-venv/bin/python analysis/apr_za_cloud_review_20261005/za_count_free/run_experiment.py --seasons 2022
PYTHONPATH=src OMP_NUM_THREADS=2 PYTHONDONTWRITEBYTECODE=1 /tmp/za-count-free-venv/bin/python analysis/apr_za_cloud_review_20261005/za_count_free/summarize.py
PYTHONPATH=src OMP_NUM_THREADS=2 PYTHONDONTWRITEBYTECODE=1 /tmp/za-count-free-venv/bin/python -m unittest discover -s analysis/apr_za_cloud_review_20261005/za_count_free -p 'test_*.py' -v
```

캐시가 없으면 두 구심 시즌의 모형을 다시 적합한다. 캐시는 이 하위 폴더의 무시된 `cache/`에 저장하며 Git에는 넣지 않는다. 캐시 키는 읽은 입력 전체·runner SHA·fields·model·seeds에 묶인다. summarize는 입력 해시, 캐시 키, 적격 행 수, p_swing 해시를 먼저 검산하고 새 모형을 적합하지 않는다. 합성 테스트는 후보 항등식·상수 이동 불변·공동 IF·경기 SE·지원 제한·분할·원 p_swing 보정 경로를 검증한다. 실행별 종료 상태와 최종 검산은 [execution.json](execution.json)에 남긴다.

IF는 분포 오염에 대한 중앙 유한차분(6자리 허용오차)과 complex-step 미분(절대오차 1e−10)을 별도로 검산했다. 항등식·카운트/상수 이동 불변성의 1e−10 기준과 유한차분의 허용오차를 혼동하지 않는다.
