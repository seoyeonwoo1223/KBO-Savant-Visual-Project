# ZA 카운트 입력 제거 실험 — 결과 요약 및 독립 교차검증 요청

정리일: 2026-10-06(한국시간). 아래는 이미 실행된 실험의 검토 요청이며, 새 후보 채택이나 운영 반영을 요청하는 문서가 아니다.

## 1. 먼저 확인할 결론

**카운트 편향을 완전히 제거했다는 결론은 내리지 않았다.** 구현한 것은 **ZA의 존 축 `q_za`에서 명시적 카운트 입력을 제거하는 것**이다. `p_swing`의 카운트 입력과 기존 존별 보정은 의도적으로 유지했다. 따라서 같은 위치라도 카운트가 달라지면 최종 ZA 기여값은 달라질 수 있다.

카운트 영향이 남았다는 사실과 통계적 편향이 입증됐다는 주장은 구분해야 한다. 보호 스윙 등 정상적인 카운트 전략을 보정하려는 영향도 있다. 반대로 입력을 제거했다고 심판의 카운트별 콜 성향·Take 선택의 영향을 모두 제거한 것도 아니다.

| 구분 | 이번 처리 | 확인된 범위 |
|---|---|---|
| q_za의 카운트 입력 | 제거 | 같은 위치·존 경계에서 카운트만 바꾸면 q 불변 |
| p_swing의 카운트 입력 | 유지 | 카운트별 리그 스윙 전략을 기준으로 사용 |
| p_swing의 기존 q_call 기반 존별 보정 | 유지 | q 변경이 p와 APR까지 바꾸는 결합을 피함 |
| 학습 콜 라벨·Take 선택의 간접 영향 | 남을 수 있음 | 제거·식별을 검증하지 않음 |
| 타자별 받은 카운트 구성의 영향 | 완전 제거 아님 | N0/D 후보도 카운트×위치 공동 구성을 전부 표준화하지 않음 |
| 실제 지각 능력과 전략적 행동의 분리 | 미확인 | 독립적인 물리·인지 기준이 없음 |

## 2. 목표와 구현

APR은 상황별 선택 가치를 유지하고, ZA는 득점 가치 가중 없이 존 안팎에 맞춘 선택을 보도록 분리하려는 작업이다. 이번에는 ZA 실험만 실행했다.

`S`는 스윙 여부, `p`는 리그 p_swing, `q`는 존 확률, `r=S−p`, `z=2q−1`이다. 기존 ZA는 `100 mean[r(2q_call−1)]`이다.

- 구심 `q_call`: 위치·존 경계·balls_before·strikes_before로 Take의 CalledStrike 대 Ball/HBP를 학습하는 기존 모형.
- 구심 `q_za`: 같은 학습 대상에서 카운트 필드만 제외. 입력은 `x_relative,z_relative,sz_top,sz_bottom`. 기존 HGB, 5 seed, 3 날짜 교차적합 블록을 유지.
- `p`: 카운트 입력과 기존 q_call 기준 isotonic 보정을 유지. 모든 후보에 같은 p 배열을 사용.
- ABS: 기존 중간/후면 존 입력이 카운트를 보지 않으므로 2026 저장 예측을 재사용. 새 적합을 하지 않음.

고정된 S와 위치에서 카운트에 따른 p만 바뀌면, 투구 기여값의 변화는 `−100 × (p₂−p₁) × z`다. **q가 카운트 불변이어도 점수 자체가 카운트 불변인 것은 아니다.**

구심 q_za는 여전히 실제 콜 모형이다. 이상적인 조건부확률로 설명하면 카운트별 콜 확률을 **해당 위치에서 Take된 공의 카운트 구성으로 평균낸 값**에 가깝다. 입력 제거는 이 평균을 모든 카운트에 공통으로 적용하게 하지만, 물리적인 규칙 존을 새로 정의하지 않는다. 이것은 모형 목표에 대한 설명이며, 신경·지각 능력이나 인과적 편향 제거의 증명이 아니다.

## 3. 자료와 구현 검산

| 시즌 | 시대 | 판단 투구 | 타자 | 300구 이상 | 경기 |

| 2022 | 구심 | 213,888 | 279 | 162 | 714 |
| 2023 | 구심 | 214,504 | 293 | 173 | 708 |

2026은 저장 자료 기준 10월 3일까지다. 구심은 월별 curated에서 기존 자격·전처리와 p/q 경로를 재현했다. ΔV·RE·사건/가치 모형은 적합하지 않았다. 운영 코드·공개 산출물·APR·기존 gates는 변경하지 않았다.

세 시즌 공개 타자 집합·투구 수가 일치했고, SA·ZA raw·현행 SE의 최대 차이는 5×10⁻⁷ 미만이었다. 기존 ZA+·백분위·입력·SE도 6자리 반올림 후 완전히 재현했다. **구심은 집계 재현이지 과거 운영 투구별 예측의 완전 동일성 검증은 아니다.** 2026은 저장 예측 재사용 검증이다.

구심 동일 위치의 카운트를 0-0/3-2로 바꾼 q_za 차이, 후보 간 p 변경, ABS q 변경은 모두 0이었다. 합성 테스트 14개가 통과했다. 항등식·불변성·공동 영향함수·군집 SE·지원 제한·p 보정 경로를 검사했으며, IF는 complex-step 절대오차 1e−10과 중앙 유한차분 6자리 허용오차를 구분했다.

## 5. 비교 후보와 안정성

| 후보 | 정의 | 반분 Spearman–Brown: 2022 / 2023 / 2026 |
|---|---|---|
| Z0_call | 100 mean[r(2q_call−1)] | .840 / .788 / .827 |
| Z0_free | 100 mean[rz] | .821 / .778 / .827 |
| N0_free | 100 Cov_n(r,z) | .823 / .775 / .823 |
| D_bin | 100{mean(r\|q≥.5)−mean(r\|q<.5)} | .771 / .741 / .821 |
| D_q | 100{mean(qr)/mean(q)−mean((1−q)r)/mean(1−q)} | .823 / .774 / .822 |
| P0_free | 100 mean[(2S−1)z] | .792 / .728 / .761 |

전체 기준은 300구, D_bin은 안팎 각 50구·10경기, D_q는 양쪽 Kish ESS 50 이상과 .1≤mean(q)≤.9다. 전체 적격 162/173/166명 모두 공통 지원을 통과했다. 반분은 시즌 전체 정렬 경기 코드 홀짝이며 각 절반 150구, D_bin 각 25구·5경기, D_q 양쪽 ESS 25 이상이다. 반분 공통 지원은 155/165/161명이며 같은 선수의 기존 점수와 비교했다.

반분은 예측을 고정하며 교차적합 학습 표본도 겹친다. 독립적인 미래 검증이 아니고, 작은 차이에 대한 우열 검정도 하지 않았다. N0/D_q가 기존보다 뚜렷하게 안정적이라는 증거는 없다.

`Z0_free=N0_free+SA×mean(z)`, `D_q=N0_free/[2 q̄(1−q̄)]`다. N0의 상수 잔차 이동 불변성은 선수 간 SA 무상관을 보장하지 않는다. 2023 SA Pearson은 기존 .0885 → Z0_free .1152 → N0_free .1386이었다. 상관 감소를 목표로 후보를 선정하지 않았다.

Z0에만 별도 M·중심·k로 ZA+ 민감도를 계산했다. 2022/2023 M은 35.0756→37.6413 / 34.3679→36.9807, k는 160.770→179.024 / 183.165→202.995로 바뀌었다. 원점수 분포·척도·수축 변화가 함께 반영돼 적격 ZA+ SD가 13.776→12.062 / 13.080→11.457로 줄었다. 이를 측정 개선으로 해석하지 않았고, N0/D/P0에는 같은 M을 적용하지 않았다. 2026 Z0·ZA+는 완전히 동일했다.

## 6. 아직 입증하지 않은 것

- 카운트별 최종 ZA의 불변성, 선수별 받은 카운트 구성에 대한 완전한 표준화.
- Take 선택과 심판·포수 영향을 제거한 물리 존 확률, 인지와 전략의 분리.
- 모든 위치에서 가운데→경계→바깥으로의 단조성. q=.5 부근과 기하학적 섀도 띠는 같지 않다.
- 구심 앞면 좌표와 ABS 중간/후면 좌표의 완전한 동등성.
- 2019–2026 전체 gates 통과, 독립적인 물리·인지 라벨 검증.

현재 권고는 Z0_free를 **q 분리 구현의 기준 후보**로 두고 N0를 병행 검토하는 것이다. 운영 채택이나 순수 인지 지표라는 선언은 하지 않았다.

## 7. Claude에 요청하는 검토

위 결론을 전제로 승인하지 말고, 코드·원자료 기록·결과를 독립적으로 확인해 달라. 특히 다음을 검토해 달라.

1. **측정 정의:** p의 카운트 전략 보정을 유지한 채 q만 카운트 불변으로 만드는 것이 원하는 ZA 정의에 맞는가? 카운트 영향과 통계적 편향을 구분한 설명이 타당한가?
2. **남는 경로:** Take 콜을 학습한 q_za의 간접 카운트 영향·선택 문제·카운트 구성 의존성을 과소평가했는가? 물리적 규칙 존 또는 고정 카운트 분포로 표준화한 콜 존이 다른 목표로 필요한가?
3. **구현 분리:** q_za가 p의 보정층에 새로 들어가지 않는지, 기존 q_call·p 경로가 보존됐는지 확인해 달라. 공개 집계 일치를 투구별 동일성으로 과장하지 않았는지도 확인해 달라.
4. **산식·불확실성:** N0/D 항등식과 공동 영향함수, 경기 SE, 같은 선수의 반분 비교, 후보 지원 조건이 정확한가? 모델 추정 불확실성을 빠뜨린 한계를 충분히 설명했는가?
5. **결과 해석:** 콜 손실 증가·반분 값 감소·높은 순위 상관이 실제로 무엇을 지지하는가? N0/D_q의 구성 표준화나 ZA+ 분산 감소를 과장했는가?
6. **다음 실험:** 이 자료로 답할 수 없는 핵심 문제를 해결할 최소 후속 실험을 우선순위 3개로 제안해 달라. 새 실험 제안과 이미 확인된 결과를 구분해 달라.

답변은 `확인된 사실 / 구현 오류 가능성 / 해석 수정 / 추가 자료 없이는 판정 불가 / 후속 실험`으로 구분하고, 코드에 접근하지 못했다면 문서·산식만 검토했다고 밝혀 달라.
