# ZA 카운트 입력 제거 실험 계약 — 첫 적합 전 고정

사용자가 선택한 범위는 **실험 브랜치 구현·검증까지**다. 운영 코드·공개 데이터·기존 gates·APR은 변경하지 않는다. 기존 검토의 신규 후보 미실행 제한은 완료된 검토의 범위였으며 이번에는 아래 ZA 실험을 별도로 요청받았다. 외부 비공개 수치·대조점·분석자 표기는 남기지 않는다.

기준은 이전 검토와 같은 `6495992497af77df9abef861d235443a3302f130`, 브랜치는 `experiment/za-count-free-20261005`다. 시작 시 원격 master가 `1b6655d1`로 갱신된 것을 확인했고 주요 산식 소스·constraints·기존 gates는 기준과 같았다. 데이터 갱신을 혼합하지 않고 고정 스냅샷에서 실행한다.

## 목적과 결합 분리

ZA의 존 축에서 **명시적 카운트 입력을 제거**한다. 구심 `q_za`는 `(x_relative,z_relative,sz_top,sz_bottom)`, ABS는 기존 `(x_mid_relative,top_gap_cm,bottom_gap_cm)`다. 위치와 존 경계가 같으면 카운트만 달라져도 같은 q_za를 반환해야 한다. 기존 HGB·5 seed·3 날짜 블록을 유지한다. 단조적 공간축이나 순수 물리 존을 증명하는 실험은 아니다.

기존 q_call과 카운트를 포함한 p_swing의 원 모형·존별 isotonic 보정은 보존한다. 보정층에 q_za를 넣지 않는다. q_call을 직접 교체하면 p_swing도 변하는 현재 결합을 피한다. r=S−p_swing를 고정한 채 ZA에 곱할 q만 바꾼다. ΔV·사건/가치 모형은 적합하지 않는다. count-free 구심 콜 모형은 Take 선택·심판·포수·훈련 카운트 구성의 영향을 여전히 받으므로 “순수 존 인식력”이라는 채택 선언을 하지 않는다.

## 자료와 실행 범위

구심은 월별 curated와 워크북이 있는 **2022·2023 전체 판단 적격 투구**, ABS 음성 대조는 저장 판단 parquet이 있는 **2026 마감 10월 3일**을 사용한다. 2019–2021/2024–2025 전체 파이프라인을 재생성하지 않는다. 두 구심 시즌의 기존 p_swing·q_call 부분만 재현하며 ΔV/RE 가치 적합·과거 metrics parquet 재생성은 하지 않는다.

summary → schema → summary의 명시적 월별 pitches/events 경로와 필요한 컬럼 순으로 읽는다. partition-index와 data/web/data glob은 사용하지 않는다. 모든 입력 경로·SHA-256·건수·버전·seed·블록을 기록한다. 기존 reliable-halves/자격/손/무브먼트 규칙을 재사용하며 공개 leaderboard의 판단 투구 수·SA·ZA raw·SE와 일치 여부를 확인한다. 미일치 시즌은 결과를 생성해도 하네스 한정으로 표시하고 공개 모형의 비교 근거로 채택하지 않는다.

조건: constraints-za.txt 고정 여섯 버전, Python 3.12.14, PYTHONPATH=src, OMP_NUM_THREADS=2, 바이트코드 쓰기 금지. 결과·캐시는 이 분석 경로 또는 /tmp에만 저장한다. 공개 산출물 writer는 호출하지 않는다.

## 후보와 지지 제한

r=S−p, z=2q_za−1이다. 아래는 기존 검토의 정의를 재사용하며 거리/득점 비용 가중 후보는 추가하지 않는다.

| 후보 | 원점수 |
|---|---|
| Z0_call | 100 mean(r(2q_call−1)), 운영 대조 |
| Z0_free | 100 mean(rz), q 카운트 입력만 제거 |
| N0_free | 100 Cov_n(r,z), 타자 평균 잔차 중립 |
| D_bin | 100{mean(r\|q≥.5)−mean(r\|q<.5)} |
| D_q | 100{mean(qr)/mean(q)−mean((1−q)r)/mean(1−q)} |
| P0_free | 100 mean((2S−1)z), 리그 정책을 제거하지 않은 일치 마진 대조 |

모두 n≥300을 기본으로 한다. D_bin은 안팎 각 50구·10경기 이상, D_q는 ESS(q)·ESS(1−q)≥50와 .10≤mean(q)≤.90을 추가한다. 각 반분은 n≥150, D_bin 안팎 각 25구·5경기, D_q 양쪽 ESS≥25와 같은 q 평균 범위다. 전체와 공통 지지 집합의 결과를 모두 보고하고 지원 제한에 따른 제외 인원을 공개한다. q의 분산과 퇴화는 따로 기록한다.

## 고정할 검증·보고

필수 구현 검산은 (1) q 카운트 반사실 불변, (2) p_swing 고정, (3) ABS q 변경 없음, (4) N0/D의 상수 r 이동 불변, (5) D_q=N0/[2q̄(1−q̄)], (6) 이진 q에서 N0=2π(1−π)D_bin, (7) 공동 IF의 미분 검산이다. 소스상 feature/분리 규칙도 검사한다. 산술 오차는 1e−10 이내, 공개 반올림 집계 비교는 1e−4 이내로 고정한다.

q_call/free의 held-out Take log loss·Brier, baseline q_call .1–.9 경계 Take의 카운트별 보정오차, 선수 원점수·SE·표본/구성·SA/APR 관련성, 동일 선수 경기 홀짝 반분 Pearson의 Spearman-Brown, 전후 rank 이동을 보고한다. SE는 **예측 고정 공동 영향함수**의 경기 합이며 G/(G−1) 보정을 구분한다. 순위 변화는 불확실성이 포함된 기술통계이지 개별 선수 능력 변화의 검정이 아니다.

Z0_free의 ZA+ 민감도만 새 q의 리그 M·중심·SE·k로 독립 계산할 수 있다. N0/D/P0에는 현행 M을 자동 적용하지 않고 원점수 척도로 비교한다. score shape 비교는 같은 표본에서 하며 단위가 다른 원점수 크기를 능력 개선으로 해석하지 않는다.

**이번에 채택할 후보를 성능 수치로 자동 선정하지 않는다.** 역사적 C1은 실제 심판 콜 예측 목적이고 이번에는 명시적 카운트 불변이라는 목표가 달라진다. 기존 C1/ZG 기준을 사후 뒤집거나 qfree가 콜 log loss에서 이겼다는 주장으로 목표 변경을 정당화하지 않는다. 신뢰도·SA/APR 상관 감소만으로 성공을 선언하지 않는다. 8시즌 게이트/독립 물리 라벨/외부 인지 기준은 여기서 미측정이며 별도 검증이 필요하다.

실험 결과 뒤에는 카운트 불변 구현 완료 여부, 콜 예측 비용, 구성 표준화의 지지·신뢰도·분산 비용, 순수 인지 해석의 한계를 종합해 후속 권고를 작성한다. 유리한 결과를 만들기 위해 지원 제한·후보·문턱을 변경하지 않는다.
