# APR·ZA 0009 검토와 조건부 표준오차 검증

## 범위와 판정

현재 원격 운영 버전은 기존 기준과 같다. 0009 신장 결측 정정과 정확성 대수를 독립 검산하고, 사용자 선택에 따라 KBO 공식 신장을 수집했다. B1은 창구 ID 예약 → gates 사전등록 원격 커밋 `be8b84b301ba8d0159098d756e724491f263f9a6` → 실행 순서다. 운영 파일·공개 산출물·상대 결과·과거 gates 절은 바꾸지 않았다.

**확인 범위 내 조건부 SE 검증은 기준 충족, 전체 B1·운영 채택 판정은 보류**다. 실제 선수의 참값 포함률, 전체 모형 재적합, 시즌 공동 지수 bootstrap, 전시즌 검증, 작은 G 구간과 로짓 성향 이름 검증은 완료되지 않았다. 기존 역사 자료와 합성 모의실험을 새 독립 확증으로 부르지 않는다.

## 신장 수집

고정 `player_bio`의1,379개 ID(투수 포함)를 KBO 공식 프로필에서 조회했다. 이름 완전 일치·유효 신장을 확보한 ID는1,373개, 공식0cm/0kg 등 신장 미확보4개, 이름 불일치2개다. 판단 적격 타자의 시즌별 포함률과는 다른 분모다.

출처 URL·공식 페이지 이름·원문 신장/체중 표기·HTML SHA·조회일(한국시간2026-10-09)·성공/실패 상태를 `kbo_heights.json`에 보존했다. 원자료는 현재 프로필 스냅샷이며 과거 시즌 당시 등록 신장이나 ABS 시스템에 입력된 신장과의 일치를 입증하지 않는다. 미확보·이름 불일치는 신장을0으로 넣거나 미래 ABS 존으로 자동 보완하지 않았다. `data/` 선수 파일은 변경하지 않았다.

## 공식 ABS 규격 검토

공식 발표 원문과 안내 PDF(2024), 2025 변경 발표, 현재2026 주요 규정 웹 본문·이미지를 직접 확인했다. 시즌별 신장 비율은2024 상단56.35%/하단27.64%, 2025~2026 상단55.75%/하단27.04%다. 좌우는 중간면, 홈플레이트43.18cm에각2cm 확장. 상하는 중간면·끝면 모두 통과, 끝면 높이 기준은1.5cm 낮다. 경계 접촉 규칙을 확인했으며 정확한 시즌별 공 반지름과 VB/ABS 측정 정합은 미확인이다.

0009가 인용한 현행 함수는 두 판정면에 동일 높이 기준을 적용한다. 이를 공식 고정 경계 구현으로 그대로 사용할 수 없다. 2026 페이지의 본문·실제 그림은 맞지만 이미지 alt에는 이전 비율이 남아 있다. `kbo_abs_2026_supplement.json`이0010 이후 새로 확보한2026 근거이며 기존 메시지는 수정하지 않았다.

## 정확성 후보와 남은 작업

정확성에서 리그 기대를 빼면 현행 Z0와 같다는 대수는 확인했다. A1은 고정 q구간 표준화 정확성의 후보이나 구간 내 구성·지원·결측 정책이 필요하다. A2는 확률 가중 조건부 스윙률의 차로 정확성 평균과 달라 보조로 제안했다. SA 별도 표시만으로 성향·공 구성 영향이 사라지지 않는다.

사용자의 A0/A1 후보 범위 답변을 기다린다. 신장 스냅샷의 회고적 한계·시즌별 판단 적격 포함률·근사 존 기준 비율/공통 카운트 가중·불완전 궤적/공 크기 가정을 고정한 뒤 ZN-A/ZS/ZN-U를 등록한다. BT는 기존 X를 반복하지 않는 증분 질문이나 표본·시점·통제·비교 기준이 별도 등록 대상이다. 이번에는 이들 모델을 적합하지 않았다.
