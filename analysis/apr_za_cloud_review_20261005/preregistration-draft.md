# 후속 검증 사전 등록 초안 — 모두 미실행

이번 작업에서는 새 후보의 적합·성능 비교·포함률 모의실험·경기 부트스트랩을 실행하지 않았다. 아래는 결과를 생성하기 전에 검토·고정할 설계다. 이미 확인한 역사적 결과 뒤에 작성했으므로 역사 자료 자체를 새로운 확증 표본이라고 부르지 않는다. 최종 실행 전 자료 해시·마감·생성법·표본·문턱·선택 규칙을 별도 커밋으로 고정하고, 이후 변경하면 별도 등록으로 남긴다.

## 공통 표본·해석 계약

- 기준은 이번 B 운영 `64959924`다. 타자별 n≥300, 반분은 각 n≥150을 기본으로 하되 각 초안의 지지 조건을 적용한다. 2019–2023 구심/2024–2026 ABS를 분리 보고한다.
- 원점수, 예측 고정 SE, 리그 중심·k를 포함한 지수 불확실성, 전체 재적합 불확실성을 따로 이름 붙인다. 신뢰도/상관은 이들 중 어느 척도인지 명시한다.
- 역사적 2019–2026 자료는 재검증·개발용이다. 빠진 과거 parquet은 확보 가능할 때만 쓰며 현재 집계로 경기 교차항을 대체하지 않는다. 자료가 없으면 미측정이고 전체 통과를 선언하지 않는다.
- 확증용 실제 자료는 등록 뒤 첫 정규시즌의 독립 경기·공통 판정 과제 등에서 모집단·마감을 평가 전에 고정한다. 과거 시즌을 보고 유리한 표본을 골라 확증이라고 재명명하지 않는다.
- 새로운 모형을 적합할 경우 외부 날짜 블록의 결과·보정·튜닝을 훈련에 쓰지 않는다. 회고 날짜 교차적합과 순방향 검증을 구분한다.
- 효과 크기·짝지은 차이 CI·표본 포함률을 보고한다. SA 상관 감소, APR 상관 감소, 상관의 통계적 비유의만으로 능력 측정의 개선을 선언하지 않는다.
- 운영 src/web/data·기존 gates·공개 산출물은 별도 운영 결정 없이는 변경하지 않는다. 외부 비공개 수치·대조점은 저장소에 남기지 않는다.

## B1. 현행 B 점추정 유지 + 공동 추정 SE 검증

**기존 R2/RB0–RB4와 통합하는 후속 검증**이다. 당시 R2는 A 운영에서 B 도입 시 필요한 검증이었고, 현재는 B가 운영 중이다. 새로운 원점수 후보를 추가하지 않는다. 기존 RB 기준을 결과에 맞춰 완화하지 않으며 현재 계산은 포함률/채택 검증의 대체가 아니다.

`y_B=200Cov_n(r,d)`를 유지한다. 예측 고정 IF는 `ψ=200[(r−m)(d−μ)−Cov_n(r,d)]`이고 `SE²=G/(G−1)Σ_g(Σ_tψ)²/n²`를 기본 검증법으로 둔다. G 보정 없는 값도 따로 보고한다. G≤1은 SE 불가, G<20은 정규근사만으로 공개 구간을 내지 않는다.

### 분석적 검산·음성 대조

RB0를 재사용한다: B=200Cov_n의 일치, 구역·행동 가법성, r와 d의 타자 내 상수 이동 불변성, 관측치 질량 미분과 IF 일치(오차 ≤10⁻¹⁰; 수치 미분은 step 수렴도 별도 확인). d가 상수이면 모든 재표집에서 B=0·IF=0·bootstrap 분산=0이어야 한다. r가 상수일 때도 같은 조건이다. 공분산 분모 n과 sampleVar 분모 n−1을 혼동하지 않는다.

### 구간 포함률과 경기 bootstrap

RB1/RB2의 n=100·300·1000, 경기 내 상관 0·0.1·0.3, 조건별 2,000회, 양/음/0 참 공분산을 유지한다. 균등/불균등 경기별 투구 수를 모두 포함한다. B1 확정 시 생성법·실제 G·모수·참 목표·seed=20261005와 Monte Carlo 오차 계산법을 고정한다. **이 초안에서 생성법과 작은 G용 와일드 bootstrap 세부 구현은 아직 확정 전**이므로 그대로 실행 가능한 최종 등록이라고 부르지 않는다. 연속 r,d의 공분산 추정량 검산과 이진 S의 행동 생성모형을 구분해 현실성을 점검한다. 실제 관측 자료의 bootstrap 일치만으로 포함률을 증명하지 않는다.

경기 bootstrap은 선수별 관측 경기를 복원추출하며 선택된 경기의 모든 투구를 같이 넣는다. 매 재표집에서 n, m, μ, B를 다시 추정한다. 동일 경기가 여러 번 뽑히면 재표집 경기 ID를 별도로 부여한다. 전체 표본 m이나 μ를 고정하지 않는다. 표준오차 비교용 재표집은 선수당 2,000회, seed=20261005이며 보고 구간은 percentile와 사전 선택한 studentized 방식으로 구분한다. 단일 선수가 한 경기 안에서 얻은 여러 투구를 독립 추출하지 않는다.

| ID | 유지할 판정/보고 |
|---|---|
| RB0 | 위 항등식·음성 대조 통과는 구현 검산이며 성능 증거 아님 |
| RB1 | G≥20의 95% 구간 포함률 92–98%; G<20은 별도 포함률을 충족한 방식만 사용 |
| RB2 | n≥300의 원점수 절대 편향 ≤참 타자 SD의 .05; 로그오즈 절편 성향 상황에서 변화 >기존 B SD의 .10이면 무조건적인 “공격성 중립” 이름을 사용하지 않음 |

두 가지 bootstrap을 별도 산출한다. (1) 선수별 경기 복원추출의 고정 예측 원점수 SE. (2) 시즌 경기 전체를 공동 복원추출해 선수 간 공동 변동·리그 중심 L·σ²·τ²·k까지 다시 계산한 지수 분포. (2)에서도 모형 예측을 고정하면 전체 파이프라인 불확실성이 아니다. 그 뒤 별도 재적합 bootstrap은 RE·사건/가치·p/q·등위 보정·평균·리그 기준·k를 모두 재추정하며 학습/평가 분리도 재현한다. 이 재적합의 비용·실패율은 별도 보고하고 이번에는 실행하지 않는다.

X1 반복성과 X4 결과 연관성이 좋아도 SE의 포함률이 틀릴 수 있다. B1에서는 X1/X4 성능만으로 올바른 SE라고 판정하지 않는다. 이 기준을 통과해도 개별 순위의 확실성이나 미관측 반대 행동의 인과 타당성을 자동 보장하지 않는다.

## H. 존 높이·체격 관련 원인 진단

**기존 R3/RH0–RH4를 대체하는 새 채택 실험이 아니라 선행 원인 진단**이다. 실제 신장은 검증된 선수 프로필의 신장이고, 측정 존 높이 `H=30.48(sz_top−sz_bottom)`는 자세·존 설정·좌표 오차가 포함된 다른 변수다. 투수 `release_height_cm`를 타자 신장으로 사용하지 않는다. 신장 자료가 없으면 신장 효과는 미측정이다.

진단은 현재 p/q를 고정하고 (a) 존 높이 분위별 (b) 실제 신장 분위별을 따로 분석한다. 좌우 경계/상하 경계/코너를 서로 배타적으로 정의하고, 시즌 판정면 좌표·경계까지 cm 간격을 확인한다. 같은 절대 거리와 같은 정규화 거리 분석을 둘 다 보고한다. ABS의 판정면과 앞면 상대좌표 region을 같은 거리라고 취급하지 않는다.

카운트, 구종, 속도, 투타 손, 구장, 날짜, 상하 위치, 코너 비중을 공통 지지 영역에서 층화/가중해 `E[S−p]`의 보정오차를 비교한다. q 구간을 맞춘 분석과 맞추지 않은 분석을 함께 고정한다. q도 체격·존의 함수여서 q에 조건화한 결과만으로 원인을 분리할 수 없다. 층당 500구 미만은 결측·지지 부족으로 표시하고, 타자·경기 의존을 보존한 bootstrap CI를 보고한다. 측정 존의 선수 내 시간 변화와 원자료 센서/좌표 변화를 보조 대조로 확인한다.

확인할 것은 (1) 높이 그룹 보정오차가 같은 맥락에서도 남는지, (2) 그 오차가 ZA 원점수에 전달되는 공분산/가중합이 얼마인지, (3) 좌우/상하/코너 어디에 남는지다. 점수와 신장의 단순 상관 감소만으로 편향 해소를 선언하지 않는다. 같은 변수의 상관 변화 비율을 기전 기여율로 보고하지 않는다.

입력을 추가해 재적합하는 채택 평가는 기존 R3와 통합한다. RH0 held-out 누출 검산, RH1 paired log loss 개선 ≥.001·95% CI 하한>0·어느 시즌도 악화>.002 없음, RH2 셀 보정 최대 오차 증가≤1%p·체격 차이 감소≥25%, RH3 경계별 조건부 계수/CI 보고, RH4 독립 기준 상관 차이의 CI 하한≥−.03을 유지한다. 독립 판정 기준이 없으면 “예측 개선”까지만 판단하고 인지 편향 해소는 보류한다. K-A 실패·K-B 운영 결정과 구별하며 입력 추가의 성공을 미리 가정하지 않는다.

## B2. 로짓 성향 중립화의 별도 후보

기존 R2/R1의 로짓 절편 기전 지적을 **실제 추정 후보의 정의·식별·SE 계획**으로 확장하는 초안이다. 이번에는 절편을 적합하지 않았고 성능 결과·채택 판정을 만들지 않았다.

고정 p에 대해 `p_ai,t=logistic(logit(p_t)+a_i)`를 두고 타자 절편 a_i를 이항 offset likelihood로 추정한다. p 경계는 `[10⁻⁶,1−10⁻⁶]`로 사전 clip하고 원 p의 경계 도달률과 clip 효과를 보고한다. 기존 B에는 이 clip을 소급하지 않는다. 모든 Swing/Take가 같은 선수는 유한 절편이 없으므로 후보 점수 미산출로 표시한다. 추정 가능 선수는 n≥300, Swing·Take 각각≥20, G≥20으로 제한하고 기존 적격 대비 포함률과 제외 유형을 공개한다.

후보 원점수는 `B2_i=200Cov_n(S−p_ai,d)`다. 무벌점 유한 절편의 score 식 때문에 표본 잔차 평균은 0이지만, 이를 미리 고정한 nuisance로 취급하지 않는다. 로짓 기울기 형태가 공통이고 타자 성향이 절편에만 들어간다는 가정, 조건별 행동 지지, p 보정·d 추정의 충분성, latent 능력과 성향의 식별 제약이 필요하다. 절편이 진짜 선택 배치 차이까지 흡수할 위험도 있다.

공동 추정 SE는 `(a_i,m_i,μ_i,C_i)`의 estimating equations Jacobian와 경기 score 합으로 sandwich를 만든다. 유한 무벌점 해에서 `e=S−p_a`, `h=p_a(1−p_a)`, `E(e)=0`이면 고정 예측 IF의 검산형은

```text
IF_a = e / E(h)
IF_B2 = 200{ e[d − E(hd)/E(h)] − E(ed) }
```

이다. 일반 공분산 식의 평균 추정과 a 추정항을 함께 미분해 위 식과 대조한다. 경계·비유한 해·벌점/계층 절편을 쓰면 이 식을 그대로 재사용하지 않고 새 Jacobian을 등록한다. bootstrap에서도 매번 a·평균·공분산을 다시 추정한다. B1의 조건부/전체 파이프라인 구분을 재사용하며 지수의 L/중심/k 정의는 후속 확정 전 자동 운영하지 않는다.

생성모형 비교에는 가산 확률 이동(범위 내), 로짓 절편만 다른 상황, 존/가치 기울기의 실제 능력 차이, p의 위치·높이별 보정오차, 공 구성 차이, 경기 의존, 개인 d의 오지정을 포함한다. B와 B2는 같은 생성/검증 표본에서 비교하며 B1의 포함률 기준을 재사용한다. 가산 중립이 맞는 상황에서 B2가 능력 신호를 지우는지와 로짓 모형이 틀린 상황의 실패도 보고한다. 생성 세부 모수와 최종 검증 과제는 실행 전 고정할 남은 항목이다.

채택 검토 조건 초안은 B1 SE 포함률 통과, 적격 포함률≥90%, 독립 존/선택 판정 기준과의 상관 차이 paired CI 하한>0, 반분 신뢰도 평균≥.60·B 대비 감소≤.05다. 관측 B2–SA가 작아졌다는 것만으로 통과하지 않는다. 동일 능력·구성을 고정한 모형에서 로짓 절편의 잔여 영향 크기와 오지정 손실을 보고한다. 한 조건이라도 미측정이면 운영 대체를 추천하지 않는다.

## Z-e. 기존 거리 후보의 재사용 여부 — 후순위 미실행 초안

현행 유지+안팎 진단을 우선하므로 당장 새 ZA 산식을 요구하지 않는다. 다만 먼 존 밖 스윙 강조를 별도로 원한다면 **초기 검토의 `Z-e-draft.md` E1을 재사용**한다. 새 이름으로 같은 후보를 또 만들지 않는다. 기존 R1 D-bin/D-q는 구성 표준화 목표이며 E1의 거리 강조와 다르다.

E1은 `h=1+.5 I(q<.5 AND region=chase)+1 I(q<.5 AND region=waste)`, `w=h/mean_league(h)`, `100mean_i[w(r−m_i)z]−μ_league`다. 무게는 가치 추정이 아니라 거리 강조의 정책 강도이며 ΔV/APR/선수 결과/외부 수치로 조정하지 않는다. 앞면 region을 ABS 물리 판정면 거리라고 부르지 않는다. p/q는 새 평가에 사용하는 B 기준 예측 버전을 고정하고, m·정규화·리그 평균은 각 평가창/반쪽/날짜 마감 안에서 재추정한다. 대조는 Z0와 N0이며 새로운 가중 강도·확신도 후보로 자동 대체하지 않는다.

기존 ZG1–ZG5는 다음 **정의와 문턱 그대로** 재사용한다. 게이트 목표와 순수 인지 목표의 한계는 별도 진단하며 과거 실패를 보고 문턱을 바꾸지 않는다.

ZG4의 실제 팀 경기 수·트레이드·마감은 원사이트와 대조해 먼저 고정한다. 리그 경기 수×2/10으로 임의 대체하지 않는다. 외부 원자료나 정의가 없으면 미측정이고 전체 통과 불가다. 사후 마감 이후 투구로 비용/정규화를 추정하지 않는다. 외부 비공개 수치는 파일·커밋에 남기지 않는다.

추가 겹침 기준은 **기존 E1 초안 ZE1–ZE3를 유지**한다. 적격 선수의 공개 APR **현재 B**와의 시즌별 Spearman 절댓값 증가 `|ρ(E1,B)|−|ρ(Z0,B)|≤.03`(모든 시즌), 8시즌 평균 `|ρ(E1,B)|≤.70`, 타자 내 상수 r 이동 후 점수 차이<10⁻¹⁰이다. .03/.70은 역할 보존의 정책 허용폭이지 독립성/유의성 경계가 아니다. 원래 초안의 A와 현재 B는 다른 대조이며 과거 A 표본의 통과를 현재 B 통과로 옮기지 않는다. 현재 Z0–B 평균이 .767이므로 이 절대 상한은 새 후보에 상당한 제약이다. 상한을 완화해 성공을 만들지 않는다. 새로운 목표로 바꾸려면 별도 등록한다.

ZG6 X4 계수/CI·시즌 간 상관, 다음 BB% 상관 차이 CI, 보정오차·존 비중·2스트라이크 비중·거리 구성과의 관련성, 안팎 기여, n별 불확실성·집단 포함률도 보고한다. N3의 기존 실패는 인정하며 E1은 가치 비사용이라는 차이가 있지만 그 실패 회피를 가정하지 않는다.

선택 규칙: 필수 ZG/ZE를 모두 통과해야 추가 검토 대상으로 남긴다. **통과만으로 채택하지 않는다.** 이후 독립 공통 판정 과제(또는 맥락·절편을 분리한 독립 존 선택 기준)에서 E1−Z0의 타자 bootstrap 상관 차이 CI 하한>0, 같은 모집단 반분 신뢰도 감소≤.05를 추가로 요구한다. 이는 후속 초안의 실질 개선 요건이며 기존 게이트를 소급 변경하는 것이 아니다. 독립 기준이 없거나 차이가 불확실하면 단순한 현행을 유지한다. 후보가 개선돼도 본래 목표가 “기대 일치 초과분”에서 “먼 체이스 강조”로 바뀐다는 설명을 먼저 승인받을 별도 운영 안으로 만든다.

실행 순서는 B1 → H 진단 → 필요할 때 R1/B2 → 거리 강조가 여전히 필요할 때 Z-e다. 외부/과거 투구 자료가 없는 검증을 합성값으로 채우지 않는다.
