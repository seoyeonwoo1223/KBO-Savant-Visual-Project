- 평균 공동 추정의 기대값 `E[Bhat]=B[1−(1−h)/n−hΣm_g²/n²]`을 CSV와 독립 대조했다. 등록 생성모형·고정 경기 크기에 한정한 식이다.
- 실제 166명에 대한 RB3는 현행 SE와 G 보정 IF 모두 통과한다. IF 선택을 가르는 기준이 아니다. 서로 다른 bootstrap의 퍼짐이 Monte Carlo 오차와 비슷하다는 것은 합리적 설명이지만, **모든 차이가 잡음뿐이라는 증명이나 유한표본 샌드위치=bootstrap의 정확한 항등식은 아니다**.
- IF는 공분산의 질량 미분과 상수 이동 음성 대조에 근거한다. RB1은 IF 구간만 검증했으므로 같은 합성 격자에서 현행보다 우월하다고 주장할 직접 대조는 없다.
- 웹에 SE 구간이 없더라도 SE가 k를 바꾸면 APR 점수·순위에 영향을 준다. 기존 k 723.54→662.91(보정 없음)/681.89(G 보정), 보정 없는 IF 비교 최대 .55968점이라는 작은 영향과 “영향 없음”을 구별한다. 실제 운영은 변경하지 않았다.
- 작은 G 실패, 실제 참값 포함률, 시즌 공동 경기 bootstrap(리그 중심·k), 전체 예측 재적합, 전시즌 검증은 남아 있다. t 임계값·반합성은 별도 사전등록 후보이며 이번에 실행하지 않았다. 반합성은 타자별 경기 모집단, 불균등 경기 크기의 투구 가중 목표 `EΣrd/E n−(EΣr/E n)(EΣd/E n)`, 표집·유한 G 편향을 명시해야 한다.

## ABS 기하·공유 오차식·단위

끝면 기준을1.5cm 낮추는 공식 기하에 동의한다. 단, 기존 gap으로 복원한 `max(z_mid,z_back)−min(z_mid,z_back)`은 절댓값이며 부호 있는 낙하 `delta=z_mid−z_back`가 아니다. 모든 궤적이 하강한다는 추가 검증 없이 0012의 단순식을 일반식으로 사용할 수 없다. 일반 이동량은 아래와 같다.

```
top_shift = max(0,1.5−delta)−max(0,−delta)
bottom_shift = min(0,1.5−delta)−min(0,−delta)
```

0012의1,577/116,403(1.3548%)는 하강 가정 아래 **수직 경계 상태만** 바뀌는 Take다. 원격 고정 소스에서 `PLATE_HALF_WIDTH_FT=10/12`이므로 `x_mid_cm=25.4×x_mid_relative`다. 공식 좌우 ±23.59cm까지 포함한 공 중심 기준 변화는 같은 하강 가정 아래848/116,403(0.7285%)다. 실제 콜 차이·정확성 개선이 아니며, 공 반지름도 포함하지 않는다. 부호 있는 원 궤적과 두 면을 직접 사용한 수치로 후속 확인해야 한다. 운영 x 척도의1을 공식 존 경계1로 간주하지 않는다.

두 면의 공유 수직 정규 오차와 수평 독립이라는 가정이면 0012-C6 식에 동의한다. 수직 인자는 `max(0, Φ((rho−T)/sigma_z)−Φ((−rho−B)/sigma_z))`로 비어 있는 교집합을 처리하고, sigma=0의 결정적 극한·양수 sigma·공 반지름 고정값/민감도·면별 오차 상관 가정을 등록한다. Take 콜로 적합한 sigma는 순수 센서 정확도와 구분한다. 2024·2025 plane_fallback·단위·상/하단 정합 포함률은 아직 미검증이며 자동 추정값을 넣지 않는다.

## A1′와 BT 등록 초안에 대한 답

A1′ 식은 구간 내 q 구성을 고정하므로 동일 구간 q=.01/.09 예를 제거한다. 다만 원 실제 투구 정확성 A0와는 다른 표준 환경 점수이며 구간 내 판별력도 버린다. 모든 타자·구간에 같은 가산 스윙률 변화 delta, 고정 qbar/w/지원, clipping 없음이면 기울기 `Σw(2qbar−1)`가 같아 순위가 유지된다. 타자별 다른 delta 또는 n/(n+k_b) 축소를 적용하면 이 불변성이 자동 성립하지 않는다. 빈 구간 prior·지원/제외·w/qbar/k_b의 기준 훈련 자료·평가 분리·구간 폭 민감도·가산/로짓 성향 대조를 등록 전에 고정한다. 후보 범위 사용자 선택은 대기 중이다.

BT의 T 증분 질문·완료된2019→2020…2024→2025 쌍·타자 군집 불확실성·ABS 전환 민감도에 동의한다. “쌍 단위 CV”가 어떤 분할인지 명시해야 한다. 같은 타자가 여러 쌍에 남는 무작위 분할로 신규 타자 일반화를 주장하지 않고, 미래 시즌 예측을 평가하려면 시간 분리와 미관측 시즌 고정효과 처리도 정한다. β_T의90% CI 전체가 사전 ±Delta 안에 있어야 계수 동등성이며, 비유의성 또는 계수 동등성만으로 모든 증분 예측 없음이라고 단정하지 않는다. delta·Delta의 단위/크기와 결과별 판정 결합 규칙은 결과를 보기 전에 등록한다. 이번에는 적합하지 않았다.
