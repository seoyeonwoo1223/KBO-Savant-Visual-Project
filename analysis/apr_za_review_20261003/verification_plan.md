# APR·ZA 읽기 전용 재현 기준 (계산 전 고정)

이 문서는 신규 산식 실험의 등록이 아니라 기존 산식·저장 결과의 감사 범위다. 신규 후보의 적합·성능 비교·채택은 실행하지 않는다. 개선 실험은 별도 `gates.md`에 등록용 초안으로만 쓴다. 이 파일을 먼저 커밋한 뒤 아래 재현 계산을 수행한다. 결과에 따라 문턱을 바꾸지 않는다.

## 공통 정의

- 대상: 현재 체크아웃의 2019–2026 공개 리더보드, 기존 X·Z 계열 결과 CSV/JSON, 2026 투구별 근거의 필요한 열. 과거 시즌 모델 재빌드는 하지 않는다.
- 읽기: `data/curated/summary.json` → `data/curated/schema.json` → 명시한 열·파일. 인덱스, 바이너리 원문, 생성 데이터의 차이는 열지 않는다.
- 환경: Python 3.12, `pip install -r requirements.txt -c constraints-za.txt`, `PYTHONPATH=src`, `OMP_NUM_THREADS=2`, `OPENBLAS_NUM_THREADS=2`. 바이트코드 쓰기를 끈다.
- 결과: 이 폴더의 `results/`만. 절대 경로·파이썬 빌드 문자열·실행 시각은 기록하지 않는다. 입력의 상대 경로·SHA-256·기준 커밋과 패키지 버전은 기록한다.
- 주장: 직접 산식·데이터로 재현한 값은 **확인함(코드·데이터로 확인함)**, 식별할 수 없는 원인·방향·제안 효과는 **추정**. 저장 기록의 열람과 투구별 재계산은 구분한다.

## 감사 기준

| ID | 계산 | 문턱 | 선택 규칙 |
|---|---|---|---|
| V1 | 소스 `MODEL_VERSION`, 공개 8시즌 버전, APR 입력 식을 대조 | 일치 여부를 그대로 보고 | 요청의 버전 전제와 다르면 운영값·기존 후보값을 분리 |
| V2 | 리더보드로 리그 중심화·수축 k·지수·midrank 재계산 | 점수 최대 오차 ≤ 0.0001, k 상대 오차 ≤ 0.0001 | 미달 시 산식·반올림·모집단 차이를 조사하고 실패를 남김 |
| V3 | 2026 투구별 APR·ZA·SA 및 구역/행동 가법성 재계산 | 공개 점수·집계 최대 오차 ≤ 0.0001 | 다른 모델 버전이면 일치 검증의 대상으로 삼지 않음 |
| V4 | 기존 X 후보 CSV로 A/B–SA 상관·표준편차, Z CSV로 평균 존 방향 역산 | 기록 상관 오차 ≤ 0.0002, CSV 정밀도를 표기 | 기존 후보 재현이며 신규 후보 선택에 사용하지 않음 |
| V5 | 기존 X/Z 결과 JSON에서 신뢰도·외부 비교·회귀 CI 대조 | 문서 반올림 정밀도에서 일치 | 투구/외부 원자료가 없으면 독립 재현으로 부르지 않음 |
| V6 | 2026 ZA와 2스트라이크 비중·존 높이, 경계 방향별 연관을 기존 점수로 재계산 | 인과 채택 문턱 없음 | 관측 상관만 보고; 선수 유형 원인이라는 주장은 검증 불가로 표시 |
| V7 | 동일 스크립트를 두 번 실행해 결과 파일 해시 대조 | 바이트 동일 | 결과 비결정성을 해결한 뒤 최종 커밋 |

## 한계

확인함: 신규 후보를 실행하지 말라는 사용자 지시가 이 검토에 적용된다. 체격 특성을 추가하는 재적합, 새로운 D 후보 성능, 실행 능력 보정, 계층 수축, 순방향 교차적합은 실행하지 않는다. 기존 투구의 요약 상관만으로 체격의 인과효과 또는 관측되지 않은 반대 행동의 정확성을 식별할 수 없다는 점은 이론상 한계이며, 해당 효과의 크기는 추정으로 남긴다.
