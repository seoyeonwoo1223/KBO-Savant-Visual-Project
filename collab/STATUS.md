## 확정된 검토 목표와 실행 순서

사용자 결정 원문 취지를 [2026-10-08 결정 기록](decisions/20261008-apr-za-direction.md)에 정리했다. 운영 산식은 위 현행 기준을 유지한다.

- **APR:** SEAGER 목표만 계승·KBO 변형, 리그 기대 스윙 차감 우선. SEAGER 차이의 별도 설명은 필수 요구가 아님. 평균 적극성 차감은 필수가 아닌 실험·비교 대상.
- **ZA:** 정확성 자체가 주점수, SA 별도. 구심(2023년까지)은 신장 기반 근사 존 정규화·실제 Take 콜 학습·고정 공통 카운트 가중 q_std, 최종 해석은 표준화된 콜 존. ABS(2024년 이후)는 시즌별 공식 타자별 규정 존·정규화·경계 고정, 필요 모형은 측정/궤적 불확실성 처리로 제한.
- **순서/담당:** claude 피드백 → gpt 비판적 검토 → ID 예약·gates.md 사전 등록 커밋 → 현재 Codex 클라우드 환경에서 gpt 실험. 사용자 지시로 이 검토 범위의 조건부 실행이 승인됨. 피드백 전 실행하지 않음.
- **미확정:** 변환 계수·공통 가중 수치/기준 기간·시즌별 규정 출처/판정면 검산·정확성 집계/단위·검증 문턱·최종 실험 순서. claude와 논의하고 등록 전에 고정.
- **범위:** 기존 ZQ-a·ZL-a 초안의 일괄 승인·q_za 자동 대체·운영 반영·병합 승인 아님. 기존 결과·기준·발송 메시지는 보존.

## 남은 설계 논의와 사용자 결정 대기

1. **claude 피드백 선행:** APR 적극성 비교·SE 검증, 신장 근사 존 변환/입력 감사, 시즌별 ABS 규정/판정면, 정확성 집계·검증 문턱·실험 분할/순서. 0008의 사용자 목표·실행 담당을 다시 승인 대기로 올리지 않음.
2. 기존 ZQ-a·ZL-a 통합 초안은 새 목표에 맞춰 개정/추가 등록할 범위를 논의. 특히 잔차 주점수·현행 q 고정·q_std 실패 시 q_za 전환을 그대로 실행하지 않음. 원 등록과 결과는 보존.
3. 공개 출력물 일치 감사 예외는 명시 승인되지 않음. 계산은 원천 자료에서 시작하며 필요성과 대안을 구체화해 논의.
4. 과거 수축 수치의 문서 정정·AGENTS 창구 안내는 이번 지시로 자동 승인된 것으로 확대하지 않음.
5. 최종 운영 산식/공개 반영·병합은 실험 검토 후 별도 사용자 결정. 현행 운영은 유지.
6. PL+ 세부 산식과 외부 Zone Judgement 공개 방법론은 여전히 미확인. 사용자 KBO 정의 선택과 원 지표 구현 확인을 구분하며 비공개 수치·역추정 가중을 근거로 쓰지 않음.
7. **신장 원천 결정 완료(2026-10-09):** KBO 공식 신장을 수집하고 출처·조회 시점을 기록한다. 현재 프로필과 과거 신장의 차이, 실패·이름 불일치·선택 편향을 보고한다(0010). 미래 ABS 역산은 자동 대체하지 않는다.
8. **정확성 범위 (0010):** A0/A1을 주점수 후보로 비교할지, A0만 주후보·A1 보조로 둘지 답변 대기. A2는 정확성 평균과 달라 보조로 권고.
