# 사용자 결정: APR·ZA 검토 목표와 후속 실험 범위

- 결정일: 2026-10-08 (사용자 시간대 Asia/Seoul).
- 근거: 사용자가 채팅에서 직접 전달한 APR 결정 1–3, ZA 결정 1–5. 에이전트 제안과 구분해 기록한다.
- 상태: 검토 목표 확정, claude 피드백 요청. 기존 운영 산식 채택·변경이나 병합 결정은 아니다.
- 실행 담당/환경: claude 피드백을 받은 뒤 gpt가 비판적으로 검토하고, 현재 Codex 클라우드 환경에서 실험·비교 검토까지 수행한다. 피드백 전 실행하지 않는다. 실험마다 ID 예약과 gates.md 사전 등록·커밋을 먼저 한다. 이 조건을 충족한 아래 검토 범위의 실험은 사용자 지시로 진행하며 같은 범위의 실행 허가를 다시 요구하지 않는다. 새로운 목표·범위 또는 운영 변경은 별도 결정이다.

## APR

1. SEAGER의 **목표만 계승**한다. 상수와 모델은 KBO에 맞게 변형한 형태를 검토·채택하는 방향이다. 원문의 두 비율 산식을 그대로 복제하는 목표가 아니다.
2. 리그 기대 스윙을 차감하는 **리그 대비 평가**를 우선한다. SEAGER와의 차이를 별도 설명 문구로 굳이 명시할 필요는 없다는 사용자 선호를 기록한다. 기존 연구 근거·발송 메시지는 보존한다.
3. 타자 평균 적극성 차감을 필수 조건으로 보지 않는다. claude와 소통하며 차감 유무 등을 실험·비교해 검토한다. 현행 B를 즉시 폐기하거나 로짓 중립 B2를 채택한 결정이 아니다.
4. 이번 결정에 대한 claude 피드백을 먼저 받고 gpt가 비판적으로 검토한다. 이후 위 범위의 실험은 gpt가 현재 환경에서 수행한다. SE 검증과 적극성 처리 비교의 등록 기준·이미 본 결과·재현 범위를 구분한다.

## ZA

1. 주점수는 **선택의 정확성 자체**다. 리그 기대 스윙 잔차를 주점수의 정의로 유지하는 방향이 아니다. 단위·지수화·최종 집계 세부는 아직 확정하지 않았다.
2. 타자별 존 정규화를 적용한다.
   - **구심 시대(2023년까지):** 신장 기반 기준 존으로 투구 좌표를 정규화하고, 실제 Take의 볼/스트라이크 콜을 학습한다. 학습 모형의 카운트별 콜 확률을 고정 공통 카운트 가중치로 평균한 q_std를 사용한다.
   - 신장만으로 당시 규칙의 자세 기반 존을 정확히 재현할 수 없으므로 기준 존은 **근사**다. 최종 대상은 **표준화된 콜 존**이다. 신장 근사 존 자체를 실제 역사적 규칙 존 또는 인지 정답으로 부르지 않는다.
   - **ABS 시대(2024년 이후):** 해당 시즌 공식 ABS 규격으로 타자별 존을 정하고 정규화한다. 규정 경계는 고정한다. 모델이 필요하면 측정 오차·부족한 궤적 정보에 따른 불확실성 처리로 역할을 제한한다. 실제 콜을 학습해 규정 경계를 옮기는 역할을 주지 않는다.
   - 구심 q_std 검증이 미달해도 q_za로 자동 대체하는 결정이 아니다. 미달 시 원인·지원·정규화·불확실성을 검토한다.
3. 가급적 선택의 정확성만 평가하고 **SA는 별도로** 둔다. 로짓 성향 제거를 ZA 주점수의 필수 조건으로 채택하지 않았다.
4. 후보 선택·검증 기준은 claude와 논의한다. 카운트/SA 상관 기준 강등, 반분·연도 간 관계, 외삽·표본 지원·실패 처리, 거리 가중 등의 세부 제안은 일괄 확정된 것이 아니다.
5. claude 피드백 후 gpt가 비판적으로 검토하고, 현재 환경에서 사전 등록 후 실험한다. claude가 실행하는 것으로 기록하지 않는다.

## 피드백·설계에서 구체화할 항목

- 신장 원천·시점·선수 ID 연결·결측과 신장→근사 존 변환의 근거. 기존 sz_top/sz_bottom을 어떻게 대조할지와 좌표 단위·판정면 정합성.
- 시즌별 공식 ABS 규격·적용 시점·규정 판정면·공의 경계 통과 조건의 출처. 불완전 궤적과 측정 오차 처리, 규정 고정 검산.
- 공통 카운트 가중의 모집단·기준 기간·수치·외부 평가 fold의 누출 방지·모든 양의 가중 카운트의 지원.
- 정확성 원점수·집계·분모·지원·경계/불확실성 처리와 기존 잔차 지표의 대조 범위. SA는 별도 산출한다.
- 기존 ZQ·ZL·H·B1·B2의 재사용 가능한 검산과 새 등록이 필요한 변경을 구분한다. 기존 실행 결과·문턱·발송 메시지를 덮어쓰거나 새 목표의 확증 결과로 재해석하지 않는다.
- 출력물 감사 예외와 운영 변경은 이번 지시에서 별도로 승인된 것으로 확대하지 않는다.
