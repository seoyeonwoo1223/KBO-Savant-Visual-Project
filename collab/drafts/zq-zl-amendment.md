### 추가

- **하네스 H0 확장:** 재적합한 q_call과 p_swing 배열이 ZC 캐시와 SHA-256으로 일치해야 한다. 투구 ID(`game_id`, `event_seq`)·순서·fold·dtype·Python·패키지·입력 파일 해시도 일치해야 한다. ZC `load_human`은 `event_seq`를 버리므로 새 러너에서 보존한다.
- **지지 경보 (문턱은 제안):**
  - 투구 t의 가중 경보 질량: a_t = Σ_c w_c·1{그 외부 평가 fold의 학습 데이터에서 (카운트 c, region_t) 셀의 Take < 50}.
  - 판정에는 시즌 평균 ā를 쓴다. ā > 0.05이면 ZQ2를 미판정으로 둔다.
  - a_t > 0인 투구 비율도 보고한다.
  - 민감도: a_t > 0인 투구를 세 후보(Z0_call, Z0_free, Z0_std)에서 공통으로 빼고 다시 계산한다. 추정 대상이 바뀐다는 점을 보고한다.
  - 학습 Take의 x·z 1–99 분위 밖 투구 비율은 "주변 분포 경보"로만 부른다. 두 축 사이의 빈 영역이나 카운트별 조건부 외삽을 검증했다고 쓰지 않는다.
- **재표집:**
  - 단위는 타자다. 공유 경기 의존은 다루지 않는다는 한계를 적는다.
  - 매 재표집에서 편상관 잔차 회귀를 다시 적합한다.
  - 공통 ID는 두 시즌 모두 적격이고 공변량 결측이 없는 타자다.
  - 총 시도·성공·탈락 수와 탈락 사유를 보고한다. 탈락이 5%를 넘으면 판정을 보류한다. 탈락률이 낮다고 편향이 없다는 증거는 아니다.
- **paired SE (보고):**
  - 타자 i의 차이 Δ_i = 100·mean[r(z_free − z_call)].
  - 투구 영향함수 ψ_t = 100·r_t(z_free,t − z_call,t) − Δ_i, 경기 합 U_g = Σ_t∈g ψ_t.
  - SE² = G/(G − 1)·Σ_g U_g² / n². G ≤ 1이면 계산하지 않고, G가 작으면 정규근사의 한계를 적는다.
  - |Δ| > 2·SE 인원은 고정 예측 조건부 기술통계다. 다중 검정·순위 불확실성·재적합 불확실성의 증거가 아니다.

## ZL-a. ZL 실행 전 보완

### 대체

| 기존 ZL 문장 | 대체 |
|---|---|
| "이미 본 결과 … L0 자체는 계산하지 않았다" | (Z0 − Z0_null)은 L0와 대수적으로 같으므로 L0의 SA 상관은 이미 봤다: Z0_call 기준 −0.16 / −0.04 / −0.08, Z0_free 기준 −0.18 / −0.06 (2022 / 2023 / 2026). 이 진단은 Z0에 원 p를, 귀무에 clip p를 썼으므로 새 정의와 clip 차이만큼 다르다. SA 방향을 판정 기준에서 뺀 결정은 이 값을 본 뒤에 내렸다. 명시적 L0 산출물·SE·반분·시즌 간 평가는 아직 하지 않았다 |
| ZL0 "Pearson(L0, Z0 − Z0_null) ≥ 0.95" | 산술 항등식으로 바꾼다. 같은 clip p로 계산한 Z0′·Z0_null에서 max \|L0 − (Z0′ − Z0_null)\| ≤ 1e−10. 타자별 절편 score 잔차 \|mean(S − p_a)\| ≤ 1e−8. 원 p Z0와 Z0′의 최대 차이(clip 영향)를 보고한다. 통과는 구현 검산일 뿐 측정 개선의 증거가 아니다 |
| ZL1·ZL2 판정 | 점추정 기준(Z0 대비 감소 ≤ 0.05)은 그대로다. "등록 운영 규칙 통과"라 부르고 통계적 비열등 입증이라 부르지 않는다. 95% bootstrap 구간은 보고한다. a_i는 반분·재표집·시즌 간 비교의 각 창 안에서 다시 적합한다 |
| ZL4 "가산 이동 귀무 clip(p + m_i)" | 두 귀무를 구분해 보고한다. (i) 평균 일치 가산 귀무: mean clip(p + m_i′) = mean S가 되도록 m_i′를 푼다. (ii) 단순 clip(p + m_i). 로짓 귀무에서 Z0·N0의 같은 값도 보고한다 |
| ZL5 "\|Δ\| > 1 SE 비율" | Δ_i = L0_i − Z0_i의 paired SE(차이의 공동 영향함수, 경기 합, G/(G − 1))로 정의하고, \|Δ\| > 2·SE 인원을 보고한다 |

### 추가

- **반분 지원:** 각 절반 150구 이상, Swing·Take 각 10구 이상, 10경기 이상. 미달 타자는 그 창에서 Z0·L0 양쪽 모두 뺀다.
- **수치 실패 (문턱은 제안):**
  - 분모는 수치 풀이 전에 지원 적격인 타자다.
  - 실패는 ±8 구간 안에 근이 없음, 비유한 해, E(h) < 1e−3이다. ±8 무근은 유한 해가 없음과 구별해 기록한다. 전부 스윙이거나 전부 테이크인 타자는 지원 조건에서 미리 빠진다.
  - 원 창의 실패율이 2%를 넘으면 그 창은 판정을 보류한다. 2% 이하면 실패 타자를 Z0·L0 양쪽에서 함께 뺀다.
  - 원 창과 재표집 창의 실패율, 재표집 탈락률을 따로 보고한다. 실패율이 낮다고 선택 편향이 없다는 증거는 아니다.
- **유한차분 검산 (문턱은 제안):**
  - 대상: 타자 i의 L0_i를 투구 t의 질량 ε에 대해 미분한 값. 오염 분포 (1 − ε)F + ε·δ_t이고, 각 ε에서 a_i를 다시 푼다.
  - 방법: 중앙 차분. step h = 1e−4·1e−5·1e−6.
  - 허용오차: |IF| ≥ 1e−6이면 상대오차 ≤ 1e−6, 그 미만이면 절대오차 ≤ 1e−9.
  - step 사이 결과가 허용오차 안에서 일치하는지 본다. 근 찾기와 반올림 오차의 바닥이 있으므로 오차의 단조 감소는 요구하지 않는다.
- **결론 문구:** 미달이어도 "로짓 성향 성분이 선수에게 유리하게 작용함이 입증됐다"고 쓰지 않는다. "그런 성분이 존재할 수 있다는 모형상 한계"로만 쓴다.
- **B2와의 관계:** offset·clip·root·지원·공동 영향함수 하네스를 B2와 공유하고, 판정·문턱은 지표별로 따로 둔다. ZL은 운영 q만 쓰고 ZQ의 q 변경과 섞지 않는다.
